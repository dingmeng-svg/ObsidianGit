## 数据核对验证标准

采集完成后，用以下方法交叉验证：

| 数据 | 第一验证源 | 第二验证源 | 允许误差 |
| :--- | :--- | :--- | :--- |
| 上证指数 | 东方财富 | 腾讯行情API（qt.gtimg.cn） | 0 |
| 深证成指 | 东方财富 | 腾讯行情API（qt.gtimg.cn） | 0 |
| 创业板指 | 东方财富 | 腾讯行情API（qt.gtimg.cn） | 0 |
| 两市成交额 | 东方财富 | 腾讯行情API | ±50亿 |
| 上涨/下跌家数 | 东方财富行情页 | 腾讯行情API | ±50家 |
| 涨停家数 | 东方财富行情页 | 腾讯行情API | ±5家 |
| 北向资金成交额 | 东方财富沪深港通 | 新浪财经 | ±2亿 |
| 板块资金流向 | 东方财富行业资金流 | 新浪财经 | 排名一致即可 |

**核对原则**：偏差超范围时，以新浪财经为第三方裁决。同花顺/雪球需登录，不可作为验证源。

## Agent 采集流程

当 SOP V4.1 的腾讯 API 采集失败时，Agent 应按以下步骤使用本表：

```
1. 查表：按「类别」定位需要采集的数据行
2. 打开：用 browser 工具打开「数据源链接」
3. 定位：根据「提取提示」列的描述，在页面中找到对应数字
4. 记录：将提取的数值填入 YAML 对应字段
5. 验证：打开「第二验证源」页面，核对是否在允许误差内
6. 超出误差：打开新浪财经，以第三方数据为准
7. 反馈：采集完成后，更新「数据源状态」列：
   - ✅ YYYY-MM-DD 验证正常
   - ⚠️ YYYY-MM-DD 页面改版，字段位置变化（附新位置说明）
   - ❌ YYYY-MM-DD 链接失效/数据缺失
```
