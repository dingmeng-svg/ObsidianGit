# 第一部分：每日决策入口

## 1.1 统一决策树（每天第一件事）

```
今天是什么日子？
  │
  ├── 步骤A：今天是交易日吗？
  │   自查清单：
  │   □ 是周六或周日？→ 不是交易日
  │   □ 查2026年法定节假日表（见1.2）→ 节假日不是交易日
  │   □ 调休补班日？→ 虽然是周末但是交易日！
  │   □ 调休放假的工作日？→ 虽然是工作日但休市！
  │
  ├── 是交易日 → 翻到【第二部分：交易日复盘】
  │
  └── 不是交易日（休市日）
      ├── 先检查有没有重大突发事件：
      │   □ 全球主要股指单日跌幅超过3%？
      │   □ 央行意外加息/降息？
      │   □ 地缘冲突导致原油单日涨超5%？
      │   □ 国内出台资本市场重大政策文件？
      │   └── 有的话 → 优先做事件速报+影响评估
      │
      └── 判断休市类型 → 翻到【第三部分：休市日SOP】
```

## 1.2 2026年法定节假日参考

| 节日 | 日期 | 休市安排 |
|:---|:---:|:---|
| 元旦 | 1月1日（周四） | 1月1日-4日 |
| 春节 | 2月17日（周二） | 2月14日-22日（调休） |
| 清明节 | 4月5日（周日） | 4月4日-6日 |
| 劳动节 | 5月1日（周五） | 5月1日-5日 |
| 端午节 | 6月19日（周五） | 6月19日 |
| 中秋节 | 9月25日（周五） | 9月25日-27日 |
| 国庆节 | 10月1日（周四） | 10月1日-7日 |

> **每次执行前**：搜索确认国务院官方通知。节假日安排每年可能调整。
> 休市日记录必须标注**下一交易日日期**。

## 1.3 去重机制（每天强制执行）

无论交易日还是休市日，动笔之前必须：

1. **翻看前一天保存的复盘/审计记录**，找到里面的「重要新闻」部分
2. 重复新闻（内容相似度超过70%）→ 只保留一句结论，或标注"昨日已述"
3. 新新闻 → 正常展开
4. 休市日连续多天时 → 对比前一天的假设追踪表，看有没有新验证

# 第二部分：交易日复盘（操作流程）

## 2.1 核心理念

交易日复盘**不只是记录数据**，而是用结构化框架，把收盘信号转化为可执行的认知。

做完复盘后，应该能回答：
- 今天市场**真正发生了什么**？（不是涨跌数字本身）
- **谁在买、谁在卖**？（资金从哪来、到哪去）
- 自己的判断**被验证了还是被打脸了**？

## 2.2 数据采集工具清单

## 2.3 数据采集流程（逐步操作）

### Step 1：收盘数据（约 3 分钟）

打开**同花顺APP首页**或**东方财富APP**，记录：

- [ ] 上证指数：收盘点数、涨跌幅
- [ ] 深证成指：收盘点数、涨跌幅
- [ ] 创业板指：收盘点数、涨跌幅
- [ ] 科创50：收盘点数、涨跌幅
- [ ] 两市成交额（注意单位是"亿"）
- [ ] 上涨家数、下跌家数
- [ ] 涨停家数、跌停家数

> 💡 **成交额提示**：不同平台显示的数字可能相差几十亿，属正常范围。固定使用一个平台的数据，保持一致即可。

### Step 2：板块数据（约 5 分钟）

打开**东方财富"行业板块"页面**，记录：

- [ ] 涨幅前 3 的板块 + 涨幅%
- [ ] 跌幅前 3 的板块 + 跌幅%
- [ ] 资金净流入前 3 的板块 + 金额
- [ ] 资金净流出前 3 的板块 + 金额

### Step 3：新闻采集（约 8 分钟）

打开**财联社电报**或**东方财富"要闻"**，按优先级收集：

| 优先级 | 内容类型 | 采集数量 |
|:---:|:---|:---:|
| 第一 | 央行操作、关键经济数据、重大政策 | 全部浏览 |
| 第二 | 美股/港股收盘、A50期指、人民币汇率 | 3-5 条 |
| 第三 | 商品期货、亚太市场 | 2-3 条 |
| 第四 | 行业新闻、公司公告 | 选最重要的 3-5 条 |

### Step 4：外盘数据（约 2 分钟）

打开**同花顺"全球"页**或**东方财富"全球市场"**，记录：

- [ ] 纳斯达克：收盘价、涨跌幅
- [ ] 道琼斯：收盘价、涨跌幅
- [ ] 恒生指数：收盘价、涨跌幅

### Step 5：数据交叉验证（约 2 分钟）

快速核对：
- 指数点数 → 两个平台对比，应完全一致
- 成交额 → 允许 ±50 亿误差
- 涨跌家数 → 允许 ±50 家误差
- 涨停家数 → 允许 ±5 家误差

对不上但误差在范围内 → 取常用平台数据。
误差超出范围 → 找第三个平台确认。

### 模块 3：🔍 分条详细解读（写作参考）

从模块 2 中挑 3-5 条最重要的新闻，每条展开写 100-200 字解读。

每条的思路：
- 这条新闻**说了什么**？
- **为什么重要**？
- 对市场**可能有什么影响**？
- 需要**关注什么后续**？

> 提示：可嵌入一些英文关键词（如 policy easing、sector rotation、risk appetite），方便日后搜索和关联。

### 模块 4：📈 收盘总结（写作参考）

提炼今天市场的**2-3 个核心特征**，回答以下问题：

1. **今天市场在交易什么逻辑？**（宏观驱动？政策驱动？情绪驱动？）
2. **核心矛盾是什么？**（多空双方在争什么？）
3. **操作层面的启示是什么？**（宏观/板块层面，**严禁推荐个股**）

> 格式示例：
> - **特征一**：今天市场呈现典型的"XX"格局——[描述]
> - **特征二**：资金从[XX]流向[XX]，说明[判断]
> - **核心矛盾**：[一句话概括]
> - **启示**：[宏观/板块层面的操作思路]

## 2.5 数据缺失或异常处理

| 情况 | 处理方法 |
|:---|:---|
| 北向资金净额 | 自 2024 年起不再按日披露。只记录成交额，**不要编造数字** |
| 北向成交额 | 仍按日披露，正常记录 |
| 某个数据找不到 | 换一个平台查。实在找不到就写"—"，注明原因 |
| 板块排名无法获取 | 从新闻中间接推断领涨/领跌板块 |
| 数据源之间不一致 | 取常用平台数据，保持一致；差距太大就找第三个平台 |
| 成交额数据 | 写确定值，**不要同时写"约XXXX亿"又写精确数字** |

## 2.6 记录与分享规范

1. **先完成完整记录，再分享/发布** — 不要在未完成时边写边发。
2. **数据区保持干净** — 每行一个指标，便于快速扫读。
3. **有数据就写数据，没有就写"—"** — 不留占位符。
4. **标注信息来源** — 每个数据都应知道其出处。

## 2.7 交易日常见问题

| 问题 | 解决方法 |
|:---|:---|
| 数据采集时间过长 | 控制在 20 分钟内，避免过度追求完美 |
| 新闻太多写不完 | 按优先级筛选，最多记 8 条 |
| 忘记去重 | 动笔前先翻阅昨天的记录 |
| 成交额单位搞错 | 确认是"亿"还是"万" |
| 北向净额填写了数字 | 该数据已停止披露，留空或写说明 |
| 行文过于机械 | 用自己的话写，口语化更好 |

# 第三部分：休市日 SOP（操作流程）

## 3.1 核心理念

**休市日不等于无事可做，而是「回顾整理 + 前瞻预期」的黄金时间。**

休市日要回答三个问题：
1. **本周市场验证了什么？**（周度审计）
2. **下周市场可能发生什么？**（策略推演）
3. **自己的判断框架需要调整吗？**（元复盘）

## 3.2 休市类型判断

```
今天是休市日，具体是哪种？
├── 周六（或周五是节假日首日）
│   └── 【周六型 · 周度审计】
├── 周日（或节假日第二、三天）
│   └── 【周日型 · 策略推演】
├── 节假日连续第 3 天以上
│   └── 【长假守望型】
├── 距下一交易日 ≤ 1 天
│   └── 【收假前一日 · 节后交易计划】（必须执行）
└── 每月第一个周六
    └── 额外加做【SOP健康度自检】
```

### 重大突发事件优先处理

| 触发条件 | 操作 |
|:---|:---|
| 全球主要股指单日跌幅 > 3% | 暂停原计划，先做事件速报 + 影响评估 |
| 央行意外降息/加息 | 同上 |
| 地缘冲突导致原油单日涨 > 5% | 同上 |
| 国内出台资本市场重大政策 | 同上 |

## 3.3 通用写作要素（所有休市日类型适用）

### 情绪曲线（每次必含）

在记录开头，用一条情绪线概括本周/本假期的市场心理：

```
> 🎬 情绪曲线：😤(焦虑/警惕) → 😊(欣慰/认可) → 🤔(思考/分析) → 💪(坚定/行动)
```

根据实际情况调整表情和阶段描述。

### 记忆锚点系统

在文章中设置这些"路标"，方便阅读和日后回顾：

| 模块 | 锚点标语 | 建议时长 |
|:---|:---|:---:|
| 开场 | 「休市不停更！」 | 1 分钟 |

## 3.4 数据字典（操作参考）

做周度审计时，需要以下数据。查询方式及注意事项：

| 指标 | 查询方式 | 注意事项 |
|:---|:---|:---|
| 周度成交额均值 | 将本周每日成交额相加 ÷ 交易天数 | 使用自己每日记录的数据计算 |
| 周度涨停家数合计 | 同花顺问财搜索"本周涨停家数" | 不同平台可能差 15%，标注来源 |
| 北向资金周度净额 | ⚠️ 不存在！自 2024 年起不披露 | 改为记录周度成交额合计 |
| 板块周度表现 | 东方财富行业板块，切换"周"视图 | 科创板板块需单独标注 |

### 数据质量标注

在记录中对每个数据标注质量：

| 标记 | 含义 | 适用场景 |
|:---|:---|:---|
| ✅ 已验证 | 至少两个独立来源确认 | 指数数据、成交额 |
| ⚠️ 估算值 | 单源或推算 | 某些细分数据 |
| ❌ 不可获取 | 制度性缺失 | 北向净额 |

## 3.5 数据缺失处理

| 步骤 | 操作 |
|:---|:---|
| 1 | 换几个平台再查一次，确认真的缺失 |
| 2 | 有其他平台数据但非主流来源 → 采用，标注来源 |
| 3 | 实在找不到 → 记录中写"—" |
| 4 | 在数据下方加说明，解释缺失原因 |

| 场景 | 处理方式 |
|:---|:---|
| 指数收盘数据缺失 | **必须尽力查找**（这是最核心数据） |
| 指数开盘数据缺失 | 可标"—"，补充说明 |
| 板块资金流向缺失 | 使用其他平台替代数据，标注来源 |
| 北向资金净额 | 制度性缺失，**严禁编造** |

# 第六部分：常见问题与注意事项

## 数据类

1. **成交额单位** — 确认是"亿"，不是"万"或"元"
2. **北向资金净额** — 2024 年起停止披露，只记录成交额，**严禁编造**
3. **数据源不一致** — 取常用平台数据，保持一致；差距太大则找第三个验证
4. **缺失就标"—"** — 宁可不写，也不造假
5. **精确值就是精确值** — 不要在同一处同时写"约XXXX亿"和精确数字

## 流程类

6. **先完成完整记录，再分享** — 不要在未完成时边写边发
7. **动笔前先翻看昨天的记录** — 去重是最容易被跳过的步骤
8. **控制采集时间** — 数据采集不超过 20 分钟，避免陷入信息沼泽
9. **假设追踪表单独维护** — 使用独立文件，不要在每篇复盘里重新发明

## 内容类

10. **估值数据必须可查** — 不编造 PE、增速等指标
11. **跨周期对标要具体** — 写明"类似2019年初"，而不是"类似历史上某次"
12. **不推荐个股** — 只分析板块、方向，不说"买入XX股票"
