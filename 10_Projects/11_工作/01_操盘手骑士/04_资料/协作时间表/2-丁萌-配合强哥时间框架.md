# 2-丁萌-配合强哥时间框架

> **定位**：丁萌的个人日程框架，用于与强哥对齐协作窗口。
> **核心原则**：盘中互不打扰（9:15-15:00 各自专注），晚间直播同步（20:30-21:15 共同播报），收盘后（15:00-16:00）和晚饭时（19:00-19:30）是沟通窗口。


## 核心分析

### 强哥的关键时间节点

| 时段 | 强哥在做什么 | 配合策略 |
| :--- | :--- | :--- |
| **周一至周五 9:15-12:00** | 盘中交易（竞价→走势→午盘） | 各自专注，互不打扰 |
| **周一至周五 12:30-15:00** | 午间+下午走势+收盘 | 各自独立运作 |
| **周一至周五 17:00-21:00** | **工作日直播** | 晚间播报同步 |
| **周六日 19:00-21:00** | 周六日直播 | 共同直播 |
| **周六日 9:00-12:00** | 亲情时光+阅读 | 独立学习/复盘/个人事务 |
| **周六日 16:00-19:00** | 休闲/晚餐时光 | 自由支配 |

## 更正裁决：归入项目资料区

### 理由

强哥的时间表是"协作方的可用窗口"，这份是"丁萌如何调整自己的节奏来配合协作方"。两者是配对关系——一份定义强哥什么时候在做什么，一份定义丁萌如何配合这个节奏。它们应该放在一起，作为项目协作的参考资料。

### 目标路径

```
10_Projects/11_工作/01_操盘手骑士/03_资料/和老刘配合版的时间框架.md
```

### 与强哥时间表的关系

| 文件 | 定位 |
|:---|:---|
| `强哥时间节点安排表.md` | 外部协作方的工作节奏 |
| `和老刘配合版的时间框架.md` | 丁萌自身配合该节奏的日程框架 |

两者放在同一个目录下，形成完整的协作时间参考。
