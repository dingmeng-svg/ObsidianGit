## 二、详细时间表


### 07:00 — 07:15 开设备

**做什么**：
1. 打开电脑、打开 OBS，确认画面正常
2. 开灯（三盏灯），确认灯光正常、画面清晰
3. 试验好麦克风，对着镜头说两句话，确认音量正常
4. 登录财联社，快速扫隔夜美股收盘、日韩港股早盘情况
5. 配合袁姐姐完成推流地址获取和粘贴


### 07:15 — 07:30 备课 + OBS 打字

**做什么**：
1. 根据今天盘前新闻和预判，从固定语义场中选词填表
2. 将填好的词打字到 OBS 文字图层中
3. 调整位置和大小，确认手机预览能看清

**打字格式**（输入到 OBS 文字图层）：

```
【今日英语】
Gap Up / 跳空高开
Add Position / 加仓
Volume / 成交量
Fed / 美联储

【核心语块】
The market gapped up on heavy volume.
```


### 07:30 — 07:55 自由时间

**做什么**：
- 吃早餐、喝咖啡
- 最后再看一遍财联社新闻
- 深呼吸、放松、准备开播


### 07:55 — 08:00 开播前最后检查

**做什么**：
1. OBS 画面正常？
2. 声音正常？
3. 三盏灯都亮着？
4. OBS 文字显示正常？→ 确认无误后，**点击文字图层眼睛图标，显示今日英语词**
5. 袁姐姐已完成推流？→ 确认「开始推流」已点亮


### 08:00 — 12:00 上午档直播

**内容方向**：
- 8:00-9:15：盘前预热，读财联社早间头条，讲隔夜外围市场，今天重点关注什么
- 9:15-9:30：竞价时段，看竞价数据，讲哪些板块/个股异动
- 9:30-11:00：早盘实盘，讲开盘强弱、板块轮动、盘中异动、量能变化
- 11:00-11:30：上午走势小结，预判下午方向
- 11:30-12:00：自由解说，回答评论区问题（如果有），继续跟盘

**英语融入方式**：
- 新词第一次出现时解释意思，第二次复习，第三次巩固
- OBS 文字一直显示在画面角落，观众随时看到
- 每个词至少暴露 3 次以上

**操作提醒**：
- 本时间段**不需要任何操作**
- 如果有突发新闻，心里过一下是否对应了某个词，对应的话自然带出来


### 12:00 — 13:00 午休

**做什么**：
- 吃午饭
- 休息、让嗓子休息
- 用电脑扫午间财联社快讯，看有无突发新闻
- 如果有突发新闻，在心里过一遍下午怎么自然带出对应英语词


### 12:55 — 13:00 配合袁姐姐重新推流

**做什么**：
- 确认袁姐姐已完成新的推流地址粘贴
- 确认 OBS「开始推流」已重新点亮
- 确认视频号后台「开始直播」已重新点亮


### 13:00 — 16:00 下午档直播

**内容方向**：
- 13:00-13:15：午后开盘，回顾上午走势
- 13:15-14:30：午后走势，趋势、量能、资金流向
- 14:30-15:00：尾盘博弈，盯最后半小时的异动和竞价
- 15:00-15:30：收盘总结 + **英语主课堂**
- 15:30-16:00：全天综合总结，预告晚间强哥直播

**英语融入方式**：
- 上午的词继续重复暴露
- 午休时备的新词，在对应场景自然带出
- 15:00-15:30 英语主课堂集中复习
- 英语主课堂结束后，切换到当日核心语块整句显示


### 15:00 — 15:30 英语主课堂（每天固定环节）

**流程**：

| 步骤  | 丁萌做什么                                          | OBS 文字做什么         |
| --- | ---------------------------------------------- | ----------------- |
| 第一步 | “今天我们学了 5 个词，快速过一遍——”                          | 仍显示今日 5 个词        |
| 第二步 | 逐个复习：英文 → 中文 → 今天的实例                           | 每说到一个词，配合高亮或停顿    |
| 第三步 | “现在把这 5 个词串成一个句子——”                            | **切换到语块整句**，放大、居中 |
| 第四步 | 带读 2 遍：“The market gapped up on heavy volume.” | 语块整句保持显示          |
| 第五步 | “大家不用背，每天跟着读一遍，一周下来就会了。”                       | 语块整句保持显示          |


### 15:30 — 16:00 收尾

**做什么**：
1. 全天走势综合总结
2. 预告晚间强哥直播（20:00-21:00）
3. 提醒：“今天学的词，晚上强哥复盘可能会用到，大家可以留意。”
4. **16:00 下播**
5. OBS 文字图层：点击眼睛图标隐藏文字（或保持显示，供晚间备用）


### 16:00 — 16:30 课后整理

**做什么**：
1. 将今日备课表（5 个词 + 1 个语块）存档
2. 将今日词清单整理成一条消息，发给强哥：
   - “强哥，今天白天教了这几个词：[词清单]。晚上直播时如果自然提到可以带一下，不强求。”
3. **如果袁姐姐还没学会 OBS 打字**：保留今日文字图层不删，方便晚间可能使用
4. **如果袁姐姐已经学会**：清空或隐藏文字图层，次日重新输入
5. 下班
