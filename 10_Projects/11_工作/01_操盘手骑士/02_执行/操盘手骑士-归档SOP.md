# 操盘手骑士 · 产出物归档 SOP

> **适用范围**：操盘手骑士项目所有文件的归档操作（AI 执行版）。
> **设计原则**：活跃文件在 `10_Projects/…/操盘手骑士/` 下按目录分类，过期文件在 `40_Archive/项目存档/操盘手骑士/` 下保持同构目录结构。

---

## 一、递归原则

```
40_Archive/项目存档/操盘手骑士/
  ├── 01_规划/         ← 已归档的规划文档
  ├── 02_执行/         ← 已归档的执行文档
  ├── 03_资料/         ← 已归档的资料文档
  ├── 04_产出/         ← 已归档的产出文档
  ├── 股市数据播报/    ← 按月份归档的复盘稿
  │   ├── 2026/5月/
  │   ├── 2026/6月/
  │   └── ...
  ├── CPO 板块 产业链系列/
  ├── M.A.S.T.E.R 技能习得模型/
  ├── 白皮书/
  ├── 创世纪系列/
  ├── 会炒菜就会炒股/
  ├── 会议纪要/
  └── 痛点/
```

- **按类型归档**（01_规划/ 02_执行/ 03_资料/ 04_产出）：与活跃目录保持子目录结构和文件名一致。
- **按项目归档**（CPO/MASTER/白皮书/创世纪/会议纪要/痛点）：独立子项目整体归档，保留原目录结构。
- **按月份归档**（股市数据播报/2026/{MM}月/）：时间序列产出物，按月份整体移动。

## 二、触发时机

| 触发条件 | 说明 |
|:---------|:-----|
| 每月第一个周复盘 | 将上月股市数据播报复盘稿归档到对应月份 |
| 项目阶段变更 | 某模块不再活跃（如旧规划/旧白皮书/废弃脚本）→ 立即归档 |
| 文件重命名/校准后 | 旧版本写完 Archive 新文件后，立即删除原路径旧文件 |
| 主人主动要求 | 「这个归档」「那个已过时，归档」 |

## 三、AI 执行指令集

### 3.1 分类判断

收到「归档 X」指令后，先判断类别：

| 文件所属 | Archive 目标路径 | 示例 |
|:---------|:----------------|:-----|
| `01_规划/`、`02_执行/`、`03_资料/`、`04_产出/` 下的文件 | `项目存档/操盘手骑士/{同目录名}/` | `01_规划/xxx.md` → `项目存档/操盘手骑士/01_规划/xxx.md` |
| 独立子项目（CPO/MASTER/白皮书等） | `项目存档/操盘手骑士/{项目名}/` | `03_资料/工具箱/短视频 创作 白皮书/` → `项目存档/操盘手骑士/白皮书/` |
| 股市数据播报的月度复盘稿 | `项目存档/操盘手骑士/股市数据播报/{YYYY}/{MM}月/` | `04_产出/股市数据播报/2026/6月/` → `项目存档/操盘手骑士/股市数据播报/2026/6月/` |
| 会议纪要 | `项目存档/操盘手骑士/会议纪要/` | `02_执行/会议纪要/xxx.md` → `项目存档/操盘手骑士/会议纪要/xxx.md` |

### 3.2 文件重命名规范

归档时文件名统一命名体系：

- 分隔符统一用 `-`（空格/下划线/圆点/全角空格 → `-`）
- 无括号后缀（移除 `（2026-05-06 会议提炼）` 等）
- 项目前缀统一：`操盘手骑士-`
- 别名通过 `aliases` 字段保留，保持 wikilink 可用

### 3.3 FM 校准（归档书写入时必须执行）

| 字段 | 归档前 | 归档后 |
|:-----|:-------|:-------|
| `tags` | 各类非标值 | `[归档, 工作]` |
| `status` | `active` / `draft` / `internal-only` | `archived` |
| `archived_date` | — | `YYYY-MM-DD`（归档当天日期） |
| `aliases` | 可选 | 写入旧文件名，确保全库断链自愈 |
| 清理 | `source`、`usage`、`用途`、`category`等非标字段 | 删除，归入正文 |

### 3.4 正文归档说明块

写入 Archive 文件时，在 FM 之后添加 callout 说明块：

```markdown
> **归档说明**
>
> - **原路径**：{原相对路径}
> - **归档日期**：{日期}
> - **内容**：一句话概括
> - **归档原因**：为什么归档
```

### 3.5 旧文件删除与断链检查

1. Archive 新文件写入成功 → **立即删除原路径旧文件**（不请示，减少轮次）
2. 删除前搜索全库旧文件名引用 → 有引用则通过 `aliases` 自动映射（不需手动修补）
3. 删除后验证原目录中该文件已消失

### 3.6 股市数据播报按月归档（特殊流程）

适用于每月初将上月复盘稿移入 Archive：

1. 确认上月复盘稿目录：`04_产出/股市数据播报/2026/{MM}月/`
2. 搜索该目录下文件，确认无活跃双链引用
3. 整体移动目录到 `40_Archive/项目存档/操盘手骑士/股市数据播报/2026/{MM}月/`
4. 验证后写入 Worklog

## 四、不归档内容

以下内容永远保留在 `04_产出/` 下，不随月份归档：
- `04_产出/股市数据播报/SOP/` — 生产规范文档
- `04_产出/股市数据播报/股市数据播报 MOC.md` — MOC 索引

## 五、质量验证

| 检查项 | 标准 |
|:-------|:-----|
| 归档文件存在 | `ls` Archive 路径确认 |
| 原路径已删除 | `ls` 原路径确认旧文件消失 |
| FM 正确 | `status: archived`，`tags: [归档, 工作]`，有 `archived_date` |
| 别名写入 | `aliases` 包含至少一个旧文件名 |
| 无断链 | 旧文件名可通过 alias 解析（免手动修补） |
