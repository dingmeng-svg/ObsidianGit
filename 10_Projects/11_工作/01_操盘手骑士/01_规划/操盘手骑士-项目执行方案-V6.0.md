## 一、项目定位

**核心问题**：股民"知而不行"——道理全懂，执行全废。

**核心交付**：
1. **线上内容**：数据与直播稿等，价格较低，用于获客和建立信任。
2. **线下培训**：核心交付的主要来源，让用户从"知而不行"转变为"知而能行"。

**内容原则**：
- 盘前直播（09:00-10:00）：隔夜信息 + 开盘观察，内容待与强哥商议后完整填充。
- 盘后直播（15:30-16:00）：当日收盘数据 + 百万军规故事 + 行动指令。
- 晚间直播（19:00-21:00）：强哥主播，丁萌全程配合。
- 三段内容时间上不重叠，信息不重复。

## 十、短视频生产标准

- **时长**：30-60秒，独立内容，不混剪直播
- **结构**：自然开场 → 讲故事 → 顿悟时刻 → 自然共鸣 → 顺其自然
- **模式**：一条百万军规一个真实故事，"我曾经→转变→改变后"
- **生产节奏**：每天11:00-12:00写一条稿，下午或傍晚拍摄，次日10:00-11:00剪辑发布
- **学习期**：前10条约3小时/条，稳定后约1小时/条


## 十一、数据采集与语言标准

- **数据源**：同花顺APP（指数/涨跌家数）、东方财富（板块资金/新闻）、财联社（电报）
- **交叉验证**：指数0误差，成交额±50亿，涨跌家数±50家，涨停±5家
- **采集时间**：控制在20分钟内
- **语言标准**：零修饰语，对标新闻联播财经风格
- **缺失处理**：标"—"，不编造

# 第一部分：每日决策入口

## 1.1 统一决策树（每天第一件事）

```
今天是什么日子？
  │
  ├── 步骤A：今天是交易日吗？
  │   自查清单：
  │   □ 是周六或周日？→ 不是交易日
  │   □ 查2026年法定节假日表（见1.2）→ 节假日不是交易日
  │   □ 调休补班日？→ 虽然是周末但是交易日！
  │   □ 调休放假的工作日？→ 虽然是工作日但休市！
  │
  ├── 是交易日 → 翻到【第二部分：交易日复盘】
  │
  └── 不是交易日（休市日）
      ├── 先检查有没有重大突发事件：
      │   □ 全球主要股指单日跌幅超过3%？
      │   □ 央行意外加息/降息？
      │   □ 地缘冲突导致原油单日涨超5%？
      │   □ 国内出台资本市场重大政策文件？
```

# 第二部分：交易日复盘（操作流程）

## 2.1 核心理念

交易日复盘**不只是记录数据**，而是用结构化框架，把收盘信号转化为可执行的认知。

做完复盘后，应该能回答：
- 今天市场**真正发生了什么**？（不是涨跌数字本身）
- **谁在买、谁在卖**？（资金从哪来、到哪去）
- 自己的判断**被验证了还是被打脸了**？

## 2.3 数据采集流程（逐步操作）

### Step 1：收盘数据（约 3 分钟）
打开**同花顺APP首页**或**东方财富APP**，记录：
- [ ] 上证指数：收盘点数、涨跌幅
- [ ] 深证成指：收盘点数、涨跌幅
- [ ] 创业板指：收盘点数、涨跌幅
- [ ] 两市成交额（注意单位是"亿"）
- [ ] 上涨家数、下跌家数
- [ ] 涨停家数、跌停家数

> 💡 **成交额提示**：不同平台显示的数字可能相差几十亿，属正常范围。固定使用一个平台的数据，保持一致即可。

### Step 2：板块数据（约 5 分钟）
打开**东方财富"行业板块"页面**，记录：
- [ ] 涨幅前 3 的板块 + 涨幅%
- [ ] 跌幅前 3 的板块 + 跌幅%
- [ ] 资金净流入前 3 的板块 + 金额
- [ ] 资金净流出前 3 的板块 + 金额

### Step 3：新闻采集（约 8 分钟）
打开**财联社电报**或**东方财富"要闻"**，按优先级收集：

| 优先级 | 内容类型 | 采集数量 |
|:---:|:---|:---:|
| 第一 | 央行操作、关键经济数据、重大政策 | 全部浏览 |
| 第二 | 美股/港股收盘、A50期指、人民币汇率 | 3-5 条 |
| 第三 | 商品期货、亚太市场 | 2-3 条 |
| 第四 | 行业新闻、公司公告 | 选最重要的 3-5 条 |

### Step 4：外盘数据（约 2 分钟）
打开**同花顺"全球"页**或**东方财富"全球市场"**，记录：
- [ ] 纳斯达克：收盘价、涨跌幅
- [ ] 道琼斯：收盘价、涨跌幅
- [ ] 恒生指数：收盘价、涨跌幅

### Step 5：数据交叉验证（约 2 分钟）
快速核对：
- 指数点数 → 两个平台对比，应完全一致
- 成交额 → 允许 ±50 亿误差
- 涨跌家数 → 允许 ±50 家误差
- 涨停家数 → 允许 ±5 家误差

对不上但误差在范围内 → 取常用平台数据。误差超出范围 → 找第三个平台确认。

## 2.5 数据缺失或异常处理

| 情况 | 处理方法 |
|:---|:---|
| 北向资金净额 | 自 2024 年起不再按日披露。记录中写"自2024年起停止披露"，**不要编造数字** |
| 北向成交额 | 仍按日披露，正常记录 |
| 某个数据找不到 | 换一个平台查。实在找不到就写"—"，注明原因 |
| 板块排名无法获取 | 从新闻中间接推断领涨/领跌板块 |
| 数据源之间不一致 | 取常用平台数据，保持一致；差距太大就找第三个平台 |

## 2.6 记录与分享规范
1. **先完成完整记录，再分享/发布** — 不要在未完成时边写边发。
2. **数据区保持干净** — 每行一个指标，便于快速扫读。
3. **有数据就写数据，没有就写"—"** — 不留占位符。
4. **标注信息来源** — 每个数据都应知道其出处。

# 第三部分：休市日 系统文档（操作流程）

## 3.1 核心理念
**休市日不等于无事可做，而是「回顾整理 + 前瞻预期」的黄金时间。**
休市日要回答三个问题：
1. **本周市场验证了什么？**（周度审计）
2. **下周市场可能发生什么？**（策略推演）
3. **自己的判断框架需要调整吗？**（元复盘）

## 3.2 休市类型判断
```
今天是休市日，具体是哪种？
├── 周六 → 【周六型 · 周度审计】
├── 周日 → 【周日型 · 策略推演】
├── 节假日连续第 3 天以上 → 【长假守望型】
├── 距下一交易日 ≤ 1 天 → 【收假前一日 · 节后交易计划】（必须执行）
└── 每月第一个周六 → 额外加做【SOP健康度自检】
```

### 重大突发事件优先处理
| 触发条件 | 操作 |
|:---|:---|
| 全球主要股指单日跌幅 > 3% | 暂停原计划，先做事件速报 + 影响评估 |
| 央行意外降息/加息 | 同上 |
