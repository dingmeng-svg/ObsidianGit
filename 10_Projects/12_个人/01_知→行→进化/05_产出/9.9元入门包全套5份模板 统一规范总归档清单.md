**层级归属**：🟧时间层（索引/每日记录/月度记录/未来记录）、🟦身份层（习惯记分卡）

### 一、全局统一格式规范（全部模板强制执行）

#### 1. 页面标题规范

- YAML头部携带对应时间字段作为**唯一数据源**，禁止H1重复书写年月日期
  - 每日记录：仅携带 `date` 作为唯一数据源，无额外年月、星期字段
  - 月度记录/习惯记分卡：`month: YYYY-MM`、`date: YYYY-MM-01`
  - 未来记录：`year: YYYY`、`date: YYYY-01-01`
- H1一级标题固定静态文字，不包含动态年份月份
  - 每日记录：`# 📅 每日记录`
  - 索引：`# 📑 索引 — YYYY年`（仅索引标题带年份，用于年度区分）
  - 月度记录：`# 📆 月度记录`
  - 未来记录：`# 🚀 未来记录`
  - 习惯记分卡：`# 📊 习惯记分卡`

#### 2. YAML标签统一规则

基础通用标签：`子弹笔记` 全部模板必带

1. 每日记录：`tags: [子弹笔记, 日记]`
2. 索引：`tags: [子弹笔记]`
3. 月度记录：`tags: [子弹笔记, 月度记录]`
4. 未来记录：`tags: [子弹笔记]`
5. 习惯记分卡：`tags: [子弹笔记, 习惯追踪]`

#### 3. 标准化子弹符号全局唯一体系

顶部速查统一话术：
`[ ]`待办 `[x]`完成 `→`迁移 `⏰`延期 `~~取消(删除线)~~` `-`笔记 `!`日程 `?`灵感

完整释义表格统一存放于「索引.md」，每日记录仅保留一行速查，不重复大表格。

流转定义全局统一：
- `→`迁移：当日未完成，顺延次日（每日记录内部流转）
- `⏰`延期：长期事项，移入未来记录
- `~~`取消：任务作废，删除线标记

#### 4. 统一安装说明书写标准

固定包含三块内容：
1. 文件存放路径指引（`_templates/` 文件夹）
2. YAML占位符 `YYYY` / `YYYY-MM` 替换操作说明
3. 使用后同步更新索引.md对应表格链接指引

#### 5. 联动链路书写规范

所有跨文件跳转统一使用Obsidian双链格式 `[[文件名]]`，全文文件名完全统一，无别名冲突。

⚠️ 重命名文件后，请同步检查YAML的 `title` 字段与文件名保持一致，避免索引表显示错乱。


### 二、五大模板分层定位+专属统一规则

#### 1. 《每日记录.md》｜🟧时间层·日行为采集

**核心定位**：日常轻量输入，行为原始采集

1. 仅保留一行符号速查，完整教程跳转索引
2. 习惯打卡仅放通用示例：喝水8杯、阅读30分钟，末尾引导汇总至习惯记分卡
3. 无月度统计表格，不承担汇总职能，杜绝双重记录
4. 晚间反思极简三模块：本月成就、改进点、明日核心事项

#### 2. 《月度记录.md》｜🟧时间层·月度总览与任务闭环

**核心定位**：当月日历、月度任务迁移、月度复盘决策

1. 日历空白通用6行表头，无固定日期，适配2/大小月，多余行可删除
2. 任务清单明确双向流转：上月`→`迁移、未来`⏰`延期；月末未完成回流未来记录
3. 复盘区固定联动两处：汇总所有每日记录反思、同步读取习惯记分卡月度数据

#### 3. 《未来记录.md》｜🟧时间层·远期任务缓冲区

**核心定位**：存放非当月事项，年度任务永续管理

1. 四大固定分区永久不变：近期待落地(1-2月)/中期规划(3-6月)/远期规划(下半年)/本年度备用待办
2. 完整流转链路前置公示：每日`⏰`延期→未来储备→月初迁移月度→月末回流未来
3. 全年无需修改分区标题，仅调整内部任务条目

#### 4. 《索引.md》｜🟧时间层总中枢目录

**核心定位**：全库导航、唯一完整符号教程存放页、模板联动总入口

1. 顶部标注入门包仅包含身份层+时间层，自然铺垫PARA/ZK完整版升级
2. 内置全套子弹符号对照表，全书唯一完整版教程
3. 三大固定表格：核心集子、按需填写月度记录表、带示例个性化集子（固定示范[[习惯记分卡]]）
4. 底部配套模板联动指引，串联每日/月度/习惯三套模板使用逻辑

#### 5. 《习惯记分卡.md》｜🟦身份层·月度习惯分析复盘

**核心定位**：月度汇总工具，不做日常打卡，承接每日记录数据输出长期身份洞察

1. 开篇明确分工：每日记录打卡、本文件月末汇总，解决双重记录痛点
2. 无Markdown打卡表格，采用可自由增删的清单文本
3. 两大固定板块：本月核心习惯统计、月度趋势汇总
4. 汇总结论强制联动：分析结论复制至月度记录下月调整板块
5. 开篇标注归属「🟦蓝色身份层（原子习惯）」，对齐架构图文案


### 三、全模板统一流转闭环（整套体系唯一工作流）

1. **每日层**：每日记录完成当日任务、习惯轻打卡，远期任务标记`⏰`延期
2. **月度缓冲**：`⏰`延期任务统一放入《未来记录》对应时间分区
3. **月初流转**：从未来记录迁移当月到期任务至《月度记录》
4. **月末双向回流**
   - 月度未完成任务：标记 `⏰` 延期回《未来记录》
   - 每日全月习惯数据：汇总至《习惯记分卡》做趋势分析
5. **决策落地**：习惯分析+月度复盘结论同步写入《月度记录》下月调整计划
6. **全库索引**：新建任意月度/个性化集子，同步在《索引.md》补充双链链接


### 四、售后&体验统一兜底规则（所有模板内置）

1. 全部模板零插件原生可用，Templater仅作为进阶自动化方案，不作为基础使用前提
2. 无固定死日期、月份表格，全部支持用户自行增删行/列，适配所有月份
3. 不内嵌任何营销、自测问卷入口，工具页面纯粹；升级指引统一放置在外部配套文档（FAQ、架构说明、README）
4. 符号、层级、术语全书100%统一，无版本残留旧标记，避免用户认知混乱
5. 所有空白表格、空白清单附带示例，零基础用户可直接参照填写，降低使用门槛

## 📝 子弹符号完整说明

> 每一条记录前面加一个符号，看一眼就知道是什么类型。

| 符号 | 名称 | 含义 | 用法 |
|:---:|:---|:---|:---|
| `- [ ]` | 待办 | 待办事项 | 做了就勾 `- [x]` |
| `- [x]` | 完成 | 任务已完成 | 打勾即可 |
| `→` | 迁移 | 移到下一天 | 当天未做完，顺延至次日 |
| `⏰` | 延期 | 移到未来记录 | 暂不处理，放入未来记录 |
| `~~` | 取消 | 不需要做了 | `~~买牛奶~~` → 整条划线即取消 |
| `-` | 笔记 | 普通记录 | `- 事实、观察、想法` |
| `!` | 日程 | 有固定时间 | `! 约会、会议、截止日` |
| `?` | 灵感 | 待探索 | `? 需要进一步查证或思考` |

**使用口诀**：早上写任务，白天记笔记，晚上勾完成。未完成的，迁移或取消。
> `→` 迁移：当天未做完，顺延至次日 | `⏰` 延期：暂不处理，放入未来记录

```markdown

# 🚀 未来记录

> **用途**：存放「不是这个月要做」的事情。每月初翻到这里，把本月到期的移入月度记录。
>
> **完整流转链路**：每日记录（`⏰` 延期） → 未来记录储备 → 当月到期迁移 → 月度记录 → 月末未完成回流未来记录


## 近期待落地（1-2个月内）

> 短期可落地、已有明确执行意向的事项。

- [ ] 
- [ ] 

## 中期规划（3-6个月内）

> 需要筹备、延后执行的季度事项。

- [ ] 
- [ ] 

## 远期规划（今年下半年）

> 长期目标、年度后半段重点事项。

- [ ] 

## 本年度备用待办

> 仅有年度意向、暂无具体落地时间的想法。

- [ ] 


> **安装说明**：一份未来记录对应一年。年初创建，将文件名和 YAML 区中的 `YYYY` 替换为当前年份（例如 `2026`），`date` 改为 `2026-01-01`。之后全年无需修改分区标题。
>
> **操作方式**：
> 1. 在每日记录中想到一个远期任务 → 根据时间远近放入上方对应分区，写上 `- [ ] 任务内容`
> 2. 在原每日记录中对应任务前标记 `⏰`，表示已延期到未来记录
> 3. 每月初翻到这里，把近期该做的任务移入当月「月度记录.md」，移走后在此处原任务前加 `→` 并划掉，保留迁移记录
> 4. 月末复盘时，本月未完成的任务也从「月度记录.md」移回此处对应分区，下月初再决定是否继续
>
> **用法示例**：现在是 1 月，想到「5 月要给妈妈买生日礼物」→ 放入「中期规划」分区，写 `- [ ] 买生日礼物`。到了 5 月初，翻到这份未来记录，把这条移到当月月度记录。
```
