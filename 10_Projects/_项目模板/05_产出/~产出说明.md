# 📦 产出

> 存放：所有交付物、成品文件。

## 产出路径铁律

所有可交付的成品文件**只能**放在 `05_产出/` 下，不可散落在其他目录。

### 常见产出类型

| 类型 | 示例 |
|:-----|:------|
| 播报稿 | `股市数据播报/2026/7月/每日复盘直播稿/YYYY-MM-DD-A股复盘直播稿.md` |
| 脚本 | `短视频脚本/EPXX-标题.md` |
| 白皮书 | `白皮书V4.0-标题.md` |
| 课程大纲 | `课程大纲-标题.md` |

### 目录结构示例

```
05_产出/
├── 股市数据播报/
│   ├── 2026/
│   │   ├── 7月/
│   │   │   └── 每日复盘直播稿/
│   │   │       └── YYYY-MM-DD-A股复盘直播稿.md
│   │   └── 8月/
│   └── SOP/
│       └── 各SOP文件.md
└── 其他产出分类/
```

> **季度归档**：上一季度的产出物在季度末移入 `40_Archive/项目存档/`，保持 `05_产出/` 仅存放当前活跃项目的最新产出。
