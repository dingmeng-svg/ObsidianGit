### 一、设计理念与核心原则

本模板充分尊重阿新“白天主业+晚上直播+周末特殊安排+新活动需熬夜”的复杂现实，将**不规律**作为设计前提，让团队能看见每一分付出，接住每一次疲惫。

**核心原则：**
1. **轻量高效**：每日填写不超过8分钟，勾选为主，填写为辅。
2. **现实适配**：不强求固定产出，只记录真实发生的任务和状态。
3. **特殊时段可视化**：周末双段直播、凌晨新活动突击，都有专门模块记录。
4. **压力可视化**：通过情绪与预警模块，让团队提前发现苗头，及时介入。

### 四、使用说明

#### 给阿新的填写指南

1. **填写时间**：直播结束后、睡前，固定时间填写，不超过8分钟。

2. **模块填写要点**：
   - **基础信息**：先选“今日类型”，让团队一眼知道今天是工作日、周末还是特殊日。
   - **白天碎片任务**：有空就填，没空不填。这个模块是为了**看见碎片时间的价值**，不是给你压力。
   - **晚间核心任务**：如果有多场直播（如周末下午+晚上），**“直播场次”可多选**，“直播时长合计”填总和。
   - **特殊时段工作**：只有熬夜播新活动时才填。**“熬夜后状态预警”很重要**，帮团队判断第二天是否需要给你减负。
   - **社群活跃度**：“发言频率”勾选即可，不用数具体条数；“群氛围感知”如实填，如果有火药味团队会关注。
   - **情绪与压力**：**核心模块**，真实最重要。委屈就写委屈，累就写累。
   - **希望谁介入**：可以填具体人名（哈哈/鲨鲨/不吃芹菜），也可以填“都可以”，团队会安排人响应。

3. **核心心态**：这个日志是**给你用的工具**，不是考核表。它的价值在于：让你所有时间段的付出都被看见，让团队知道该从哪里帮你。

---

#### 给团队成员的响应指南

**团队总览人（如哈哈）**
- 每日查看，重点关注：“整体状态”“压力源”“需要聊聊/求助”
- 特别注意：**“今日类型”为周末或特殊日时**，关注双场直播是否过累；**“熬夜后状态预警”为“有点飘”或“明天可能会废”时**，次日主动减负或关怀
- 若连续3天状态差，主动介入调整

**情绪支持人（如鲨鲨）**
- 重点关注：“情绪词”“需要聊聊”“熬夜后状态预警”
- 发现负面情绪或熬夜预警时主动私信：“看到日志了，今天是不是很累？想聊聊随时找我”
- 成为阿新的“安全出口”，不评判、只管听

**冲突应对人（如不吃芹菜）**
- 重点关注：“人际关系预警”“群内有火药味”“希望谁介入”中提及自己
- 发现需要怼人/调解的情况，第一时间接手：“这个你不用管了，我来”
- 处理后在群里简单同步结果，让阿新安心

**所有成员**
- 看到“希望______协助”中提及自己名字时，**24小时内响应并反馈**
- 严格保密，不得外传日志内容

### 五、附：模块设计逻辑

| 模块         | 设计目的                           |
| ---------- | ------------------------------ |
| **今日类型**   | 让团队一眼识别是工作日、周末还是特殊日，不同日子支持方式不同 |
| **白天碎片任务** | 让碎片时间的努力被看见，避免“白天好像啥也没干”的焦虑    |
| **晚间核心任务** | 支持多场次勾选，准确记录周末双段直播；跟踪月播100小时进度 |
| **特殊时段工作** | 专门记录凌晨新活动突击，配套“熬夜后状态预警”让团队提前关怀 |
| **社群活跃度**  | 勾选式记录，无需数条数；感知群氛围，预警异常         |
| **情绪与压力**  | 核心模块，让心理状态被看见，避免独自内耗           |
| **团队支援**   | 将“求助”正常化、流程化                   |
| **明日计划**   | 只定“最重要一件事”，聚焦核心，减轻压力           |
