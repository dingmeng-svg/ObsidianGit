# AH 纸笔打卡模板

> 来自《原子习惯》的极简打卡法——先画X，后数字。

---

## 模板一：单习惯墙贴月历

适用于：每天只追踪 1 个关键习惯（如晨练、阅读 20 分钟）

```
    2026 年 ___ 月 · [习惯名称] 打卡表
┌────┬────┬────┬────┬────┬────┬────┐
│ 一 │ 二 │ 三 │ 四 │ 五 │ 六 │ 日 │
├────┼────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │    │
│    │    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │    │
│    │    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │    │
│    │    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │    │
│    │    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │    │
│    │    │    │    │    │    │    │
└────┴────┴────┴────┴────┴────┴────┘
       本月连续最长：____ 天  本月完成率：____ / ____
```

**使用方式**：每天完成习惯后，在对应日期格子中画一个大大的 X。

## 模板二：多习惯月度打卡表

适用于：同时追踪 3-5 个习惯

```
    2026 年 ___ 月 · 多习惯打卡表
┌────┬────────┬────────┬────────┬────────┬────────┐
│日期│ 习惯1  │ 习惯2  │ 习惯3  │ 习惯4  │ 习惯5  │
├────┼────────┼────────┼────────┼────────┼────────┤
│ 1  │        │        │        │        │        │
│ 2  │        │        │        │        │        │
│... │        │        │        │        │        │
│ 30 │        │        │        │        │        │
│ 31 │        │        │        │        │        │
└────┴────────┴────────┴────────┴────────┴────────┘
```

**使用方式**：每天逐行打勾（✓），确保没有两个连续空格。

---

## 打印建议

- 使用**等宽字体**（Courier New / Consolas / 宋体）打印
- **横向打印**（Landscape），预留大格子空间
- **字号 20pt 以上**，确保画 X 时有足够的物理空间和满足感
- 每月打印一张，贴在最显眼的地方（冰箱/书桌/床头）
