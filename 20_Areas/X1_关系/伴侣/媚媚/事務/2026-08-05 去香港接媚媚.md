
### 🌅 上午：从深圳固戍出发，前往香港机场 (接机)

**核心思路**：上午从深圳出发，目标是在**下午1点半左右**抵达香港机场，预留充足时间接14:15落地的航班。

**【推荐方案】地铁 + 高铁 + 机场快线 (高效、时间可控)**

这套方案最稳妥，基本不受路面交通影响，适合需要精确把控时间的行程。

| 时间 | 步骤 | 详细说明 |
| :--- | :--- | :--- |
| **10:00** | 从固戍地铁站出发 | 乘坐**地铁1号线**（罗宝线，往罗湖方向）。 |
| **~10:45** | 抵达福田高铁站 | 在**前海湾站**换乘**地铁11号线**（往福田方向）。 |
| **11:15** | 乘坐高铁 | 乘坐**11:15至12:00之间**的班次，从**福田站**到**香港西九龙站**。高铁车程约14分钟，二等座票价约**68元**。建议提前用“铁路12306”APP买好票。 |
| **~11:30** | 抵达西九龙站，办理过关 | 下车后跟随人流，办理“一地两检”过关手续（先内地出境，后香港入境），使用**港澳通行证**。 |
| **~12:15** | 换乘机场快线 | 过关后，**不要出站**，跟随“**九龙站**”或“**机场快线**”指示牌，步行穿过“**圆方商场**”(Elements)，约15-20分钟到达机场快线**九龙站**。 |
| **~12:45** | 乘坐机场快线 | 在九龙站购买机场快线车票（单程约**115港币**），乘坐往“**博览馆**”方向的列车，约**10分钟一班**，车程约24分钟。 |

### 🌙 下午至晚上：从香港机场返回深圳福田口岸酒店

**核心思路**：接到媚媚后，从机场返回福田口岸附近的**福朋喜来登酒店**。

**【推荐方案】机场快线 + 港铁 (性价比高、时间可控)**

这套方案比跨境巴士便宜，且不用受限于巴士的班次时间，更适合行程结束后的悠闲节奏。

| 时间 (参考) | 步骤 | 详细说明 |
| :--- | :--- | :--- |

| **~15:20** | 换乘东涌线 | 在青衣站换乘**东涌线**（往香港方向），坐2站到**南昌站**。 |
| **~15:35** | 换乘屯马线 | 在南昌站换乘**屯马线**（往乌溪沙方向），坐3站到**红磡站**。 |
| **~15:50** | 换乘东铁线 | 在红磡站换乘**东铁线**，**务必乘坐“落马洲”方向**的列车（不是“罗湖”），坐到终点站。 |

> **备选方案**：如果希望更省力（比如行李较多），可以选择**跨境巴士**。在香港机场T1航站楼**L5层接机大堂A区M02柜台**（中旅巴士）购票，可直达**深港城市候机楼**（距离福田口岸200米），票价**150元/位**。但需注意末班车时间为**14:30**，可能赶不上。

### 📋 你的全天接机执行手册

**总目标**：上午从深圳固戍出发 → 下午1点半到香港机场接媚媚 → 傍晚带她回到福田口岸的酒店。

---

### ☀️ 上午出发段（去机场接人）

#### 第一步：坐地铁去福田高铁站
1.  从**固戍地铁站**进站，坐**1号线**。
2.  方向是**罗湖**，坐6站，在**前海湾**下车。
3.  下车后，在站内换乘**11号线**（注意看头顶指示牌，换乘很近）。
4.  坐**11号线**，方向**福田**，坐5站，在**福田站**下车。
5.  出地铁闸机，跟着 **“高铁”** 或 **“火车站”** 的指示牌走，进入福田高铁站的候车大厅。

#### 第二步：坐高铁去香港（关键一步）
1.  **票买好了吗？** 提前在“铁路12306”APP买好票，目的地是**香港西九龙**。买票用**身份证**。
2.  在候车大厅屏幕上，找到你车次的**检票口**。
3.  刷**身份证**进站台，上车。
4.  高铁开动，**14分钟**后到达**香港西九龙站**。

#### 第三步：在西九龙站过关 & 换乘机场快线（最容易懵的一段）
1.  **下车后，跟着人流走**，你会依次经过**内地出境**和**香港入境**两道关卡。拿出你的**港澳通行证**，按工作人员指引操作。（可能需要提前在微信“海关旅客指尖服务”小程序填好健康申报，截个图备用）
2.  **关键动作**：办完所有过关手续后，**不要出西九龙站**。你已经在站内了，现在要找去“九龙站”的路。
3.  抬起头，找写有 **“圆方”（Elements）** 或 **“机场快线”** 的指示牌。
4.  跟着指引，你会穿过一个**有顶棚的人行天桥**，直接走进一个叫“圆方”的大商场。
5.  在商场里，继续跟着 **“机场快线”** 的绿色标识走，就能到达**九龙站**的大厅。
6.  在九龙站，找到**机场快线**的闸机，刷**八达通**或用支付宝/微信的香港乘车码进站。如果没卡，就去客服中心买票。
7.  坐上往 **“博览馆”** 方向的列车，坐**24分钟**，终点就是**香港机场**。

#### 第四步：到达机场 & 接人
1.  下车后，你就在**T1航站楼**里了。
2.  跟着 **“抵港”** 或 **“到达”** 的牌子走，下到**接机大堂**。
3.  看大屏幕上，找到媚媚的航班号对应的**到达口**。
4.  在那个出口旁边等着就行，她出来第一眼就能看到你。

---

### 🌙 下午返程段（从机场回福田酒店）

#### 第五步：从机场坐港铁回深圳
1.  接到媚媚后，在机场站直接坐**机场快线**，坐**1站**到**青衣站**下车。
2.  在青衣站，换乘**东涌线**（往香港方向），坐**2站**到**南昌站**下车。
3.  在南昌站，换乘**屯马线**（往乌溪沙方向），坐**3站**到**红磡站**下车。
4.  **最关键的一步来了**：在红磡站，换乘**东铁线**。一定要看清楚月台上的显示屏，找**终点站是“落马洲”** 的那一趟列车上去！（注意：不是去“罗湖”的！）
5.  坐上东铁线，一直坐到终点站 **“落马洲”** 下车。

#### 第六步：过关 & 回酒店
1.  出地铁闸机后，你就到了福田口岸的香港一侧。跟着人流，办理**香港出境**和**内地入境**手续，回到深圳。
2.  从口岸大楼出来后，打开手机地图导航 **“福朋喜来登酒店”**。
3.  步行过去，大约**5-10分钟**就到了。

### 💎 给你最后的核心提醒
*   **证件三件套**：**身份证**（坐高铁用）、**港澳通行证**（过关用）、**手机**（买票、导航、联系媚媚）。
*   **支付**：在香港坐地铁，强烈建议两人都用**八达通**，或者在支付宝/微信上开通“香港乘车码”，刷码进站最方便。
*   **别担心**：香港的指示牌非常清晰，全程都有中英文，而且车站和机场的工作人员都会说普通话，不确定就问，不会走丢的。
