## 一、什么是富贵包？

富贵包是指**第7颈椎与第1胸椎交界处**出现的凸起包块。它并非真正的"富贵"，而是由**长期不良姿势**造成的——低头看手机、含胸驼背、伏案工作，导致颈胸交界处的肌肉紧张、痉挛、增厚，脂肪和软组织在此堆积。

> **富贵包的核心成因是肌肉力量失衡**：胸肌、斜方肌上束**紧张缩短**，颈深屈肌、菱形肌、斜方肌中下束**薄弱无力**，椎体被迫代偿性前倾。康复原则是：**先松解紧张的肌肉，再强化薄弱的肌肉**。

**自测方法**：靠墙站立，双脚打开与髋同宽，臀部、肩胛骨贴墙，看**后脑勺能否贴到墙**。如果贴不到且颈部有明显凸起，说明存在富贵包或头前倾体态。

## 二、康复原则与周期

| 原则 | 说明 |
|:---|:---|
| **无痛训练** | 全程以轻微酸胀为宜，出现锐痛/刺痛/麻木立即停止 |
| **先松后练** | 先拉伸放松紧张肌肉，再强化薄弱肌肉 |
| **循序渐进** | W1-W2 专注动作质量，W3-W4 逐步增加组数 |
| **日常维持** | 每天 8 小时的日常姿势 > 30 分钟的训练 |

**推荐周期**：连续训练 **4-6 周**为一个疗程。体态改善后转为每周 3 次维持训练。

**频率**：每周 6 天，每天 1 组。

## 五、训练日执行方案（25-30 分钟）

> **训练结构**：热身放松（8-10 分钟）→ 矫正训练（12-15 分钟）→ 放松整合（3-5 分钟）

### 第一阶段：放松紧张肌肉（8-10 分钟）

**目标**：松解胸肌、斜方肌上束、枕下肌群。

#### ① 胸肌门框拉伸

| 项目 | 内容 |
|:---|:---|
| **时长** | 每侧 30 秒 × 3 次，组间休息 10 秒 |
| **准备姿势** | 找一门框，双脚前后站立，前脚屈膝，后脚伸直，与门框呈 30° 夹角 |
| **① 手臂贴门框** | 手臂弯曲 90°，前臂贴门框，上臂与地面平行 |
| **② 身体前倾** | 缓慢向前送髋，身体整体前倾，感受胸肌拉伸 |
| **③ 保持呼吸** | 保持 30 秒，不憋气 |
| **④ 换边** | 转身换另一侧手臂 |
| ✅ **感觉** | 胸前侧有拉开感。肩膀刺痛则降低幅度 |

#### ② 上斜方肌拉伸

| 项目 | 内容 |
|:---|:---|
| **时长** | 每侧 30 秒 × 2 次 |
| **准备姿势** | 坐姿，背挺直，肩膀放松 |
| **① 手扶头部** | 右手放在头顶，轻轻将头向右侧拉，左耳靠近右肩 |
| **② 肩膀下沉** | 左侧肩膀用力向下沉，感受左侧脖子侧面到肩膀的牵拉 |
| **③ 保持** | 保持 30 秒，自然呼吸 |
| **④ 换边** | 左手拉头向左侧，右侧肩膀下沉 |
| ✅ **感觉** | 脖子侧面到大臂上端有牵拉感 |

#### ③ 枕下肌群点头放松

| 项目 | 内容 |
|:---|:---|
| **时长** | 20 次，速度 2 秒/次 |
| **准备姿势** | 仰卧，双眼平视天花板，颈部完全放松 |
| **① 缓慢点头** | 头部缓慢做"点头"动作，幅度 1-2cm |
| **② 感受拉伸** | 感受后脑勺下方的枕下肌群被拉伸 |
| **③ 保持呼吸** | 不要憋气，不要用力抬头 |
| ✅ **感觉** | 后脑勺下方有轻微拉伸感。如果头晕→停止 |

### 第二阶段：矫正训练（12-15 分钟）

**目标**：强化薄弱肌肉——颈深屈肌、菱形肌、中下斜方肌。

#### ④ 下颌回收训练（收下巴）

| 项目 | 内容 |
|:---|:---|
| **组数** | 2 组 × 15 次，每次保持 5 秒，组间休息 20 秒 |
| **准备姿势** | 坐姿或站姿，腰背挺直，双肩放松 |
| **① 水平后收** | 下巴水平向后移动，像挤出"双下巴"，不要低头或仰头 |
| **② 指尖辅助** | 可用食指轻轻辅助推下巴向后 |
| **③ 保持 5 秒** | 感受脖子前侧深层肌肉发力 |
| **④ 缓慢还原** | 不要突然放松 |
| ✅ **感觉** | 脖子前侧深层有发力感。脖子后侧酸痛→动作可能不标准 |

#### ⑤ 上背部激活（沉肩夹背）

| 项目 | 内容 |
|:---|:---|
| **组数** | 3 组 × 10 次，每次保持 10-30 秒 |
| **准备姿势** | 坐姿或站姿，上身直立，手臂放松下垂 |
| **① 肩胛骨后缩** | 想象肩胛骨向脊柱中间"夹拢"，像夹着一支笔 |
| **② 保持** | 保持 10-30 秒，感受上背部肌肉发力 |
| **③ 放松** | 缓慢放松回到起始位置 |
| ✅ **感觉** | 肩胛骨之间有收缩感。如果耸肩→放松肩膀再试 |

#### ⑥ 弹力带抗阻训练（加强版收下巴）

| 项目 | 内容 |
|:---|:---|
| **组数** | 3 组 × 10 次，每次保持 5-10 秒 |
| **准备姿势** | 坐姿，脊柱平直，弹力带中间置于头枕部，双手握两端 |
| **① 微收下颌** | 下巴水平向后运动 |
| **② 对抗弹力** | 双手向前拉弹力带，头部保持静止对抗 |
| **③ 保持 5-10 秒** | 用最大力量的 50%-60% |
| **④ 缓慢还原** | 休息 3-5 秒 |
| ✅ **感觉** | 脖子后侧和上背部有发力感。无弹力带→徒手做收下巴 |

#### ⑦ Y-T-W 伸展（强化上背部）

| 项目 | 内容 |
|:---|:---|
| **组数** | Y / T / W 各 2 组 × 10 次 |
| **准备姿势** | 俯身约 45°（趴在桌子边缘或站立俯身），背挺直 |

**Y 字型**：双臂上举呈 Y 字，拇指朝上，用后背发力抬起  
**T 字型**：双臂平举呈 T 字，拇指朝上，肩胛骨后缩抬起  
**W 字型**：屈肘呈 W 字，手肘向后夹，肩胛骨完全收紧

✅ **感觉**：上背部（肩胛骨周围）发力。手臂酸胀→用手臂代偿了，先做肩胛后缩再抬手

### 第三阶段：放松整合（3-5 分钟）

#### ⑧ 猫牛式

| 项目 | 内容 |
|:---|:---|
| **时长** | 10 次（来回交替为 1 次） |
| **准备姿势** | 四足跪姿，手在肩正下方，膝在髋正下方 |
| **① 猫式（拱背）** | 呼气，慢慢拱起上背部，头自然下垂 |
| **② 牛式（塌腰）** | 吸气，塌腰，抬头看向斜上方 |
| **③ 交替** | 配合呼吸，慢慢做 |

#### ⑨ 膈肌呼吸

| 项目 | 内容 |
|:---|:---|
| **时长** | 2 分钟 |
| **准备姿势** | 仰卧，双膝屈起，手放腹部 |
| **① 吸气鼓腹** | 鼻子吸气，腹部鼓起，肩膀不动 |
| **② 呼气收腹** | 嘴巴呼气，腹部下落 |
| ✅ **感觉** | 腹部起伏。如果肩膀抬起→胸式呼吸，把注意力放回腹部 |

## ⚠️ 重要提示

1. **富贵包的形成是长期姿势不良的结果**，消除也需要时间——坚持 4-6 周才能看到明显改善。
2. **康复训练不能替代日常姿势改善**——每天 8 小时的错误姿势远大于 30 分钟的训练效果。
3. 若训练中出现**锐痛、刺痛、麻木或放射痛**，立即停止该动作。
4. 本计划仅供参考，如有颈椎病史或严重不适，请先咨询康复科医生。
