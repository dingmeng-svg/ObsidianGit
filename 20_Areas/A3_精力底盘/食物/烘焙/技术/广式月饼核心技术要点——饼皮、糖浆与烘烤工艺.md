# 广式月饼核心技术要点——饼皮、糖浆与烘烤工艺

> 烘焙达人“蛮好（高比克）”的广式月饼实操经验分享，覆盖从核心糖浆制作、饼皮标准骨架、面粉选择与成本分析、手感判别到烘烤工艺的全流程技术要点。这是广式月饼制作的底层逻辑汇总，掌握了这些，面对任何配方都能游刃有余。归档备查。

---

## 一、核心：琥珀红糖浆的制作

琥珀红糖浆是让月饼饼皮色泽红润的关键，效果远超市售普通糖浆。其中的秘诀在于**枧水**的催化作用。

**配方**：
- 糖浆（任意）：1000克
- 枧水（任意）：5克
- 清水：若干

**操作步骤**：
1. 将糖浆倒入不锈钢锅，连锅一起称重，记住总重量。
2. 加入少量清水，开火煮开。
3. 加入枧水，继续煮。你会发现加入枧水的地方马上开始变红，随后搅拌均匀。
4. 煮一会儿后连锅称重，若重量低了就加点水，继续煮。
5. 直到煮出非常明显、漂亮的**琥珀红色**后，调节好最终重量（进去多少糖浆，煮完还要剩多少糖浆），关火。这个过程很快。

> 核心要点：枧水是让糖浆呈现红润色泽的关键催化剂。

## 二、饼皮的标准骨架与配方演变

几乎所有广式月饼配方都围绕一个基础骨架展开，万变不离其宗。

**广式月饼饼皮标准骨架**：
- 面粉：100%
- 糖浆：70%
- 花生油：25%
- 枧水：2%

掌握了这个黄金比例，就掌握了所有广式月饼皮的基础。以下是基于标准骨架的各家配方演变汇总，以及它们与基础配方的数值对比。

### 配方演变集锦

| 配方来源 | 面粉 (基准100) | 糖浆 (基准70) | 枧水 (基准2) | 花生油 (基准25) | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **基础骨架** | 100 | 70 | 2 | 25 | 黄金标准 |
| **1.5倍应用配方** | 103 | 66 | 3 | 28 | 低粉155, 糖浆99, 枧水4.5, 油42 |
| **小悦悦 原味皮** | 与1.5倍配方一致 | | | | 低粉155, 糖浆99, 枧水4.5, 油42 |
| **小悦悦 黑米皮** | 低粉140+黑米粉21 | 94 | 4.5 | 40 | 针对黑米粉吸水性调整 |

| **彩文** | 与茉 高低配 C 类似 | 94 | 1-2 | 32 | 放过夜使用（冰箱保鲜），12个量 |

## 三、面粉选择与成本分析

**推荐面粉**：河套牌雪花粉。做月饼皮超级好吃，口感软糯，醒皮时间只需30分钟。

虽然单价较贵（约10元/斤），但从成本和收益角度分析，其价值远超价格。

**单个月饼皮成本对比（以100克面粉为基础配方）**：

| 成本项 | 计算过程 | 金额 |
|:---|:---|:---|
| 便宜面粉 | 3元/500g | 0.6元 |
| 贵面粉（河套） | 10元/500g | 2.0元 |
| 糖浆（70g） | 15元/500g | 2.1元 |
| 花生油（25g） | 20元/500g | 1.0元 |
| **配方总重** | 100+70+25+2=197g | — |

一份配方约可做 6.5 个月饼皮（每个30g皮+45g馅=75g月饼）。

- 使用便宜面粉的单个饼皮成本：0.57元
- 使用贵面粉（河套）的单个饼皮成本：0.78元

**结论**：一个饼皮只贵约两毛钱，但换来了极佳的操作性、极短的醒皮时间和出众的口感，非常划算。

## 四、标准手感判别

### 基准配方一（金龙鱼麦芯粉）
- 金龙鱼麦芯粉：100
- 枧水：2
- 琥珀糖浆：70
- 花生油：25
- 醒发时间：1.5-2小时

### 基准配方二（河套雪花粉）
- 河套雪花粉：100
- 枧水：2.5
- 琥珀糖浆：70
- 花生油：28
- 醒发时间：30分钟

**手感修正**：
- 醒好后饼皮**太软**：加少量面粉揉匀，直到软硬合适。
- 醒好后饼皮**太干**：加少量油揉匀，直到软硬合适。

> 记住这两种粉的手感，以后做任何配方都以此为准。

## 五、馅料的选择与骨架原理

- **不建议新手自己炒馅**：先买成品馅料，把基本烤制弄懂。不合格的馅料（太软、太水）会造成百分百翻车。
- **纯单一馅料（如纯豆沙）**：建议只做50克的小月饼，不要做75克以上的。因为纯馅料缺乏“骨架”，做大月饼容易**泄脚、鼓腰**。
- **坚果、蛋黄是天然骨架**：可以支撑起75克甚至更大的月饼。做50克小月饼时，可以做纯馅料不带蛋黄。
- **后期加工**：确认合格馅料的状态后，可以自己尝试加工。

## 六、烘烤工艺

### 高温定型的意义

月饼进炉后的前几分钟，必须有足够的热能让饼皮表面迅速收干定型。如果温度温吞，糖浆微融时饼皮开始下垂，就会形成**泄脚**。定型预热一定要提高，要预先把开门进盘的热量损失考虑进去。

### 烘烤时间参考（以75克为例）
- 定型：约8分钟
- 烘烤：约12分钟

### 成熟判断
- 在馅料正常的情况下，高温区域的**细裂纹**出现，就要当心月饼快熟了。
- 合格成熟的底部：无湿底，无油斑。若底部不熟，等月饼温度微降后，塞回烤箱加时。

### 喷雾与刷蛋液

- **喷雾**：第一次进炉时用**雾化瓶**喷，润一下即可（非喷水），目的是防止表皮被高温烤裂。定型的是周围，上下后期会自然熟成。
- **刷蛋液**：蛋液配方为 **1个蛋黄 + 1/4个蛋白 + 2滴油 + 20克清水**。油用筷子沾，多了会失败。**必须等月饼略微降温再操作，每次薄刷**，可以多次。厚刷会形成蛋液疤痕，适得其反。想要表面油亮，需要刷两次：第一次刷完入炉烤几分钟，拿出来薄刷第二次再入炉烤。

**标准烘烤流程**：
```
喷雾 → 8分钟定型 → 出炉薄刷蛋液 → 8分钟烘烤 → 出炉薄刷蛋液 → 4分钟二烤
```
