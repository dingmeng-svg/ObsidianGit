# Collector

> **定位**：全系统唯一的「行」的入口。收录一切行为念想——待办、闪念、习惯、输出——全部倒进来。然后排序、筛选、分配到每日行动中。

## 核心铁律

1. **无过滤录入**：所有念头不经筛选直接丢入。超过两分钟才能完成的事项，先记下来再分配。
2. **只存行为意图，不存知识内容**：任何可变成笔记、知识点、素材的内容，禁止进入此处，必须进 `_raw/`。
3. **捕获期只增不删，分拣期才可移出**：日常只管追加，整理、归档、分配全部交给每日/每周分拣流程。分拣时将条目剪切至对应落点，物理移出即代表处理完毕。
4. **唯一中转站**：手机、备忘录等外部念头，统一通过手机备忘录作为唯一临时中转载体。每日打开 Vault 第一件事，将外部中转全部批量录入此处，清空外部缓冲区。外部中转内容不长期留存，仅作为跨设备临时过渡。

## 极简录入格式

统一使用单字母前缀 + 内容 + 可选场景与时效：

```
- [ ] [前缀] 内容 @场景 | 时效备注
```

**前缀定义**：

| 前缀 | 含义 | 示例 |
|:---|:---|:---|
| `[T]` | 待办任务 | `- [ ] [T] 整理附件规范文档 @电脑 \| 本周内完成` |
| `[N]` | 闪念灵感 | `- [ ] [N] 知行分离的新比喻 @任意` |
| `[H]` | 习惯相关 | `- [ ] [H] 每日早睡23点前关机 @居家` |
| `[Q]` | 读写队列 | `- [ ] [Q] 看完《卡片笔记写作法》第三章 @手机 \| 本周` |
| `[W]` | 等待跟进 | `- [ ] [W] 等腾讯云密钥回执 @任意 \| 持续跟进` |

`@场景` 和 `| 时效备注` 均为可选辅助信息，不纳入正式标签体系。

## 分拣速查

```
[T] 任务 → Bullet Journal 日记 / 项目待办 / Incubator
[N] 闪念灵感 → 剪切至 00_Inbox/_raw 作为独立文件
[H] 习惯想法 → 习惯孵化池 / 阻断器 / 月度调整
[W] 等待事项 → 周复盘专项跟进
[Q] 读写队列 → 批量阅读/写作排期
两分钟小事：分拣第一步直接当场完成，不进入四象限排序
```

## 分流通道

| 前缀 | 分流目标 | Agent 转换标签 | 备注 |
|:---|:---|:---|:---|
| `[T]` | Bullet Journal 日记 / 项目主文档 / Incubator | `待办录入` | 含 `等待跟进` 子类 |
| `[N]` | `00_Inbox/_raw/` 独立文件 | `闪念录入` | 触发 Ingest 编译 |
| `[H]` | `Habit Design Reference` 对应区块 | `习惯录入` | 按内容归入孵化池/阻断器/月度调整 |
| `[Q]` | Bullet Journal / Incubator | `读写队列` | 待读/待看/待写 |
| `[W]` | Bullet Journal 今日跟进区 | `等待跟进` | 外部依赖事项 |

**Agent 动作**：在分拣阶段，将上述前缀转换为符合总纲规范的扁平标签，写入目标文件的 YAML 头部。

## 分拣四象限规则

- **重要紧急** → 今日 Bullet Journal 立刻执行
- **重要不紧急** → 排入日程或项目计划
- **紧急不重要** → 批量代办或委托
- **不紧急不重要** → 直接删除

**项目任务判定**：
- 单一步骤、无前置依赖 → 归入 Bullet Journal 当日/近期日记
- 多轮操作、存在前置环节、有明确目标产出 → 同步写入对应项目主文档「下一步行动」区块，仅将当日执行步骤放入 Bullet Journal
- 长期多阶段规划 → 移入 Incubator，月度复盘评估启动时机

**等待事项 `[W]` 跟进规则**：
- 周复盘强制逐条核对 `[W]` 条目状态
- 超过 14 天无反馈的等待事项，单独标记，评估是否主动催促或搁置删除
- 外部回复完成后，勾选条目并移出收纳箱，同步归档至对应任务/项目文档

## 系统约束

**Hermes Agent 权限**：
- **仅可执行**：每日扫描并统计未处理条目数；超过阈值时在对话中主动提醒；周复盘时输出清空进度报告
- **禁止执行**：自动分拣、自动分流、自动删除、自动归档。所有行动决策权在人类手中

**Agent 监控策略（双维触发）**：
- 条目 > 50 条 → 提醒分拣（防过载）
- 存在 > 7 天未处理的 `[T]` 待办 → 提醒复核（防腐化）
- 周复盘日 → 强制输出收纳箱清空进度报告（保闭环）

**Agent 统计基准**：仅统计当前文件中未勾选的复选框（`- [ ]`）的行数。物理移出或划掉即不再纳入统计。

**Ingest 豁免规则**：本文件永久豁免自动 Ingest 编译。Agent 的 Ingest 扫描逻辑在遍历 `00_Inbox/` 时必须跳过此文件。

**每周清空验收标准**：
1. 所有 `[N]` 闪念类条目已移入 `_raw/`
2. 所有 `[H]` 习惯类条目已归档至习惯设计参考对应模块
3. 所有 `[T]` 待办类事项已分配至当日 Bullet Journal、对应项目或 Incubator
4. 最多残留 5 条 `[W]` 等待类条目，超过阈值必须完成全部分拣
