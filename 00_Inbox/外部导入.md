# 📥 外部导入总览

> 外部导入文件暂存区。本目录用于存放从外部剪藏、导出、迁移的内容。
>
> 所有外部导入内容须经人工审核判断后，发出指令由 Hermes Agent 归档或提炼。
>
> 需要系统自动 Ingest 的走 `_raw/`，其余保留在本目录人工处理。
