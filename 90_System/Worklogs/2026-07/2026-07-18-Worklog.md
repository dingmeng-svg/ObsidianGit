## 工程开发 & 踩坑记录

### 踩坑 1：`rgba()` 导致热力图渲染引擎挂掉

- **问题**：`renderHeatmapCalendar` 的 `colors` 参数传 `rgba()` 数组 → 格子全空白
- **根因**：插件解析 `rgba()` 时渲染引擎挂掉
- **解法**：必须用 Hex 数组或引用插件配色名

### 踩坑 2：CSS 无法覆盖进度条颜色

- **问题**：想用 CSS `!important` 覆盖进度条背景色
- **根因**：进度条是 DataviewJS 内联 `div style` 渲染，CSS 选择器优先级不够
- **解法**：直接修改 JS 源码中的颜色值

### 踩坑 3：```heatmap` 代码块不可用

- **问题**：尝试用原生 ````heatmap` 代码块替代 DataviewJS
- **根因**：插件 v0.7.1 未注册代码块处理器，`onload()` 只挂载了 `window.renderHeatmapCalendar`
- **解法**：保持 DataviewJS 方案

### 踩坑 4：`renderGreenBar` 跨代码块不可用

- **问题**：函数定义在第一个代码块，后面代码块报 `ReferenceError`
- **根因**：DataviewJS 每个代码块独立作用域
- **解法**：每个代码块各自定义一次

### 踩坑 5：热力图月份标签截断

- **问题**：`Jan` 显示为 `Ja`，`Mar` 显示为 `M`
- **根因**：容器 `min-width` 不足，字符被截断
- **解法**：CSS `min-width:0` + `white-space:nowrap`

### 踩坑 6：图片粘贴导致 GUI 卡死

- **问题**：消息附件直接粘贴图片 → Hermes GUI 线程 GIL 卡死
- **根因**：`image_input_mode: auto` 时，有 `auxiliary.vision` 配置 → 走文本预处理 → 同步阻塞 GUI
- **解法**：改为 `image_input_mode: native`，跳过预处理

### 踩坑 7：User Profile 溢出导致性能下降

- **问题**：memory 满 99%（1375/1375 chars），操作变慢
- **根因**：冗余大条目未清理
- **解法**：删除 520 字冗余条目，清理至 66%
