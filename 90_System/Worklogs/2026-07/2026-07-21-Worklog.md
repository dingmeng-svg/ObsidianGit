# 2026-07-21 Worklog

## Hermes Agent 桌面端完整故障排查与解决

### 背景

将 Hermes Agent 从 0.18 更新到 0.19 版本并构建桌面端。操作系统 Windows 11，用户名含中文（`丁萌`），Node.js v22.22.3。

### 问题与解决

| 问题 | 严重程度 | 解决方式 |
|:---|:---:|:---|
| P1: PowerShell npm 脚本安全策略限制 | 阻塞 | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| P2: npm config 不支持 electron_mirror | 阻塞 | 改用 `$env:ELECTRON_MIRROR` 环境变量 |
| P3: Git 网络错误 | 中度 | 多次重试后成功 |
| P4: node-pty 原生模块被 Windows 拒绝访问 | 严重阻塞 | 跳过该模块（从 build 脚本移除） |
| P5: 修改构建脚本后 shebang 被破坏 | 中度 | 恢复备份文件，改用修改 package.json |
| **P6: electron-builder 因中文路径崩溃** | **严重阻塞** | **项目迁移到纯英文路径 `C:\hermes-agent`** |

### 核心发现：中文用户名路径是根因

`electron-builder` 在处理含非 ASCII 字符（中文）的绝对路径时，底层 C++ 模块（UCRT）发生内存栈错误（0xC0000409），这是 electron-builder 官方已知 Bug（#6232）。

`hermes` CLI 命令的路径解析依赖自身安装位置，在中文用户名环境下无法通过简单移动目录绕过。最终方案：**项目迁移到纯英文路径 + 直接使用 `npm run pack` 而非 `hermes` CLI 命令**。

### 最终路径

| 类型 | 路径 |
|:---|:---|
| 项目根目录 | `C:\hermes-agent` |
| 桌面端可执行文件 | `C:\hermes-agent\apps\desktop\release\win-unpacked\Hermes.exe` |
| 配置文件目录 | `C:\Users\丁萌\AppData\Local\hermes` |
| 原始路径（废弃） | `C:\Users\丁萌\AppData\Local\hermes\hermes-agent` |

|:---|:---:|
