# Worklog 2026-08-13

## Git 备份全链路修复

### 问题诊断
- 原因：`github.com` DNS 解析到 `20.205.243.166`（受限 IP），443 TCP 被运营商深度包检测干扰
- 现象：`git push` 21 秒超时（`Could not connect`），但 curl `--resolve` 到可用 IP 时秒连 200
- 关键证据：git `GIT_CURL_VERBOSE=1` 显示 TLS 握手完成但证书校验失败（IP 与 SAN 不匹配）

### 解决方案
1. **创建 failover 脚本** `git-push-failover.sh`：逐个尝试 5 个 GitHub 官方可用 IP
   - 主 IP：`140.82.114.3`（实测最稳）
   - 对每个 IP 临时关闭 sslVerify（IP 证书无法匹配）+ 设 `Host: github.com` 头
   - 提取 remote URL 中的凭据，组装 IP URL

2. **改造 backup 脚本** `obsidian-git-backup.sh`：push 段调用 failover 脚本
   - failover 脚本不存在时 fallback 到直接 IP push

3. **cron 改造**：从 LLM 模式（`no_agent=false`，被 provider 漂移 guard 拦截）改为 `no_agent=True` + `script: obsidian-git-backup.sh`
