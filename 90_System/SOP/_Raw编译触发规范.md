# _Raw 编译触发规范

> **定位**：帮助人类判断何时应当将 `00_Inbox/_raw/` 中的素材提交给 Hermes 进行 Ingest 编译。
> **核心原则**：编译主动权完全在人类。以下条件不是强制规则，而是决策启发式——帮助你在面对一堆素材时，快速判断哪个值得优先处理。

---

## 一、编译触发启发式

当以下任一条件满足时，建议优先编译该素材：

### 1. 重复引用触发

同一素材的内容、概念或观点在以下位置被提及 ≥ 3 次：
- 日记中的子弹记录
- 周/月复盘中的"学到了什么"
- 与其他人的讨论记录

→ **信号**：这个素材已经在你的思考和行动中反复出现，值得提炼为永久知识。

### 2. 季度确认触发

在 Quarterly Review 中，该素材被明确标记为"对当下核心目标有重要参考价值"或"解答了长期困惑的问题"。

→ **信号**：这个素材与你的战略方向对齐，提炼后可直接支持决策。

### 3. 项目需求触发

你正在推进的活跃项目直接需要该素材中的概念、方法论或数据。

→ **信号**：这个素材有即时实用价值，编译后能直接转化为产出。

### 4. 闪念升级触发

日记中的闪念（你自己的想法，非外部素材）围绕同一主题出现 ≥ 3 次。

→ **信号**：这不是外部素材的编译，而是你自己的思考已经足够成熟，可以写一篇原创原子笔记了。此时以你的闪念为主，_raw 素材为引用补充。

---

## 二、编译反触发的判断

以下情况建议**暂不编译**：

- 素材收藏后从未在日记中被提及 → 可能是收藏冲动，非真实知识需求
- 素材观点与当前所有活跃项目无关，且短期内不会被用到 → 保持收藏，等待未来触发
- 素材内容你已经在其他原子笔记中充分覆盖 → 冗余，可直接删除 Raw 文件

---

## 三、AI 主动提醒机制

即使你未手动触发编译，Hermes 的 Lint 健康检查也会在以下情况主动提醒：

- Raw 素材被 ≥ 3 条笔记引用 → 提醒"建议编译"
- Raw 素材闲置超过 60 天未被任何笔记引用 → 提醒"建议清理"

**注意**：AI 仅做提醒，不主动执行编译。是否编译始终由你决定。

---

## 四、编译执行

决定编译后，向 Hermes 发送指令：
> "请编译 `00_Inbox/_raw/[文件名]`"

Hermes 将按 `HERMES.md` §三 Ingest 编译规则自动执行：
1. 生成结构化摘要 → `33_Summaries/`
2. 提取概念 → 查重后新建或追加 → `31_Atomic_Notes/`
3. 建立双向链接 → 更新 MOC
4. 被动推荐 → 从 Archive 检索相关旧笔记
