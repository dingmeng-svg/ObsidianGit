## 五、关键避坑清单（已踩过的坑，云端不要重复踩）

### DataviewJS 陷阱

```
❌ genDate.startOf('isoWeek') — Dataview 内置 luxon 不支持 isoWeek 单位
✅ genDate.startOf('week') — 'week' 默认周一为一周起始
```

### 热力图陷阱

```
❌ renderHeatmapCalendar(this.container, { colors: "rgba(...)", entries }) — rgba 导致渲染引擎挂掉
❌ 原生 ```heatmap 代码块 — 插件 v0.7.1 未注册代码块处理器
✅ renderHeatmapCalendar(this.container, { colors: "default", entries }) — 引用插件预设配色组名
```

### Collector 规则

```
Collector.md 豁免 Ingest 编译（不被当作知识素材提炼原子笔记）
Collector.md 不豁免 [T] 任务分流扫描和 [H] 习惯扫描（正常功能）
```

### 文件操作安全

```
❌ rm -rf / rm -f / find -delete — 绝对禁止
✅ mv / cp 指定文件
❌ write_file 处理 >300KB 文件 — 易超时失败
✅ terminal + Python 脚本处理大文件
```
