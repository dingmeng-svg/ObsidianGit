# 云端分身路径校准指令

> **目的**：通知云端 Hermes Agent（腾讯云服务器 24/7）校准股市数据播报的落盘路径。
> 本文件由本地 Agent 生成，通过 Syncthing 同步到云端。云端 Agent 启动时读取此文件并执行修正。

## 一、路径规范

**项目结构**：`10_Projects/11_工作/01_操盘手骑士/`

| 编号 | 目录 | 用途 |
|:---:|:-----|:-----|
| 01 | 规划 | 项目规划、路线图 |
| 02 | 执行 | 执行记录、任务追踪 |
| 03 | 运营 | 日常运营、数据 |
| 04 | 资料 | 参考资料、调研素材 |
| **05** | **产出** | **所有交付物、成品文件** |

**标准产出路径**：
```
10_Projects/11_工作/01_操盘手骑士/05_产出/股市数据播报/2026/<M月>/每日复盘直播稿/YYYY-MM-DD-A股复盘直播稿.md
```

## 二、云端需要修正的问题

### 问题 1：写到了 04_产出

当前 SOP V4.1 已修正为 `05_产出`。云端 cron 如果仍按旧缓存执行，会写错位置。

**修正**：cron prompt 中的 `04_产出` → `05_产出`

### 问题 2：写到了 10_Projects_Things I'm actively working on/

这个长文件名目录是错误路径，**永远不要写入**。所有产出文件只能放在 `10_Projects/11_工作/01_操盘手骑士/05_产出/` 下。

### 问题 3：日期目录格式不一致

有时用 `2026/7月/`，有时用 `7月/`（少了年份目录）。

**修正**：统一使用 `2026/<M月>/` 格式（如 `2026/7月/`）

## 三、云端 cron 配置修正

### 每日复盘 cron

```
cronjob action="update" job_id="<job_id>"
prompt="...（完整 prompt）...
【文件落盘】write_file 存入：10_Projects/11_工作/01_操盘手骑士/05_产出/股市数据播报/2026/<M月>/每日复盘直播稿/YYYY-MM-DD-A股复盘直播稿.md"
```

### 休市审计 cron

同上，落盘路径保持一致。

## 四、需要云端执行的操作

1. 读取本文件，理解路径规范
2. 更新 cron job 的 prompt 中的落盘路径
3. 检查 `04_产出/` 和 `10_Projects_Things/` 下是否有旧文件，如有则迁移到 `05_产出/`
4. 清理上述错误路径下的空目录
5. 在 Worklog 中记录校准结果

## 五、路径校验

云端 Agent 每次执行复盘后，应检查：
- 文件是否写在了 `05_产出/股市数据播报/2026/<M月>/每日复盘直播稿/` 下
- 文件名格式是否为 `YYYY-MM-DD-A股复盘直播稿.md`
- 如果发现写到了错误路径，记录并修正
