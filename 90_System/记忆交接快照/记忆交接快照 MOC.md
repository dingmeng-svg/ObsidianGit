## 规范说明

### 位置规则

- 快照文件存放在 `90_System/记忆交接快照/YYYY-MM/` 子目录
- 文件名格式：`YYYY-MM-DD-Hermes记忆交接快照.md`
- 云端校准指令（如 `云端分身全面校准指令v2.0.md`）属于独立文件，与快照同级存放但不计入快照序列

### 快照生成时机

- 每次重大系统变更完成后生成
- 云端 Agent 启动时读取最新快照
- 本地 Agent 在完成跨节点影响的操作后更新

### 双链规范

每个快照的 related 字段应包含：
1. `[[记忆交接快照 MOC]]`
2. 前一天的快照链接
3. 当天的 Worklog 链接
