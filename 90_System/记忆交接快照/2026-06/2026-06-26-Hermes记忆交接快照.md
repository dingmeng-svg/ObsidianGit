## 二、YAML Frontmatter 规范

### 归档文件
- 简单归档文件只用 `title` / `date` / `status: archived` / `tags` 四字段
- **读书笔记/总结类档案文件**可保留 `author` / `type` / `aliases` / `related` / `project` 等字段，不强制四字段裁剪

### 原子笔记
- 必须含 `title` / `date` / `status: finished` / `tags` / `source`（有来源时）
- `related` 中的 wikilink 必须带 `（出处）` 后缀
- 正文不可残留 `## 关联笔记` 或 `## 它和什么相关` 区——链接移入 YAML `related:`
- 位置表一律用 `知→行→进化` 箭头，不可写 `知行进化`

### 铁律
1. `---` 独立成行不黏内容
2. tags 不用 `#` 前缀
3. 双链引用用引号包列表格式
4. 原子笔记命名：`概念名（出处）.md`
5. 修改后 `yaml.safe_load()` 校验
6. 校对一次性做完不回头补

## 四、7 条 A 股复盘矫正指令

1. **零容忍**：不知道昨日的值就不提"较昨日"——宁可少写不能编造
2. **每笔数据标注来源**：东方财富第一信源，不通则换新浪/证券时报/财联社
3. **板块数据**：必须同时展示金额+涨幅%，净流出但板块涨则单独分析
4. **北向资金**：精确到亿并标注出处，严禁"约XX亿"；2014年起已改为季度披露持仓，不得写"API受限"
5. **中微观观察**：至少1条盘面细节（如中大市值20cm涨停、次日溢价）
6. **宏观看两层**：金融新闻延伸至对资金流的实际影响，不满足于表面利好/利空
7. **有据对比**：提"较昨日"必须打开前一日复盘文件读取精确值
