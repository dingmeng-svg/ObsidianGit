3. ✅ YAML `related` 缺后缀 → 补全
4. ✅ YAML `source` 字段 → 链回源文件
5. ✅ 正文残留关联笔记区 → 移入 YAML `related:` 后删除
6. ✅ `知行进化` 无箭头 → 修正为 `知→行→进化`
7. ✅ 标签是否在 21 种内
8. ✅ 空壳存根文件 → 删除
