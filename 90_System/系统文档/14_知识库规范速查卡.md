## 一、核心规则速查

### 标签体系

| 规则 | 内容 |
|:-----|:------|
| **TAG-01** | 领域标签总量 ≤ 20 种。功能性标签不计入上限 |
| **TAG-02** | 细分标签与父标签互斥，打了细分标签不打父标签 |
| **当前实际** | 领域标签 9 个，功能性标签 7 个。剩余扩展位 ≤ 11 个 |
| **双标签例外** | 仅限两个平级领域交叉时使用，占比 < 5%。功能性标签+领域标签不计入 |

### 标签字典

**核心标签（9 个）**：`个人成长` `工作` `生活` `关系` `财务` `技术` `心理学` `知识管理` `语言`

**功能性标签（7 个）**：`国际政治` `科学` `系统文档` `归档` `素材` `日记` `习惯`

### 状态合法值

| 值 | 说明 |
|:---|:------|
| `draft` | 灵感碎片，概念尚未成型 |
| `active` | 概念清晰，仍在打磨中 |
| `mature` | 提炼完成，内容稳定 |
| `deprecated` | 内容已过时（文件名加 `⚠️` 前缀） |
| `archived` | 已完结项目或内容 |

### type 合法值（原子笔记必填）

`concept` / `model` / `practice` / `critique` / `moc`

### 命名规则

| 规则 | 内容 |
|:-----|:------|
| **NAMING-01** | 原子笔记文件名只保留纯概念名，出处下沉 YAML source/author |
| **系统文档** | 编号前缀 + 功能描述，如 `05_Vault Management 全流程操作规范.md` |
| **版本号** | 不在文件名中体现，藏正文头部 |

### 附件路径

| 规则 | 内容 |
|:-----|:------|
| **DIR-02** | 附件统一存放 `90_System/Assets/` 或项目下的 `_attachments/` |
| **图床图片** | 远程图片以纯文本 URL 存在，不构成本地附件 |

### Inbox 分区

| 目录 | 用途 | 保鲜期 |
|:-----|:-----|:------:|
| `00_Inbox/_raw/` | 只读原料仓，不删不改 | 无限 |
| `00_Inbox/processing/` | 加工区，知识提炼 | 7 天 |
| `00_Inbox/` 临时 | 行动类闪念/待办 | 24 小时 |

## 二、YAML 字段速查

### 必填字段

| 字段 | 说明 |
|:-----|:------|
| `title` | 笔记标题 |
| `date` | 创建日期 |
| `status` | 5 种合法值 |
| `tags` | 从标签字典选取 |
| `type` | 原子笔记必填 |

### 推荐字段

`source`（单值主来源） / `author` / `project`（项目名，不加双链） / `aliases` / `related`

### 系统扩展字段（不计入 12 字段上限）

`human_edited` / `ai_generated` / `last_ai_edit` / `ai_edit_summary` / `doc_level` / `version` / `last_sync` / `related_docs` / `dependent_skills`
