# 16_双链维护规范

> **地位声明**：本文件是知识库双链（Wikilink）的维护规范。所有重命名、断链修复、引用更新操作均以此为准。
>
> **版本**：v1.0.0
> **生效日期**：2026-07-11
>
> **执行层文档**：本文件是规则标准。具体执行流程、脚本、故障排查见 `vault-management` Skill。
>
> **对应 Skill**：`vault-management`（执行时自动加载）

---

## 一、核心原则

### 1.1 双链格式铁律

| 铁律 | 说明 |
|:---|:---|
| **必须使用双链格式** | `[[笔记名]]`，不是 `[笔记名]` 或 `[笔记名](路径)` |
| **禁止相对路径** | `[[../笔记名]]` 是错误的，使用 `[[笔记名]]` |
| **禁止 URL 链接** | `[文本](https://...)` 不是双链，不会被识别 |
| **目录链接必须加 `/`** | `[[目录名/]]` 打开目录，`[[目录名]]` 打开文件 |

### 1.2 重命名铁律

| 铁律 | 说明 |
|:---|:---|
| **重命名后必须更新全库引用** | 不允许残留旧引用 |
| **必须验证无残留** | 更新后全库搜索确认 |
| **MOC/Dataview 查询必须同步** | `FROM "旧路径"` 需要手动更新 |

### 1.3 断链处理铁律

| 铁律 | 说明 |
|:---|:---|
| **断链超过 3 条必须人工确认** | Agent 不自动删除或修改 |
| **断链 ≤ 3 条且路径确定可自动修复** | 直接 patch，事后汇报 |
| **删除笔记前必须检查入链** | 确认无引用后方可删除 |

## 二、双链格式规范

### 2.1 标准格式

```
[[笔记名]]
[[目录/文件名]]
[[笔记名|显示名]]
[[笔记名#章节]]
[[笔记名#章节|显示名]]
```

### 2.2 目录链接

| 格式 | 效果 |
|:---|:---|
| `[[目录名/]]` | 打开目录的文件列表视图 |
| `[[目录名/文件名]]` | 打开目录下的具体文件 |
| ❌ `[[目录名/|别名]]` | **无效** — 目录链接不支持别名 |

### 2.3 禁止格式

| 格式 | 问题 |
|:---|:---|
| `[笔记名]` | 不是双链，不会被识别 |
| `[笔记名](路径)` | Markdown 链接，不是 Wikilink |
| `[[../笔记名]]` | 相对路径不可靠 |
| `[[./笔记名]]` | 相对路径不可靠 |

## 三、重命名操作规范

### 3.1 重命名流程

```
步骤1：全库搜索旧引用
步骤2：重命名文件
步骤3：批量更新引用
步骤4：验证无残留
步骤5：更新 MOC 和索引
```

### 3.2 必检清单

- [ ] 全库搜索旧文件名（包括 `_备份` 目录）
- [ ] 更新 YAML `title` 字段
- [ ] 更新正文 `# 标题`
- [ ] 更新 `related` 字段中的双链
- [ ] 更新 MOC 和索引文件
- [ ] 检查 Dataview 查询是否用到旧路径
- [ ] 验证无残留引用

### 3.3 特殊目录

重命名后需要额外检查：

| 目录 | 原因 |
|:---|:---|

| `90_System/SOP/` | 系统文档交叉引用密集 |
| `30_Resources/32_MOCs/` | MOC 是引用枢纽 |

## 四、断链修复规范

### 4.1 断链判定

| 类型 | 表现 | 处理方式 |
|:---|:---|:---|
| **真断链** | 目标文件不存在 | 需修复 |
| **假断链** | 文件存在但路径错误 | 自动修复 |
| **目录链接** | `[[目录]]` 而非 `[[目录/]]` | 视情况修复 |

### 4.2 修复流程

```
步骤1：用 find 查实际路径
步骤2：列诊断表格（原链接 / 实际文件 / 操作建议）
步骤3：根据数量决定
  - 断链 > 3 条 → 给清单让用户手动修
  - 断链 ≤ 3 条且路径确定 → 直接 patch
```

### 4.3 禁止行为

- ❌ 不检查入链直接删除文件
- ❌ 批量删除断链（可能是有意保留的占位符）
- ❌ 不验证就执行批量替换

## 五、建立对话链接规范

### 5.1 强对话链接（必须注明理由）

```markdown
**强对话链接**：
- 链接至 [[笔记X]] | 理由：提供了机制解释
- 被 [[笔记Y]] 链接 | 理由：作为反例证伪了Y
```

### 5.2 弱索引链接（允许留白）

```markdown
**弱索引链接**：
- 待链接：[概念/领域/案例] #待补理由
```

### 5.3 禁止空洞词汇

| 禁止 | 正确 |
|:---|:---|
| ❌ "相关"、"类似"、"有意思" | ✅ 必须包含动词或关系名词 |
| ❌ `[[笔记X]]（相关）` | ✅ `[[笔记X]] | 理由：提供了机制解释` |

## 六、检查清单

### ✅ 重命名后必检

1. ✅ 全库搜索旧文件名，确认无残留
2. ✅ 检查 MOC 和索引文件
3. ✅ 检查 Dataview 查询路径
4. ✅ 检查 Skills 目录引用
5. ✅ 验证新引用可点击跳转

### 🔴 STOP 信号

遇到以下情况**立即停止**，人工确认：

- ❌ 旧引用残留超过 10 处
- ❌ 不确定文件是否应该重命名
- ❌ 目标文件名已存在（会覆盖）
- ❌ 断链修复涉及删除操作
