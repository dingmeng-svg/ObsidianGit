# 🏛️ 调查项目基础概况

本次分析基于**2025年北京大学与复旦大学联合发起的第二次中国私生活质量调查（CPLS）**，该调查是目前全国范围内性观念和性行为领域唯一在运营的延续性专项调查，首次调查于2020年开展。
- 核心发起学者：北大光华管理学院於嘉副教授、北大中国社会科学调查中心副主任张春泥、复旦人口研究所副所长骆为祥
- 研究定位：为中国社会性观念与性行为发展现状提供精准观测坐标，延续了上世纪末至2015年潘绥铭团队的大规模专项调查研究脉络。

# 📊 性活跃度的代际与群体分化特征

## 1. 年轻群体的“性活跃度倒挂”现象

在有稳定伴侣的前提下，**00后性活跃度反而低于80后、90初群体**：25岁及以下有伴侣的年轻人中，无性生活的男性占比13%，女性占比17%，这一比例显著高于年长的80后与90初群体。
- 核心动因：本质是**注意力的重新分配**，短视频、游戏等低门槛、高确定性的即时快感娱乐，挤压了需要“天时地利人和”的性活动时间。
- 反常识亮点：2020年20-25岁年轻人性生活生理与心理双满意比例达92%，2025年该比例进一步提升至94%，因此不能用带有负面色彩的“性萧条”笼统概括，更准确的描述是性的重要性呈现“涨潮退潮”的周期性特征。
- 群体分化：低学历无稳定伴侣的年轻男性，无性比例是所有群体中最高的，2025年此前“低学历男性性活跃度更高”的代际特征已逐步消失。

## 2. 被忽视的中年群体性危机

中年群体是当前性活跃度与性满意度双双下滑最严峻的群体，相关数据较2020年进一步恶化：

| 群体分类 | 无性状态（每月不足一次/全年无性生活）占比 |
| :--- | :--- |
| 45岁以上有固定伴侣女性 | 约50% |
| 45岁以上有固定伴侣男性 | 接近40% |
| 36-45岁中青年群体 | 约20% |
- 核心成因：中产群体工作时长过长，个人时间被严重挤压，周末时间又集中投入到子女照料中，夫妻亲密关系维护被持续后置。
- 衍生现象：大量夫妻关系转化为“队友式”协作关系，共同的核心“事业”是抚养孩子，即便性生活缺失导致关系衰退，也极少有人将此作为离婚理由。

# 🧠 性观念与行为的“错位悖论”

调查呈现出非常典型的**观念滞后于行为**的矛盾特征：
1.  **婚前性行为的认知反差**：最近十年进入婚姻的人群中，超过90%存在婚前性行为，但00后对婚前性行为的支持度打分仅为3分（1-5分区间，1为非常不支持），远低于90%行为比例对应的预期4.5分水平。
2.  **代际观念分化**：女性性观念呈现逐代持续开放的上升曲线；而男性对“女性在性中更主动、更享受”的支持度在80后一代见顶，更年轻的男性群体观念反而出现回落。
3.  **男性双重标准**：即便到2025年，男性对女性婚前性行为的接受度，始终低于对自身婚前性行为的包容度。
4.  **婚恋预期错位**：年轻人理想初婚年龄均值为25-26岁，但现实中全国初婚平均年龄男性已超30岁、女性达28岁，现实行为已大幅推迟，但传统婚恋理想模板并未同步更新。

# 📱 互联网亲密关系的特殊走向
1.  **约炮行为大幅回落**：18-25岁年轻群体的约炮（hook up）比例较2020年出现腰斩式下降：男性从20%降至8%，女性从17%降至4%，2020年是该行为的发展顶峰。
2.  **线上婚恋渗透率极低**：尽管中国互联网高度发达，但近十年通过互联网认识后结婚的人群占比不足10%，远低于欧洲最低20%、美国超50%的水平。
3.  **底层动因**：互联网社交信任度持续下降，针对未婚劳动者的访谈显示，大众对网恋、社交软件相亲的接受度普遍偏负面。

# 🔍 关键洞察
1.  年轻人性活跃度下降并非完全负面：部分原因是原本在性关系中处于被动顺从地位的女性，开始拥有拒绝性的自主权，这是女性性主体性提升的表现。
2.  中国并未进入日本式“低欲望社会”：年轻群体对短视频、游戏的时间占用仍处于“适度替代”阶段，人类对亲密关系的需求具备自我调节属性，新鲜娱乐的边际新鲜感会逐步下降。
3.  传统性规范的滞后影响深远：性教育与家庭观念始终未对婚前性行为作出正向明确引导，即便大众行为已普遍突破传统边界，认知层面仍保留着保守底色。

在有伴侣的前提下，“00后”的性活跃度，反而低于“80后”、“90初”；在性观念的开放程度上，“80后”超越了更年轻的代际；最近十年进入婚姻的人，超过90%的人都有婚前性行为，但假如你问他们“应不应该”，答案很可能是“不”……这些发现来源于2025年北京大学和复旦大学联合发起第二次“中国私生活质量调查”（The
Chinese Private Life Survey，以下简称CPLS，第一次调查是在2020年）。

这项调查是目前全国范围内“性观念和性行为”方面唯一在运营的延续性调查。在此之前，中国人民大学社会学系的潘绥铭及团队，曾在上世纪末至2015年之间，在该领域发起过多轮大规模专项调查，为我们了解中国人的性观念和性行为提供了重要数据。

CPLS的发起学者分别是北京大学光华管理学院社会研究中心副教授於嘉，北京大学中国社会科学调查中心副主任张春泥，以及复旦大学人口研究所副所长骆为祥。於嘉认为，他们所获得的调查数据，正是我们认识自身社会在性观念与性行为上走到何处的坐标。

以下是於嘉的讲述。

**“性萧条”的本质是注意力的重新分配**

这几年大家讨论“性萧条”比较多，我们两次调查里，确实有一些数据能呼应这种印象。比如，有伴侣的25岁及下年轻人，有相当一部分处于没有性生活的状态，男性约13%，女性约17%。这个比例，反而是高于比他们年纪大的“80后”和““90初””的。换句话说，在有稳定伴侣的前提下，越年轻，性生活反而越不活跃。

《即使你不和我做》剧照

怎么理解这种现象？我觉得这是一种注意力的重新分配。作为成长在互联网时代的一批人，假设有10个小时，愿意分给性的可能只有2个小时，其它的时间，去刷短视频、打游戏了。短视频只要往下滑就行，打游戏可以不停地重开一局，这些活动都能带来多巴胺的分泌，但是发生性关系，要有天时地利人和，有一整套相对麻烦的流程。而这些娱乐提供的快感虽然不如性，但在这样一个时代，或许年轻人倾向于去抓住更容易获得、确定性更高的快感。

这种注意力的重新分配，是个人的自主选择，所以你不能说它是一件坏事。因为与此同时还有一个好消息，2020年，20-25岁年轻人性生活的生理和心理都满意的比例高达92%，这个比例2025年又上升了2%。所以用“性萧条”这样一个显然是负面的词去笼统地描述，我认为就不完全合适。在我看来，性的活跃程度，更多的像是“涨潮退潮”，有周期性，这段时间它没有那么重要，但可能切换到下一个阶段，性又会变得重要。

《装腔启示录》剧照

互联网上有一些讨论，说“年轻人不愿谈恋爱了”，这大体上是一个准确的描述，但是如果认为中国社会像日本社会那样也进入了“低欲望社会”，我认为也是武断的。我们做私生活调查，会从四个重要维度去分析，性别、年龄、是否有稳定伴侣，以及教育程度。细分到不同群体的性生活，我想更准确的描述是“有进有退”。

就年轻人群体而言，恋爱被短视频、游戏等替代，目前我认为还是“适度替代”的阶段。目前我并不太担心，因为人是会自我调节的，新鲜事物的新鲜度进行到一定阶段也会下降。

另外，过去很多研究会谈到说，在性当中，女性更多是顺从者的角色，女性可能也并不能从性爱当中获得愉悦。所以性活跃度减少，还是要拆开来看，频率是一方面，但是当原本处在被动地位的女性，变得主动，可以去拒绝性的发生，那频率变低就也不是坏事。

《1122好夫妇》剧照

相比于年轻人，在所有群体当中，其实更值得引起关注的是受过高等教育的中年人，这个群体的性活跃度和性满意度在双双下降。

从2025年新一轮的调查中，我们发现，有固定伴侣的人当中，45岁以上的女性，性生活频率每月不足一次乃至全年没有性生活的，大概有一半；而同龄的男性这个比例也接近40%。再年轻一档的，36到45岁的中青年群体，也有约20%，相当于有五分之一以上的中青年是在无性婚姻当中的。而且它比2020年的数字还要高。

一般来讲，随着进入婚姻的时间越来越长，包括孩子的降临，性活跃度会减少，这是一个全球都存在的曲线，但是下降这么快，这么明显，让我觉得在所有群体当中，中年人性活跃度的匮乏是最严峻的。

《烟火人家》剧照

为什么中年人群体受到的挤压比较严重？比如去企业做访谈，我们会很详细地问他们每天的生活轨迹，就会发现很多中产，研究生学历、在大厂工作，但几乎没有个人时间。一早去上班，晚上回家之后基本都10点11点，哪有时间去开展亲密关系。而到了周末，由于周中没有时间，又会集中地将时间花在陪孩子上。夫妻关系维护会不断往后推。遗憾的是，这种状况短时间很难缓解。

性生活消失，事实上就是一种关系的衰退。但在调查中，很少有人将离婚归因于此。中国人，特别是有孩子的夫妻，确实很少会因为亲密关系的匮乏去离婚。性生活变少，夫妻关系转变为同事关系，而“共同的事业”就是孩子，这也是“队友”这个称谓在中国能流行起来的本质。

不同群体在性中的处境也是变化的。我们在2020年的调查中看到的情况是，“80后”那一代，有稳定伴侣的男性里，学历低的反而性生活更频繁。但到2025年，这个反转在年轻人里淡了，真正凸显出来的是另一件事——低学历的年轻人越来越难先有一段稳定关系：没有固定伴侣、又学历不高的年轻男性，无性比例是最高的。

另外，我们还要看到性的“娱乐功能”，比如刚才我们讲到受过高等教育的年轻人，即便有稳定伴侣，在性上也没那么活跃，其中一个原因就是，对他们来说，在娱乐上他们有更多选项。

**中国人保守吗？**

通过2020年和2025两次调查，我们的整体结论是，中国人在性观念上还是偏保守的。比如，“是否赞同婚前性行为”这个问题，大部分人的态度是“既不赞成也不反对”，选择“完全不赞同”的也有相当的比例。

但是，我要强调，这仅仅是观念。因为从我们的调查中还可以看到，比如说最近十年进入婚姻的人，有婚前性行为的比例已经超过了90%。这是一个很大的比例，等于说是，大家都在做。但即便到了2025年，“00后”群体当中，在“赞同婚前性行为”这道题上，平均分也只有3左右。（打分1~5，1为非常不支持，5为非常支持）。以90%的人都有婚前性行为这个数据，更合理的平均分应该在4.5左右。

可以从“观念的滞后性”来理解这个看似矛盾的现象。中国社会变化特别快，性行为发生有很多便利条件，但我们的性教育，从来都不会说婚前性行为是好的，它不一定谴责，但成长过程中，家长一定会表达类似“上大学千万不要发生性行为”这样的叮嘱。这些都会影响年轻人的性观念。

2020年那次调查还看到一个挺有意思的分化。女性的性观念是一条持续向上的线，一代比一代开放。然而，面对女性该不该在性里更主动、更享受这类问题，男性的开放程度在80后那一代见顶，更年轻的人男性反而回落了一些。这道题2025年没再问，不过换个角度还能看到类似的东西。虽然2025
年男女都更开放了，但男性对于婚前性行为是存在双重标准的，他们对女性婚前性行为的接受度一直低于对男性自己的。

《欢乐颂》剧照

这种“分化”现象可以这样解释：男性在比较年轻、没有经历过太多亲密关系时是保守的，但是当他到了三四十岁，因为经历了一些亲密关系，在这些关系当中积累了观察，在性观念上会有所松动。与此同时，传统的性规范中，女性是要去“服务”男性的，但是越来越多的女性接受高等教育，她们会逐渐在性当中要求一定的主体性，观念在持续得变得开放。

我自己也做婚姻研究，婚姻里同样存在观念滞后现象。比如我们问到20岁出头这些正准备进入婚恋高峰期的年轻人，问他们理想结婚年龄，答案平均值就在25岁、26岁。但是我们再看最新的婚姻登记普查，第一次结婚的平均年龄，男性已经达到30岁以上了，女性也有28岁。现实中大家已经推迟进入婚姻，但是大家的理想模板没有发生太大的变化。

《南来北往》剧照

对比2025年和2020年的两次调查，一个比较意外的变化，发生在“hook
up”，也就是“约炮”行为。五年前的调查中，18岁～25岁的年轻人当中，有大约20%的男性有过约炮经历，女性这个数字是17%。但是5年过去，还是这个年龄段，男性下降到了8%，而女性，只有约4%。这个数值下降得还是相当可观的。

如果再连着潘绥铭老师团队过去二十多年的数据，我的感觉是，约炮现象在2020年是个顶峰。约炮涉及到对互联网的使用。中国互联网如此发达，但最近十年，结婚的人群当中，通过互联网认识的还不到10%，这是一个很低的比例。对比欧洲，最低的国家都有20%，美国这个比例甚至高达50%以上，虽然这个数字是包含了非婚姻状态的稳定伴侣关系，依然是一个很高的数字。
