# 邵艾伦口语三合一 课程介绍

> **说明**：以下为邵艾伦抖音上的口语三合一课程介绍。直播间卖的是 99 元的口语三合一，含：口语书 + 发音课 + 社群。素材供后续英语课程营销策划参考。

---

## 产品模式

- **课程名称**：口语三合一
- **价格**：99 元
- **打包内容**：口语书 + 发音课 + 社群
- **销售渠道**：抖音直播间
- **目标人群**：英语基础薄弱、想快速提升口语的普通学习者

### 营销逻辑拆解

**高客单价 → 低客单价模式**
- 不是纯粹的 99 元低价课引流
- 用户在直播间被引流到低客单价课程，后续再升单到高客单价课程

**先聚焦一个拳头产品打透**
- 产品数量和种类都很少，先做爆品

**直播卖货的核心：建立信任**
- 直播间持续输出内容，建立专业形象和信任感
- 信任建立后，下单是顺带的事

### 课程体系

一套小而美的产品线：
- 入门99元三合一 → 超级简单 → 价格便宜 → 不赚钱 → 引流目的 → 建立信任 → 后续升单
