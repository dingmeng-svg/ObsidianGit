### 归档原因详解

本制作清单被取代的核心原因：

1. **钩子体系架构升级**：旧版采用“单一免费钩子（Obsidian个人OS体验包）”，用户评论扣1后统一发送同一个压缩包。新版方案升级为**双轨钩子体系**——单集专属即时钩子（匹配当集痛点的轻量化交付物）+ 终极架构图置顶钩子（全系列统一的活文档链接）。旧版“一个包吃遍30天”的分发逻辑与新版“一集一钩子、精准匹配即时需求”的策略已不兼容。

2. **交付物内容迭代**：旧版体验包包含模板4件套+习惯记分卡+5分钟上手指南+3分钟演示视频，交付形式为ZIP压缩包+网盘链接。新版方案将交付物拆分为两类：单集轻量干货（AI自动整理脚本、五层日周月模板、身份投票表单等）即时发送，终极架构图为在线活文档（Obsidian Publish/Notion），附带更新日志和版本号。旧版的静态打包分发模式不再适用。

3. **入门版产品联动**：旧版体验包独立于付费产品体系。新版方案将免费钩子与9.9元入门版（5套模板+10分钟搭建教程+基础AI编译提示词）形成显式联动——用户领取免费钩子后，自然被引导至入门版的完整交付。旧版体验包中的“5分钟上手指南”功能已被入门版的10分钟搭建教程视频覆盖，无需单独维护。

4. **私信话术简化**：旧版私信回复需发送网盘链接+提取码+视频链接，回复模板较长。新版方案通过在线活文档统一分发，私信回复压缩为一句话+链接，降低了用户操作摩擦。旧版的分发话术和打包方式不再适用。

## 核心价值（保留参考）

尽管已被取代，本文档以下设计思想和方法论仍具有长期参考价值：

### 1. 体验包设计的核心原则

> “让用户在5分钟内感受到‘这套系统能解决我的问题’，而不是‘我需要先学会用Obsidian’。”

这条原则是贯穿旧版体验包和所有后续钩子产品设计的底层逻辑。新版的单集即时钩子（AI自动整理脚本、五层日周月模板）依然遵循此原则——每个交付物都能让用户在当集痛点场景下立刻用起来，而非先学习一套新工具。

### 2. 交付物的脱敏与降级策略

旧版体验包对模板的处理规则（删除个人隐私内容→保留结构框架→Templater占位符替换为静态文本→Dataview代码块替换为静态表格示例→所有删减处加注释说明付费版功能）形成了一套完整的“教学版制作SOP”。这套SOP在制作9.9元入门版和99元基础版的交付物时可复用以保证一致的处理标准。

### 3. 演示视频的脚本结构

旧版3分钟演示视频的四段结构（开场展示痛点场景→核心操作演示→结果可视化→收尾钩子闭环），本质上就是新版短视频四段式结构（开场→痛点细节→架构顿悟→共鸣归位）的“长视频版本”。如果未来需要制作深度教学视频（如入门版的10分钟搭建教程），可沿袭此结构做等比例缩放。

### 4. 制作工时估算的项目化管理

旧版对五个组件逐一给出了优先级分级（🔴最高/🟡中/🟢次高）、预估耗时和分批制作建议（第一天做静态组件、第二天做视频+打包）。这种将交付物制作拆解为可执行任务清单的项目化管理方式，可直接复用于新方案中9.9元入门版（3个交付物）、99元基础版（6个交付物）的制作排期管理。

### 5. 打包规范与分发方式的经验沉淀

旧版对文件大小阈值（视频文件>10MB走网盘）、打包目录结构（体验包/Templates/）、私信回复话术模板都有明确的规范说明。这些规范虽然在内容上已被新版方案取代，但其“将分发流程标准化以降低执行成本”的设计思想，已内化到新版方案的私信分层交付规范和钩子活文档机制中。

# Obsidian 个人 OS 体验包 v2.2 制作清单

> **定位**：免费钩子，用于30天内容发布期间的用户引流。用户评论扣1后，通过私信或自动回复发送此包。
>
> **核心原则**：让用户在5分钟内感受到“这套系统能解决我的问题”，而不是“我需要先学会用Obsidian”。


### 组件一：5分钟上手指南（PDF）

**优先级**：🔴 最高。这是用户打开体验包后第一个看到的文件，决定了留存率。

**内容结构**：
```
第1页：这个包是什么？
  - 一句话：这是一套帮你每天进步1%的个人操作系统模板。
  - 三句话说明你能用它做什么：①每天打卡追踪习惯；②每周复盘看到进步；③每月调整方向。

第2页：3步导入（图文）
  - Step 1：下载 Obsidian（附官网链接）
  - Step 2：打开这个 Vault（双击文件夹 → Obsidian → Open folder as vault）
  - Step 3：打开 Daily Template，开始你的第一天

第3页：第一天怎么用
  - 早晨：打开 Daily，填 Plan 区块（今天最重要的一件事）
  - 晚上：打开 Daily，填晚间反思（今天学到了什么）
  - 不需要学任何快捷键，不需要装任何插件

第4页：常见问题
  - Q：我不会用 Obsidian，是不是不能用了？A：不需要会用。你只需要打开文件、打字、关闭。其他功能以后慢慢探索。
  - Q：为什么模板里有些奇怪的符号？A：那些是 Templater 占位符，免费版用静态文本代替。付费训练营会教你用 Templater 自动生成。
```

**制作方式**：直接在 Obsidian 中写一篇笔记，导出为 PDF。排版简洁，每页不超过150字。

**验收标准**：一个从未用过 Obsidian 的人，按照指南操作，能在5分钟内打开 Daily Template 并写下第一行字。


### 组件二：模板 4 件套（Markdown 文件）

**优先级**：🔴 最高。这是体验包的核心交付物。

**提取路径**：从你当前 vault 的 `90_System/91_Templates/` 中提取。

**脱敏规则**：
- 删除你的私人笔记内容（晨启肯定语中的个人隐私、晚间反思中的具体事件、Weekly 中引用的具体项目名）
- 保留所有结构框架（Callout、表格、区块标题）
- Templater 占位符（如 `{{date}}`）替换为静态文本（如 `2026-06-29`），并在旁边加注释：`<!-- 付费版支持自动生成日期 -->`
- Dataview 查询代码块替换为静态表格示例，并在旁边加注释：`<!-- 付费版支持自动聚合数据 -->`

**打包格式**：
```
体验包/
  └── Templates/
      ├── Daily Template.md
      ├── Weekly Template.md
      ├── Monthly Template.md
      └── Quarterly Template.md
```

**验收标准**：
1. 用户将这4个文件放入自己的 vault，打开后能看到清晰的结构（标题、表格、Callout、区块），内容为空但框架完整。
2. 模板中不包含任何你的个人信息。
3. 模板中不包含任何需要插件才能显示的内容（Dataview 代码块除外，它们以注释形式保留）。


### 组件三：习惯记分卡（独立版）

**优先级**：🟡 中。这是给不想导入全部模板的用户的降级方案。

**提取路径**：从你的 Weekly Template 中提取 AH Callout 区块。

**脱敏规则**：
- 删除你的个人习惯名称（如“每日闪念记录”），替换为示例习惯（如“习惯1：每天写一张卡片”）
- 保留记分卡表格结构：习惯名称 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 | 完成率
- 添加使用说明（2-3句话）：每周一填入这周要追踪的3-5个习惯，每天完成就打勾，周末自动算完成率。

**打包格式**：
```
体验包/
  └── 习惯记分卡.md
```

**验收标准**：用户打开文件，能看到一个完整的空白记分卡表格，附有2-3句使用说明，可以直接开始填写。


### 组件四：Raw 编译演示视频（3分钟录屏）

**优先级**：🟢 次高。视频的视觉效果比图文更有冲击力，但因为制作耗时，可以在Day1发布前完成即可。

**脚本结构**（3分钟）：
```
0:00-0:15 开场：展示 _raw/ 文件夹里刚扔进去的一篇公众号文章
0:15-0:45 核心：打开 Hermes，输入指令“帮我把这篇编译成 Atomic Notes”
0:45-1:30 结果：展示 Hermes 输出的3条 Atomic Notes，每条都有编号、来源、关联链接
1:30-2:15 网络：打开 Obsidian 图谱，展示新笔记如何自动与已有笔记建立双向链接
2:15-2:45 收尾：这就是我每天花15分钟做的事——投喂，编译，连接。你也想要这个系统？评论扣1，发你体验包。
2:45-3:00 钩子：屏幕叠加文字“评论扣1，发你 Obsidian 个人OS体验包”
```

**录制工具**：OBS 或 macOS 自带的 Screenshot 工具（Cmd+Shift+5 → 录屏）。

**验收标准**：
1. 视频中不出现任何个人信息（私密笔记标题、你的真实姓名等）。
2. Hermes 输出结果清晰可读，不需要观众看代码。
3. 结尾钩子与30天内容计划的Day1视频钩子一致。


### 组件五：打包与分发

**打包格式**：
```
Obsidian个人OS体验包_v2.2.zip
  ├── 5分钟上手指南.pdf
  ├── Templates/
  │   ├── Daily Template.md
  │   ├── Weekly Template.md
  │   ├── Monthly Template.md
  │   └── Quarterly Template.md
  ├── 习惯记分卡.md
  └── Raw编译演示视频.mp4（或在线观看链接）
```

**分发方式**：
- 视频文件较大（可能100MB+），建议上传到网盘（百度网盘/阿里云盘），在私信回复中发送链接 + 提取码。
- 模板文件和 PDF 可以直接通过私信发送（文件小于10MB）。
- 视频也可以上传到 B 站/小红书（非公开），私信回复中发送链接。

**回复话术模板**（用于私信回复）：
```
感谢关注！你的 Obsidian 个人 OS 体验包在这里：

📥 模板 + 上手指南：[网盘链接] 提取码：v22a
🎬 系统演示视频：[B站/网盘链接]

打开上手指南，5分钟就能开始用。有问题随时问我～
```

## 制作时间估算

| 组件 | 预估耗时 | 优先级 |
|:---|:---|:---|
| 5分钟上手指南 | 1-2h | 🔴 最高 |
| 模板 4 件套脱敏 | 1h | 🔴 最高 |
| 习惯记分卡提取 | 30min | 🟡 中 |
| Raw 编译演示视频 | 2-3h（含录制+剪辑） | 🟢 次高 |
| 打包与分发 | 30min | — |
| **合计** | **5-7h** | — |

建议分两天完成：第一天做上手指南 + 模板脱敏 + 记分卡（约3.5h），第二天录视频 + 打包（约3h）。全部完成后，Day1 视频即可正式发布。
