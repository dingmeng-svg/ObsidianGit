## 一、项目是什么

这是一个用**短视频**讲交易的认知升级项目。不是荐股，不是讲K线技术。

**核心交付**：让普通股民通过改变认知和行为，实现稳定盈利。
**用户路径**：认知偏差纠正 → 行为纪律建立 → 交易系统形成 → 风险管理固化。
**目标用户**：困在“知道做不到”的循环里、赚过钱但守不住、隐约感知交易需要修心的操盘手。

**核心人设**：
我们有百万军规，我们能说到做到


## 二、内容生产的底层逻辑

### 2.1 痛点六实体模型

所有股民交易痛苦归并为6个根实体，是所有选题的底层分类框架：

| 实体 | 定义 | 典型症状 |
| :--- | :--- | :--- |
| A-决策瘫痪 | 信息过载，无法形成清晰决策 | 看啥都像机会但不敢买 |
| B-执行断裂 | 有策略有纪律，临门一脚做不出来 | 该止损不止，计划一套实盘一套 |
| C-情绪劫持 | 情绪压倒理性 | 买入即悔、持仓拉扯、卖飞后悔 |
| D-节奏错配 | 总是慢半拍或快一步 | 追在顶部、卖在黎明前 |
| E-认知幻觉 | 元认知失效，不知道自己不知道 | 把消息当逻辑、把运气当实力 |
| F-系统虚无 | 缺乏长期交易系统，持续负反馈 | 连续亏损→自我怀疑→绝望 |

**使用规则**：每策划一期新视频，先定位它属于哪个实体、哪个交易阶段（决策期/验证期/结果期），再找对应的体系解药。


### 2.2 七个体系

体系是后台思维模型，**永远不出现在前台内容中**。只在写稿时调取。**所有体系文档已更新术语，括号内为内部原名，括号外为对外可用名。**

| 体系 | 来源 | 用途 | 快速入口 |
| :--- | :--- | :--- | :--- |
| 骑士日·七色体系 | 老刘标准 | 对外统一呈现框架 | 周一到周日，七色+骑士+佛+动作映射 |
| 七日心法（创世纪·交易世界观） | 圣经 | 底层操作系统，用7天重建看市场眼光 | 看清真相→建立边界→各从其类→识别周期→策略有魂→雌雄同体→强制停盘 |
| 骑士八大美德 | 骑士精神 | 行为准则 | 荣誉、仁爱、牺牲、勇猛、诚实、觉察、正直、谦和 |
| 富兰克林十三项美德 | 自我修行 | 长期自律清单，每周一项 | 节制、缄默、秩序、坚决、节约、勤劳、真诚、正直、中庸、整洁、平静、忠贞、谦和 |
| 实战九字诀（九字真言） | 道家 | 实战心法，应对9种市场关键时刻 | 临（暴跌稳住）→兵→斗（信号不等）→者→皆→阵→列→前→行（止损执行） |
| 人性六毒与解药（六度万行） | 佛家 | 对抗六毒的解药 | 贪→布施、慢→持戒、嗔→忍辱、懒→精进、疑→禅定、痴→般若 |
| 五方佛·交易智慧体系 | 佛家 | 五种烦恼转化为五种智慧 | 痴→法界体性智、嗔→大圆镜智、慢→平等性智、贪→妙观察智、疑→成所作智 |

**体系使用规则**：
- 痛点E（认知幻觉）→ 七日心法·看清真相 + 人性六毒·般若
- 痛点B（执行断裂）→ 骑士·荣誉 + 人性六毒·精进 + 实战九字诀·行
- 痛点C（情绪劫持）→ 人性六毒·忍辱 + 富兰克林·平静
- 痛点F（系统虚无）→ 富兰克林·秩序 + 人性六毒·禅定

**对外铁律**：所有直播、短视频、文案，只用"骑士日 + 颜色 + 动作语言"，不出现任何内部体系术语。

## 四、直播间与硬件

### 4.1 硬件配置

- **视频**：尼康D800/D7000 + 绿联Mini HDMI线 + Elgato Cam Link 4K采集卡
- **音频**：RODE PodMic USB + 悬臂支架
- **灯光**：60cm深抛柔光灯（主光）+ 60cm球形轮廓灯 + 60×60格栅顶灯
- **供电**：沣标EN-EL15假电池（Type-C版）
- **理线**：插排固定贴（3M背胶）+ 电线整理器

### 4.2 灯光方案

- 主光：摄像机侧前方15°-30°，高度2.0-2.2米
- 轮廓光：侧后方45°，高度2.2-2.5米
- 顶灯：桌面正上方，垂直向下

## 六、AI接手快速上手指南

**第一步：理解底层框架**
阅读痛点六实体模型和痛感发酵矩阵，理解所有选题的底层逻辑。

**第二步：熟悉体系**
浏览工具箱总纲MOC和日课协调MOC，了解每个体系的“一句话核心”和对应痛点。写稿时从中调取解药。

**第三步：风格一致性检查**
- 用“你”不用“您”
- 具象化优先，不讲道理
- 体系不当前台话题
- 结尾必留钩子

**第四步：术语统一**
所有对外内容使用对外可用名（括号外），内部文档可保留原名（括号内）。对外场景严格遵守"骑士日 + 颜色 + 动作语言"铁律。
