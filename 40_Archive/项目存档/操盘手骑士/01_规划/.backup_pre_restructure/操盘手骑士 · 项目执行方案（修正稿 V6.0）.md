## 十、短视频生产标准

- **时长**：30-60秒，独立内容，不混剪直播
- **结构**：自然开场 → 讲故事 → 顿悟时刻 → 自然共鸣 → 顺其自然
- **模式**：一条百万军规一个真实故事，“我曾经→转变→改变后”
- **生产节奏**：每天11:00-12:00写一条稿，下午或傍晚拍摄，次日10:00-11:00剪辑发布
- **学习期**：前10条约3小时/条，稳定后约1小时/条


## 十一、数据采集与语言标准

- **数据源**：同花顺APP（指数/涨跌家数）、东方财富（板块资金/新闻）、财联社（电报）
- **交叉验证**：指数0误差，成交额±50亿，涨跌家数±50家，涨停±5家
- **采集时间**：控制在20分钟内
- **语言标准**：零修饰语，对标新闻联播财经风格
- **缺失处理**：标“—”，不编造

# 第一部分：每日决策入口

## 1.1 统一决策树（每天第一件事）

```
今天是什么日子？
  │
  ├── 步骤A：今天是交易日吗？
  │   自查清单：
  │   □ 是周六或周日？→ 不是交易日
  │   □ 查2026年法定节假日表（见1.2）→ 节假日不是交易日
  │   □ 调休补班日？→ 虽然是周末但是交易日！
  │   □ 调休放假的工作日？→ 虽然是工作日但休市！
  │
  ├── 是交易日 → 翻到【第二部分：交易日复盘】
  │
  └── 不是交易日（休市日）
      ├── 先检查有没有重大突发事件：
      │   □ 全球主要股指单日跌幅超过3%？
      │   □ 央行意外加息/降息？
      │   □ 地缘冲突导致原油单日涨超5%？
      │   □ 国内出台资本市场重大政策文件？
      │   └── 有的话 → 优先做事件速报+影响评估
      │

# 第二部分：交易日复盘（操作流程）

## 2.1 核心理念

交易日复盘**不只是记录数据**，而是用结构化框架，把收盘信号转化为可执行的认知。

做完复盘后，应该能回答：
- 今天市场**真正发生了什么**？（不是涨跌数字本身）
- **谁在买、谁在卖**？（资金从哪来、到哪去）
- 自己的判断**被验证了还是被打脸了**？

## 2.3 数据采集流程（逐步操作）

### Step 1：收盘数据（约 3 分钟）
打开**同花顺APP首页**或**东方财富APP**，记录：
- [ ] 上证指数：收盘点数、涨跌幅
- [ ] 深证成指：收盘点数、涨跌幅
- [ ] 创业板指：收盘点数、涨跌幅
- [ ] 两市成交额（注意单位是"亿"）
- [ ] 上涨家数、下跌家数
- [ ] 涨停家数、跌停家数

> 💡 **成交额提示**：不同平台显示的数字可能相差几十亿，属正常范围。固定使用一个平台的数据，保持一致即可。

### Step 2：板块数据（约 5 分钟）
打开**东方财富"行业板块"页面**，记录：
- [ ] 涨幅前 3 的板块 + 涨幅%
- [ ] 跌幅前 3 的板块 + 跌幅%
- [ ] 资金净流入前 3 的板块 + 金额
- [ ] 资金净流出前 3 的板块 + 金额

### Step 3：新闻采集（约 8 分钟）
打开**财联社电报**或**东方财富"要闻"**，按优先级收集：

| 优先级 | 内容类型 | 采集数量 |
|:---:|:---|:---:|
| 第一 | 央行操作、关键经济数据、重大政策 | 全部浏览 |
| 第二 | 美股/港股收盘、A50期指、人民币汇率 | 3-5 条 |
| 第三 | 商品期货、亚太市场 | 2-3 条 |
| 第四 | 行业新闻、公司公告 | 选最重要的 3-5 条 |

### Step 4：外盘数据（约 2 分钟）
打开**同花顺"全球"页**或**东方财富"全球市场"**，记录：
- [ ] 纳斯达克：收盘价、涨跌幅
- [ ] 道琼斯：收盘价、涨跌幅
- [ ] 恒生指数：收盘价、涨跌幅

### Step 5：数据交叉验证（约 2 分钟）
快速核对：
- 指数点数 → 两个平台对比，应完全一致
- 成交额 → 允许 ±50 亿误差
- 涨跌家数 → 允许 ±50 家误差
- 涨停家数 → 允许 ±5 家误差

对不上但误差在范围内 → 取常用平台数据。误差超出范围 → 找第三个平台确认。

## 2.5 数据缺失或异常处理

| 情况 | 处理方法 |
|:---|:---|
| 北向资金净额 | 自 2024 年起不再按日披露。记录中写"自2024年起停止披露"，**不要编造数字** |
| 北向成交额 | 仍按日披露，正常记录 |
| 某个数据找不到 | 换一个平台查。实在找不到就写"—"，注明原因 |
| 板块排名无法获取 | 从新闻中间接推断领涨/领跌板块 |
| 数据源之间不一致 | 取常用平台数据，保持一致；差距太大就找第三个平台 |

## 2.6 记录与分享规范
1. **先完成完整记录，再分享/发布** — 不要在未完成时边写边发。
2. **数据区保持干净** — 每行一个指标，便于快速扫读。
3. **有数据就写数据，没有就写"—"** — 不留占位符。
4. **标注信息来源** — 每个数据都应知道其出处。

# 第三部分：休市日 系统文档（操作流程）

## 3.1 核心理念
**休市日不等于无事可做，而是「回顾整理 + 前瞻预期」的黄金时间。**
休市日要回答三个问题：
1. **本周市场验证了什么？**（周度审计）
2. **下周市场可能发生什么？**（策略推演）
3. **自己的判断框架需要调整吗？**（元复盘）

## 3.2 休市类型判断
```
今天是休市日，具体是哪种？
├── 周六 → 【周六型 · 周度审计】
├── 周日 → 【周日型 · 策略推演】
├── 节假日连续第 3 天以上 → 【长假守望型】
├── 距下一交易日 ≤ 1 天 → 【收假前一日 · 节后交易计划】（必须执行）
└── 每月第一个周六 → 额外加做【SOP健康度自检】
```

### 重大突发事件优先处理
| 触发条件 | 操作 |
|:---|:---|
| 全球主要股指单日跌幅 > 3% | 暂停原计划，先做事件速报 + 影响评估 |
| 央行意外降息/加息 | 同上 |
| 地缘冲突导致原油单日涨 > 5% | 同上 |
| 国内出台资本市场重大政策 | 同上 |

## 3.3 通用写作要素

### 情绪曲线（每次必含）
```
> 🎬 情绪曲线：😤(焦虑/警惕) → 😊(欣慰/认可) → 🤔(思考/分析) → 💪(坚定/行动)

# 第六部分：常见问题与注意事项

## 数据类
1. **成交额单位** — 确认是"亿"，不是"万"或"元"
2. **北向资金净额** — 2024 年起停止披露，**严禁编造**
3. **数据源不一致** — 取常用平台数据，差距太大找第三个验证
4. **缺失就标"—"** — 宁可不写，也不造假
5. **精确值就是精确值** — 不要同时写"约XXXX亿"和精确数字

## 流程类
6. **先完成完整记录，再分享** — 不要边写边发
7. **动笔前先翻看昨天的记录** — 去重最容易被跳过
8. **控制采集时间** — 不超过 20 分钟
9. **假设追踪表单独维护** — 使用独立文件

## 内容类
10. **估值数据必须可查** — 不编造 PE、增速等指标
11. **跨周期对标要具体** — 写明"类似2019年初"
12. **不推荐个股** — 只分析板块、方向

# 附件二：短视频创作白皮书 V3.3 - 筛选篇

> **定位**：以“隐形技巧+干货门槛”为核心的高转化短视频创作方法论，专为销售筛选设计
> **适用对象**：B2B销售、高客单价产品、专业服务类创作者
> **核心理念**：技巧要隐形，真诚要可见；用干货做门槛，用专业筛用户

---

## 一、核心心法：一个根本认知

### 1.1 核心理念
> **观众能闻出表演的味道，但闻不出真诚的套路。**
筛选型短视频只有一个根本目标：**让对的人觉得“这人懂行”，让错的人觉得“这跟我没关系”。**

### 1.2 两个隐形工具
| 工具 | 作用 | 核心要点 |
|:---|:---|:---|
| **专业门槛** | 筛选精准用户 | 用行业术语、具体数据、专业洞察做门槛 |
| **真诚流露** | 建立信任感 | 技巧源于内容本身，而非外挂表演 |

### 1.3 双重约定器
| 约定器 | 作用 | 工作方式 |
|:---|:---|:---|
| **内容约定器（显性）** | 约定服务对象 | 专业术语+行业数据+深度洞察 |
| **姿态约定器（隐性）** | 约定合作方式 | 真诚分享+不迎合+不贩卖焦虑 |

---

## 二、梅拉宾法则：让技巧隐形，让专业可见

### 2.1 三要素的隐形应用
| 要素 | 显性技巧（避免） | 隐形技巧（推荐） |
|:---|:---|:---|
| **文字** | 套路化表达 | 用你的语言习惯说专业事 |
| **语音语调** | 刻意控制节奏 | 根据情绪自然起伏 |
| **肢体/视觉** | 按时间点设计动作 | 让动作成为思考的副产品 |

### 2.2 隐形执行标准
| 维度 | 显性标准（避免） | 隐形标准（推荐） |
|:---|:---|:---|
| 🎤 语速 | 机械控制150-180字/分 | 根据内容自然起伏 |
| 🎤 重音 | 刻意砸实关键词 | 用停顿代替重音 |
| 🎤 情绪 | 比正常夸张20% | 真实流露 |
| 🎬 手势 | 每30秒设计一次 | 成为思考副产品 |
| 🎬 眼神 | 开场看镜头压低 | 像日常对话 |

---

## 三、结构体系：自然化五步结构

| 步骤 | 隐形名称 | 功能 | 时长 |
|:---|:---|:---|:---|
| 1 | **自然开场** | 用真实场景开场，主动筛人 | 0-3秒 |
| 2 | **讲故事** | 用细节和情感建立代入感 | 3-30秒 |
| 3 | **顿悟时刻** | 揭示专业洞察，设置认知门槛 | 30-60秒 |
| 4 | **自然共鸣** | 用“我也有这个困惑”引发共鸣 | 60-90秒 |
| 5 | **顺其自然** | 用分享代替指令，降低推销感 | 90-120秒 |

---

## 四、内容生成技法：隐形翻译器

| 专业内容 | 显性表达（套路味） | 隐形表达（真诚味） |
|:---|:---|:---|
| 强调重要性 | “记住这个核心逻辑” | “这一点是我花了很长时间才想明白的” |
| 给出结论 | “答案就是：上游最肥” | “把产业链捋完，我的判断是上游最值得看” |
| 引导行动 | “赶紧点赞收藏” | “如果你也在看这个赛道，可以关注我” |
| 承认局限 | （不承认） | “这个我还没想清楚” |

**翻译完成后，通读一遍，问自己：“这句话像不像我在跟朋友聊天？”**

---

## 五、筛选型短视频传播规律

### 5.1 黄金3秒法则（筛选版）
| 类型 | 隐形公式 | 示例 |
|:---|:---|:---|
| 痛点型 | “刚才有个客户问我……” | “刚才有个客户问我，为什么他们的转化率这么低” |
| 反差型 | “说实话，我以前也觉得……” | “说实话，我以前也觉得长线持有一定赚钱” |
| 筛选型 | “这条视频只适合……” | “这条视频只适合年产值500万以上的企业主看” |

### 5.2 完播率驱动
**公式**：专业内容 + 认知门槛 = 精准用户看完 + 非精准用户划走

### 5.3 标题法则（筛选版）
- 优秀：“年产值500万以下的企业，这条视频可以划走了”
- 较差：“提升转化率的5个方法”

## 六、创作实战Checklist（筛选版）

### 6.1 写稿前检查
- [ ] 我要筛出什么样的用户？
- [ ] 内容是否有足够的专业深度？
- [ ] 内容是否源于真实经历和思考？

### 6.2 自然化五步逐项检查
- 自然开场：是否用真实场景开场？
- 讲故事：是否有真实细节和情感？
- 顿悟时刻：是否揭示了专业洞察？
- 自然共鸣：是否先表达共情再分享？
- 顺其自然：是否用分享代替指令？

### 6.3 录制后回看检查
- 关掉声音看一遍：像在分享，还是在表演？
- 打开声音听一遍：像日常聊天，还是在背稿？

## 七、常见问题速查表

| 问题 | 原因 | 解决方案 |
|:---|:---|:---|
| 3秒留存>60% | 筛得不够狠 | 增加专业术语，提高认知门槛 |
| 3秒留存<30% | 筛得太狠 | 降低开场门槛，保留核心专业内容 |
| 评论质量差 | 互动问题太简单 | 提高参与成本，问专业问题 |
| 像在表演 | 心态不对 | 改为“分享者”心态 |
| 像在背稿 | 逐字稿太详细 | 改为关键词大纲 |

## 总结：筛选型创作心法三句话

1. **技巧要隐形，真诚要可见**——让观众感觉不到技巧的存在，只感受到你的专业和真诚
2. **用干货做门槛，用专业筛用户**——让对的人觉得“有料”，让错的人觉得“跟我没关系”
3. **分享者心态，一次过标准**——我在分享经验，不是在表演专家；宁可不完美，也要真实

> **记住**：最高级的筛选，是让观众自己意识到“我不适合”，而不是你告诉他“你不适合”。最高级的约定，是让目标用户觉得“这人是为我服务的”，而不是你告诉他“我在为你服务”。
