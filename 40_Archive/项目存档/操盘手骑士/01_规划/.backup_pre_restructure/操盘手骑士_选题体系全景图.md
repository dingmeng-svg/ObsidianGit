> **说明**：本文档已执行术语统一更新。工具箱名称与最新去宗教化版本对齐。括号内为内部原名，保留在原子笔记中；括号外为对外可用名。两份旧版（详细版 + 精简版）已合并归档，本文档为唯一现行版本。
> **对外铁律**：所有直播、短视频、文案，只用"骑士日 + 颜色 + 动作语言"，不出现任何内部工具箱术语。


## 四层架构

| 层次 | 核心体系 | 成长映射 |
|:---|:---|:---|
| **道** (核心信仰) | 七日心法（创世纪·交易世界观） | 见众生 → 见天地 → 见自己 |
| **法** (行为准则) | 骑士八大美德 + 富兰克林十三项美德 | 见自己 (日常修行) |
| **术** (实战心法) | 实战九字诀（九字真言） | 见天地 (市场搏杀) |
| **器** (人性镜子) | 人性六毒与解药（六度万行） | 贯穿始终 (自我觉察) |


## 道：七日心法——用七天讲成长故事

这是账号的"灵魂"，用来吸引不满足于"术"、渴望"道"的高净值人群。

**系列主题：操盘手的七天蜕变**

| 天 | 主题 | 内容方向 |
|:---|:---|:---|
| 1 | 看清真相 | 操盘手的第一步，用认知驱散市场的黑暗与无知。对应：见众生 |
| 2 | 建立边界 | 建立自己的交易系统，在混沌中画出清晰的边界 |
| 3 | 各从其类 | 让正确的交易系统为你工作，结出复利果实 |
| 4 | 识别周期 | 识别市场的周期与节律，明白何时播种、何时收割 |
| 5 | 策略有魂 | 赋予交易系统生命力，让它成为自适应、自我进化的有机体 |
| 6 | 雌雄同体 | 塑造兼具果断与耐心的全新自己——进攻如猛虎，等待如大地 |
| 7 | 强制停盘 | 懂得休息是交易的最高境界。在自由日里复盘，为下一轮积蓄能量 |


## 法：行为准则——用骑士美德塑造人格

这部分是吸引同频伙伴、建立社群的基石，展示个人品格和社群准入门槛。

**系列主题：操盘手的骑士宣言**

| 美德 | 英文 | 内容方向 |
|:---|:---|:---|
| 荣誉 | Honor | 言出必行，对自己的交易计划负责 |
| 仁爱 | Compassion | 在社群里分享经验，帮扶弱者，成为他人的"微光" |
| 牺牲 | Sacrifice | 为长期盈利，甘愿牺牲眼前的诱惑和小利 |
| 勇猛 | Valor | 在别人恐惧时敢于亮剑，捕捉战机 |
| 诚实 | Honesty | 对自己诚实，直面每一笔亏损，绝不找借口 |
| 觉察 | Spirituality | 交易是一场自我认知的镜子，做一个有深度的操盘手 |
| 正直 | Justice | 有所为有所不为。只取合乎道义的利润，绝不参与恶意操纵 |
| 谦和 | Humility | 敬畏市场。无论盈利多少，始终保持低调与谦逊 |


## 法：日常修行——用富兰克林十三项美德落地实践

这部分是每天的"行动指南"，目标用户是相信长期主义、不断自我完善的精英阶层。

**系列主题：操盘手的十三项修炼**

| 周 | 美德 | 英文 | 内容方向 |
|:---|:---|:---|:---|
| 1 | 节制 | Temperance | 仓位上的节制，不孤注一掷 |
| 2 | 缄默 | Silence | 不夸夸其谈，不与人争辩无意义的市场观点 |
| 3 | 秩序 | Order | 生活、复盘、交易流程严格遵守既定纪律和节奏 |
| 4 | 坚决 | Resolution | 对验证过的策略坚决执行，善始善终 |
| 5 | 节约 | Frugality | 节约资本，把握主升浪，对震荡市的小摩擦视而不见 |
| 6 | 勤劳 | Industry | 专心致志，在自己的能力圈内做到极致 |
| 7 | 真诚 | Sincerity | 对自己真诚，对粉丝真诚。分享逻辑，不制造焦虑 |
| 8 | 正直 | Justice | 在市场中行正道，不因利益扭曲判断 |
| 9 | 中庸 | Moderation | 不走极端。不全仓猛干，不空仓到底，追求动态平衡 |
| 10 | 整洁 | Cleanliness | 维护内心和交易界面的整洁，不被杂乱信息干扰 |
| 11 | 平静 | Tranquility | 面对账户剧烈波动，内心不起波澜 |
| 12 | 忠贞 | Chastity | 忠于自己的交易系统，不朝三暮四 |
| 13 | 谦和 | Humility | 永远不认为自己能战胜市场，只是市场的追随者和学习者 |


## 术：实战心法——用实战九字诀应对市场

这部分直接切入交易场景，是对散户心态的降维打击，内容有爆款潜力。

**系列主题：操盘手的九种关键时刻应对**

| 字 | 核心含义 | 内容方向 |
|:---|:---|:---|
| 临 | 临危不惧 | 临近盘面时保持稳定情绪和判断力 |
| 兵 | 排兵布阵 | 面对瞬息万变的战场，如何调配资金，进退有据 |
| 斗 | 敢于亮剑 | 在符合交易系统时果断出击 |
| 者 | 意念通达 | 控制自己的心念和情绪，不被贪婪恐惧左右 |
| 皆 | 人盘合一 | 感知市场的共振频率，感受市场脉搏与节奏 |
| 阵 | 心如磐石 | 不受外界消息和杂音影响 |
| 列 | 破除心魔 | 打破"一买就跌，一卖就涨"的魔咒 |
| 前 | 洞察先机 | 绕到市场前面，预判趋势，比他人多看到几步 |
| 行 | 知行合一 | 将一切理论付诸实践，所有信念最终落在操作上 |


## 器：人性镜子——用人性六毒与解药剖析自我

这部分用来做最尖锐的人性剖析，直击每一个散户的心灵痛点。

**系列主题：交易中的六种情绪陷阱**

| 毒 | 对治 | 内容方向 |
|:---|:---|:---|
| 贪 | 布施 | 用分享和回馈来约束贪婪，把利润的一部分拿出来回馈生活 |
| 嗔 | 忍辱 | 用忍耐来应对市场的反复无常和亏损的折磨 |
| 痴 | 般若 | 用对市场规律的深层认知，破除"我执"，客观看待市场 |
| 慢 | 持戒 | 用交易纪律击碎因短期盈利而产生的傲慢 |
| 疑 | 禅定 | 用专注和定力化解对系统的怀疑和摇摆 |
| 懒 | 精进 | 用勤劳来对抗复盘和学习的懒惰 |


## 执行策略

优先从「道」和「法」开始建立 IP 人设，吸引第一批同频的种子用户。之后再逐步深入到「术」和「器」层面，解决具体的交易问题，展现专业和深度。

刚开始拍摄时，优先使用**系列主题**作为视频标题，能更直接地吸引精准用户。
