**一、核心交付**

- 交付物：让一个普通股民通过改变认知和行为，实现稳定盈利。
- 物理路径：认知偏差纠正 → 行为纪律建立 → 交易系统形成 → 风险管理固化。
- 所有工具（创世纪、八大美德、临兵斗者等）只为实现这个结果，不当前台话题。

**二、内容标准（7%-38%-55%）**

- **7% 内容**：每60秒视频只讲一个核心问题。结构固定：
  - 前3秒：抛出具体场景（"你今天是不是又没设止损？"）
  - 中间30秒：核心观点 + 一个可执行动作（"从明天开始，开仓同时必须挂止损单"）
  - 最后10秒：埋悬念或提问（"止盈比止损难十倍，下期讲"）
- **38% 语调**：同一段话录三个版本（愤怒版、戏谑版、语重心长版），选最有冲击力的。情绪必须与内容一致。
- **55% ①场景**：开播前拍照检查背景、层次、灯光。画面只保留人、桌、茶、书。
- **55% ②动作**：保留皱眉、摊手、前倾、指屏等肢体语言。金句处配合强调动作（用力点头、停顿直视镜头）。
- **55% ③剪辑**：重音配放大字幕，关键观点处加音效。节奏要快，不留废话。

**三、标题与表达**

- 标题必须包含数字/反差/痛点（例："三天亏了五百万""大妈也能炒好股票"）。
- 前台内容永远是：症状 → 诊断 → 解决方案 → 行动指令。
- 把抽象概念还原为具体可操作的场景和动作。
- 专注力训练表述："按照约定的规律快速执行"，不讲玄学。

**四、生产节奏**

- 周一集中写本周7条脚本，周二集中录制，周三集中剪辑，每天按排期发布。
- 每条视频对应一张卡片，自动流转：选题池 → 写稿中 → 审核中 → 录制中 → 剪辑中 → 已发布。

**五、素材库**

- 将所有工具箱内容建成标签化素材库。每个标签预存：
  - 一句话核心定义
  - 一个生活化比喻
  - 一个市场应用场景
  - 一个反面案例
- 写稿时直接从库中调取，不从头创作。

**六、发布与互动**

- 手动发布每一条视频，手动回复每一条评论。评论回复是洞察用户需求的窗口。
- 不用low方式求关注。每期结尾埋悬念和钩子，用户想知道下期答案自然关注。

**七、核心指标**

- 唯一核心指标：有效开播场次 + 短视频发布条数。
- 只要这两个在涨，其他数据波动暂时忽略。力气只往这两个矢量上使。
