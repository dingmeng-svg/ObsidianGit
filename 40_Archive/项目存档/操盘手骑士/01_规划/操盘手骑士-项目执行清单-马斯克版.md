**“操盘手骑士”项目启动执行清单**

**第一性原理——回归交易赚钱的本质**

- [ ] **追问“物性”**：我们交付的不是课程、不是法器、不是修行体系。我们交付的是：**让一个普通股民通过改变自己的认知和行为，实现稳定盈利**。所有的工具（创世纪、八大美德、六度、临兵斗者）都只是实现这个结果的“引擎零件”，不是产品本身。
- [ ] **消除“愚蠢税”**：直接拆解用户从亏损到盈利的物理路径——认知偏差纠正→行为纪律建立→交易系统形成→风险管理固化。任何不能直接服务于这四个环节的动作，一律视为“愚蠢税”，暂停或删除。
- [ ] **愿景过滤**：每一个动作（拍视频、做直播、写文章）之前，问：这个动作是让一个散户离“稳定盈利”更近了，还是更远了？如果只是追求“高级感”或“显得有文化”，先搁置。

**质疑需求——砍掉80%的自我感动**

- [ ] **用户真的关心“创世纪”吗？** 不。用户关心的是“为什么我老是亏钱”“为什么我做不到止损”“怎么选股”。所以我们不是讲“创世纪”，而是用“创世纪”的结构来拆解他的亏损根源。标题和开头必须从他的具体症状切入，绝不从宏观哲学切入。
- [ ] **用户真的需要“八大美德”吗？** 不。用户需要的是“为什么我赚到钱就飘然后赔回去”。用“谦和”这个美德来解释“德不配位”的灾难，比直接讲“骑士精神”有效一万倍。
- [ ] **用户真的需要“临兵斗者”吗？** 不。用户需要的是“看盘时怎么控制住自己的手”。用“临”字诀（临危不惧，保持稳定判断）和“阵”字诀（心如磐石，不受杂音影响）教会他一个具体可操作的动作，比给一个法器有效一万倍。
- [ ] **观众需要我的“传道”吗？** 不。观众需要的是“我听了之后明天能做什么”。每次输出前，把“我要告诉你一个道理”改为“你今天可以试试这个动作”。

**删减——让核心动作浮出水面**

- [ ] **删除所有哲学铺垫**：不讲“三观缺失”、不讲“混乱性系统”、不讲“无常与有常”。这些是后台框架，不是前台内容。前台内容永远是：症状→诊断→解决方案→行动指令。
- [ ] **删除所有“灌输式”讲述**：不讲“你要像神一样看见光”。而讲：“你今天看盘时，是不是又被三只股票的涨跌搞得心慌？你把另外两只删掉，只看一只，这就是‘要有光’。”——把场景还原为具体可操作的指令。
- [ ] **删除所有“玄学化”表达**：临兵斗者皆阵列前行，不讲“九字真言的奥秘”，而讲“这是一个专注力训练工具，跟运动员比赛前默念口诀一样”。急急如律令，不讲道教咒语，而讲“它的字面意思是‘按照约定的规律快速执行’，就是你设好止损就严格执行”。
- [ ] **删除“我要你关注”的催促**：不用low的方式求关注。每一期结尾，埋好悬念和钩子——用户想知道下期答案，自然就会关注。

**优化——把7%-38%-55%做到极致**

- [ ] **标题优化**：每个标题必须同时包含“数字/反差/痛点”三个元素。例：“三天亏了五百万”优于“近期市场风险提示”；“大妈也能炒好股票”优于“股票入门教程”；“我为什么把账户里一半的股票全删了”优于“交易系统精简方法”。
- [ ] **7%内容优化**：每60秒视频只讲一个核心问题。结构固定为：前3秒抛出具体场景（“你今天是不是又没设止损？”）→中间30秒给出核心观点和一个可执行的动作（“从明天开始，开仓同时必须挂止损单”）→最后10秒埋悬念或提出问题（“那止盈呢？止盈比止损难十倍，下期讲”）。
- [ ] **38%语调优化**：同一段话，录制三个版本——愤怒版、戏谑版、语重心长版。对着镜子或手机前置摄像头录，回看，选最有冲击力的版本。情绪必须和内容一致：讲止损要严肃，讲韭菜段子要戏谑，讲德不配位要语重心长。
- [ ] **55%场景优化**：固定机位后，每次开播前拍一张照片检查——背景有没有杂乱物品？茶具、书籍的摆放有没有层次感？灯光是否立体？确保画面里只有：人、桌、茶、书，其他全部清场。
- [ ] **55%动作表情优化**：录视频时保留肢体语言——皱眉、摊手、前倾、指屏。关键金句处配合明确的强调动作（如用力点头、停顿后直视镜头）。每天对着迈克尔·杰克逊的一个舞台动作拆解学习。
- [ ] **55%剪辑优化**：每个重音配放大字幕，关键观点处加音效（咚一声）。节奏要快，不留废话空隙。

**加速——用平行作业压缩周期**

- [ ] **台本与录制分离**：每周一集中写完本周所有7条脚本，每周二集中录制完7条视频，每周三集中剪辑完成，每天按排期发布。不搞一条龙。
- [ ] **素材库建设**：把所有工具箱内容（创世纪7天、八大美德、十三项美德、六度、九字真言）建成标签化素材库。每个标签下预存：①一句话核心定义 ②一个生活化比喻 ③一个市场应用场景 ④一个反面案例。写稿时直接从库里调取，不从头创作。
- [ ] **模板化生产**：用Notion或飞书建立内容工厂。每条视频对应一张卡片，自动流转：选题池→写稿中→审核中→录制中→剪辑中→已发布。每阶段停留时间一目了然。
- [ ] **死线压缩**：每期视频从“选题→脚本→录制→成片”的常规周期压缩50%。如果正常需要一周，设定3天截稿。用死线逼出极致潜力。
- [ ] **不怕失败**：每次直播、每条视频，允许不完美。重点是推出去看用户反应。火箭炸了就是边界数据，视频冷了就换标题/开头/情绪，不反复纠结。

**自动化——先别做，等跑通再说**

- [ ] **第一阶段（前100条视频）**：绝不碰任何“自动发布”“自动回复”“自动投流”系统。手动发布每一条，手动回复每一条评论。因为每一条回复都是洞察用户需求的窗口，自动化会彻底错过这些信息。
- [ ] **第二阶段（稳定日更+粉丝过万后）**：只自动化工序化的机械环节。如：B-roll素材库调用、字幕模板自动套用、发布时的标签模板。禁止自动化的：选题决策、标题定夺、回复中的情绪洞察。
- [ ] **第三阶段（商业闭环跑通后）**：考自动化被删除的流程。如果任何一个自动化环节可以不用了，立刻砍掉。

**反共情管理：对自己狠，对团队清**

- [ ] **对自己**：设定“死线日”，如“本周五必须发布7条视频”。周五23:59没完成，自罚200元给丁萌。用可量化惩罚替代情绪懊悔。
- [ ] **对协作**：确立唯一核心指标——“有效开播场次”和“短视频发布条数”。只要这两个在涨，其他数据波动（播放量低、没人互动）暂时忽略。力气只往这两个矢量上使。
- [ ] **对无效反馈**：有人说“讲得太深了听不懂”。不因此改内容。回复“建议先看置顶视频入门”，然后继续讲深度内容。我们的愿景是筛选同频者，不是取悦所有人。

**意识即能量：专注力管理清单**

- [ ] **环境控制**：每次创作前，手机放到另一个房间。桌面上只留创作所需的三样东西：电脑、水杯、台本素材。任何多余物品全部移开。
- [ ] **时间控制**：使用45分钟完整不受打扰的区间做创作。区间内不开微信、不看邮件、不刷任何社交平台。每个区间只做一个任务。
- [ ] **注意力拉回训练**：当发现自己走神时，摸一下手上的临兵斗者戒指，心中默念“临”，把注意力拉回到当前任务。每天练习，直到成为条件反射。

**即刻火速执行清单（今天就要做的）**

- [ ] 拉一个清单：列出阻碍我们马上开始的所有问题——缺什么设备？缺什么场地？缺什么采购？从定机位到定灯光，到麦克风，到剪辑软件，到发布流程。全部列出来。
- [ ] 下单临兵斗者戒指，今天。
- [ ] 今晚把作息时间表排出来——从周一到周日，每天24小时的固定流程。明天开始严格执行。
- [ ] 对着镜子录一段60秒视频——讲“为什么你总是做不到止损”，用7%-38%-55%的标准给自己打分。找出差距，重录，直到可以70分。
- [ ] 明天早上起来，打一盆水，擦桌子。然后坐在机位前，开灯，开机，录第一条短视频。不管好坏，发出去。

明天醒来之后，所有的一切都和今天不一样。如果明天醒来还像今天这样，那终局自己都能看得到。
