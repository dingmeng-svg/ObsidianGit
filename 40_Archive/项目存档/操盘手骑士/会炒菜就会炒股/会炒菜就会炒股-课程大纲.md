## 初版：三阶段框架（第1-21课简表）

### 基础认知阶段（第1-7天）：建立厨房式投资思维

- 第1课《选食材》：ROE 衡量新鲜度，烂菜叶对应 ST 股
- 第2课《火候掌控=买卖时机》：大火爆炒对应短线交易（MACD金叉），文火慢炖对应长线持有
- 第3课《调味公式=仓位管理》：盐少许=10%试仓，糖适量=30%加仓，老抽上色=50%重仓

### 技能进阶阶段（第8-14天）：打造家庭厨房级交易系统

- 第8课《备菜清单=自选股池》：家常菜谱=消费板块，宴席硬菜=科技龙头
- 第11课《厨房安全=风险控制》：锅不离人=止损纪律，油温预警=波动率监控
- 第14课《菜品创新=趋势跟踪》：新菜研发=捕捉行业风口（用RSI指标判断热度）

### 实战精进阶段（第15-21天）：成为星级大厨级投资者

- 第17课《宴席筹备=资产配置》：凉菜20%（债券）+热菜50%（蓝筹）+甜品30%（成长股）
- 第19课《灶台管理=账户复盘》：炒锅日志=交易记录本，调味瓶档案=持仓分析表
- 第21课《私房菜秘方=独有模式》：酸菜鱼哲学=困境反转策略，佛跳墙原理=组合投资艺术

### 特色设计

- **激励机制**：7天获"凉菜师傅"称号，14天晋级"热炒主厨"，21天毕业颁发"米其林操盘手"证书
- **风险提示**：第6课油锅起火=黑天鹅事件，第13课隔夜菜不香=破位必清仓

## 扩展版：21堂完整课纲

### 课程导入（第1课）
- 21天养成炒股习惯的目标
- 炒菜与炒股的基本类比：准备食材、火候控制、调味

### 基础知识篇（第2-7课）

| 课次 | 主题 | 类比 |
|:--|:--|:--|
| 第2课 | 股市厨房 - 市场环境 | 晴天（牛市）、阴天（震荡市）、雨天（熊市） |
| 第3课 | 食材 - 股票种类 | 不同股票如同不同食材，适合不同口味 |
| 第4课 | 锅铲 - 交易账户与平台 | 选择合适的锅铲才能炒好菜 |
| 第5课 | 火候 - 交易时间与频率 | 小火慢炖=长期投资，大火爆炒=短期投机 |
| 第6课 | 调味料 - 风险与收益 | 重口味=高风险高收益，清淡=低风险低收益 |
| 第7课 | 食谱 - 投资策略基础 | 定投策略如同按照食谱定期做菜 |

### 深入分析篇（第8-14课）

| 课次 | 主题 | 类比 |
|:--|:--|:--|
| 第8课 | 食材新鲜度 - 公司基本面分析 | 挑选新鲜食材=分析财务状况 |
| 第9课 | 火候掌握 - 技术分析入门 | K线图如同根据火候判断菜的熟度 |
| 第10课 | 调味技巧 - 行业趋势分析 | 根据季节调整调味=分析行业趋势 |
| 第11课 | 菜品搭配 - 资产配置 | 荤素搭配=不同类型股票组合 |
| 第12课 | 厨房卫生 - 风险管理 | 保持厨房清洁=止损止盈 |
| 第13课 | 特殊食材 - 新兴行业股票 | 尝试新奇食材=投资新兴行业 |
| 第14课 | 菜品创新 - 投资组合创新 | 创造新菜品=根据市场变化创新组合 |

### 实战操作篇（第15-20课）

| 课次 | 主题 | 类比 |
|:--|:--|:--|
| 第15课 | 第一道菜 - 首次股票投资实践 | 选择第一道要做的菜 |
| 第16课 | 翻炒技巧 - 股票买卖时机 | 把握翻炒时机 |
| 第17课 | 菜品调整 - 投资组合调整 | 根据口味调整菜品 |
| 第18课 | 应对危机 - 股市波动应对 | 厨房突发状况（油溅） |
| 第19课 | 菜品展示 - 投资成果展示与分析 | 展示菜品并分析优缺点 |

### 课程总结与习惯养成（第21课）
- 21天重点知识回顾
- 养成定期关注股市、理性投资的习惯
