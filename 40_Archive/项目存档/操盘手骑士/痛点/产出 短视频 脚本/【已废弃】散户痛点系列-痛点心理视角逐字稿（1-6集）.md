# [弃用草稿] 痛点心理视角逐字稿（1-12集）

**系列定位**：你面对的不是K线图，是活生生的人在按下买入和卖出。每一笔成交背后都有一个人在跟你博弈。你要做的不是预测，是观察人的行为，然后应对。

**目标用户**：看图说话、学了一堆指标但一到实战就废、隐隐感觉市场背后有人但不知道怎么看、赚过钱但被自己骗回去的操盘手。

**格式**：60秒短视频，结构化表格（标题/封面/逐字稿）

**叙事框架**：痛点心理分析视角（内部归因），对标6实体模型

### 第一集：总想买在最低卖在最高

**（对应痛点实体：E. 认知幻觉——把妄念当能力）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你总想抄底逃顶？K线不是天气预报，是人画的》 |
| **封面** | 一个人伸手去抓最低点和最高点，两手空空。大字：**你在猜天意，人家在下单！** |

**逐字稿**：

**（开头0-3秒，直视镜头，语气扎心）**

你是不是总想买在最低点、卖在最高点？我告诉你，就这一个想法，把你坑惨了。

**（3-15秒，建立对比）**

你有这种想法因为你把K线当成了天气预报——觉得分析走势，就能预测明天晴雨。但K线不是刮风下雨，每一根K线的背后，是有人在按下买入、有人在按下卖出。没有人点那个按钮，价格不会动。

**（15-40秒，点破本质）**

你想想，你等着抄最低点时，谁在卖你？是人，一个真实的、活生生的人，他为什么要在那个价格卖？他傻吗？你等着逃那个最高点的时候，是谁在买你的？也是人，他为什么要在那个价格接你的货？你从来没想过这些问题。你只想着"市场应该按我画的线走"。这不是分析，这是傲慢。你把妄念当能力，把运气当本事。

**（40-55秒，行动指令）**

明天开盘，别再看你画的那些线了。盯着一只你熟悉的票，就看分时成交那一栏。每笔大单出来的时候，问自己：这个人，他为什么要在这个时候买？为什么在这个时候卖？他不是数字，他是你的对手。

**（55-60秒，结尾引导）**

你开始把每一笔成交当成人来看的时候，你才算摸到了交易的门。下期讲：为什么你买之前清醒，买了之后整个人就变了。

### 第二集：为什么一买股票就变傻

**（对应痛点实体：E. 认知幻觉 + B. 执行断裂——确认偏误全面接管）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《买之前头头是道，套住了就"价值投资"？你在自己骗自己》 |
| **封面** | 一个人对着镜子，镜子里的人嘴巴被封住了。大字：**下单那一刻，你就不再客观了！** |

**逐字稿**：

**（开头0-3秒，皱眉，语气辛辣）**

你有没有发现——买之前你分析得头头是道，买了之后整个人就变了。涨了拿不住，跌了死扛。一买进去，智商直接掉一半。

**（3-15秒，拆解真相）**

为什么？因为你下单的那一刻，你就不再是裁判了，你变成了球员。买之前，你是来分析市场的；买之后，你是来证明自己正确的。你开始疯狂搜集所有说它要涨的消息——大盘涨了你觉得你的票肯定跟，板块动了你觉得主力来了，大V随口提一句你当成实锤。利空呢？业绩下滑叫洗盘，减持叫压价吸筹，公告利空叫主力故意吓人。

**（15-40秒，直击要害）**

人最可怕的，就是自己骗自己。今天买进去，想着明天涨了就卖，这叫投机。第二天套住了，不卖了，告诉自己"我这是价值投资"。你不是价值投资，你是给自己找了一个不认错的台阶。投机的时候，你是按计划来的；变成"投资"的时候，你是被套逼的。承认自己是投机，你有一套应对方法；骗自己是投资，你就只能眼睁睁看着亏损越来越大。

**（40-55秒，行动指令）**

今天，打开你的持仓。每一个票，问自己：我当初买它，是因为分析到位了，还是因为怕踏空冲进去的？如果是后者，明天开盘第一件事——不管你赚了还是亏了——先卖掉一半。用这个动作，把自己从球员重新变回裁判。

**（55-60秒，结尾引导）**

承认自己就是个投机者，不丢人。丢人的是骗了自己三年，账户还是绿的。下期讲：为什么你总觉得别人的股票比你的好。

### 第三集：总觉得别人的股票比自己的好

**（对应痛点实体：E. 认知幻觉 + C. 情绪劫持——社会比较与幸存者偏差）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你追的不是牛股，是别人已经亮出来的底牌》 |
| **封面** | 一个人眼巴巴看着隔壁桌丰盛的菜，自己面前也有盘子却视而不见。大字：**你是来吃饭的，不是来追厨师的！** |

**逐字稿**：

**（开头0-3秒，语速快，调侃中带刺）**

你是不是经常这样：刷手机看到别人晒涨停，心里不痛快。再看看自己的票，半死不活。然后你做了个决定——割了自己的，去追别人的。

**（3-15秒，还原场景）**

结果呢？你一追进去，别人的票也不涨了。而你刚卖掉的，开始涨了。你不是倒霉，你是被自己坑了。

**（15-40秒，戳破幻觉）**

你追的到底是谁的票？是那个在朋友圈晒涨停的人。但你想想，他买的时候发了吗？他研究的时候发了吗？他低位潜伏的时候发了吗？没有。他只在涨起来了、赚到钱了、心里美了，才发出来。你看到的是人家精挑细选的战果，不是全部。你拿别人过滤了十遍的高光时刻，去比你持仓的日常波动，你不痛苦谁痛苦？

更致命的是，你追的不是票，是别人已经亮出来的底牌。他什么时候买的？你不知道。他什么成本？你不知道。他明天卖不卖？你也不知道。你什么都不研究，就因为他赚了你就冲进去。这不叫交易，这叫接盘。

**（40-55秒，行动指令）**

明天开始，立一条规矩：当你因为"别人赚了"而想买一只票的时候，别碰手机。去冲个冷水澡。洗完回来，如果还能写出三个跟"别人赚了"无关的理由，再买。

**（55-60秒，结尾引导）**

你以为"羡慕别人"是最危险的？错了。还有一种更毒的心态——"总觉得自己的股票才是最好的"。那个能让你死扛到底、把全部身家都搭进去。下期讲。

### 第四集：总觉得自己的股票才是最好的

**（对应痛点实体：E. 认知幻觉 + C. 情绪劫持——禀赋效应与自我持仓偏爱）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你把K线图画了又画，结果图是主力画的》 |
| **封面** | 一张画满各种线的K线图，被一只手撕开。大字：**你画的线，是人家的剧本！** |

**逐字稿**：

**（开头0-3秒，语气冷）**

前面讲了总觉得别人的好。但你知道更可怕的是什么吗？总觉得自己的持仓好，怎么看怎么顺眼。

**（3-15秒，还原症状）**

你买了这个票，从按下买入键那一刻，你就开始给它上光环。涨了——"你看，我选对了"。跌了——"没事，洗盘，主力在压价"。利空来了——"假的，主力吓人的"。业绩差了——"提前计提，下个季度就反转了"。你给自己编了一个完整的故事，在这个故事里你永远正确。

**（15-40秒，刀刀见血）**

你还学了各种技术分析，画线、数浪、找形态。看到红三兵，你说要涨了；看到头肩底，你说反转了。但你想过没有——那些图是主力画给你看的。他画一个红三兵，是想拉升释放信号，还是想让你觉得要拉升了、冲进来接他的货？你判断不出来，那些图就是他自己骗自己的道具。

战场上，对方摇一下小白旗，你就觉得他投降了？说不定你一冒头，一枪就过来了。K线图就是主力的白旗，他不是要投降，他是要你的命。拿着别人画的东西当自己判断的依据，你亏的每一分钱都不冤。

**（40-55秒，行动指令）**

明天开盘，把你画的所有趋势线、支撑位、压力位全都删掉。只看成交：价格在变、量在变、谁在买、谁在卖。每一次你想说"这个图形说明XXX"的时候，改问自己：刚才是谁在动？他动的目的是什么？

**（55-60秒，结尾引导）**

关了你的画图软件，把你从图里拽出来，你才看得见真实的敌人。下期讲：当你觉得整个市场烂透了的时候，真正的问题出在哪。

### 第五集：觉得这个市场烂透了

**（对应痛点实体：C. 情绪劫持 + F. 系统虚无——防御性悲观与全盘否定）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你骂市场的时候，机会正在被看懂的人捡走》 |
| **封面** | 一个人关掉电脑，屏幕是绿的，背景却是别人在弯腰捡金块。大字：**你在骂街，别人在捡钱！** |

**逐字稿**：

**（开头0-3秒，语气低沉，停顿片刻）**

你是不是最近——打开账户看一眼，关掉，骂一句："这个市场不行，烂透了，根本没机会。"

**（3-15秒，直接打脸）**

你这口气我太熟了。你嘴里骂的是市场，但你心里真正想的是什么？是"为什么只有我在亏"。

**（15-40秒，层层剥开）**

你不是第一天炒股。你经历过赚钱，也经历过回吐；你经历了追高被套，也经历了割肉就涨。这些事反复发生，让你产生了一个念头：这个市场，我搞不定。干脆不搞了，骂它。骂完舒服了，责任不在你了，是市场不好。

但你舒服的时候，市场不会停下来。恐慌砸出的坑、磨底之后的反转、真正的主线启动——每一次市场最难看的时刻，都有人在买入。不是你这种骂着买，是那种冷静地、有计划地、看到异动就扣扳机地买。你不买，别人买；你骂街，别人在捡便宜。你以为自己退出了，其实是你主动把机会让给了看得懂的人。

**（40-55秒，行动指令）**

明天，别管大盘是涨是跌，打开盘面找三只跟大盘走势不一样的票。大盘跌它在横，或者大盘涨它先动，放进自选，盯。机会不是没有，是你的愤怒让你看不见。

**（55-60秒，结尾引导）**

跟"全烂了"相反的，还有一个更致命的——"到处都是机会！"。那个更危险，下期讲。

### 第六集：觉得到处都是好股票

**（对应痛点实体：C. 情绪劫持 + E. 认知幻觉——乌托邦幻觉与盲目乐观）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你觉得遍地黄金？那是主力给你下的饵》 |
| **封面** | 一片金灿灿的"机会"，其中一块写着"诱多"。大字：**你看见机会，人家看见韭菜！** |

**逐字稿**：

**（开头0-3秒，语气讽刺）**

全市场都在涨。你手上有钱，心慌了。脑子里只有一句话——"全是机会。再不买就来不及了。"

**（3-15秒，浇冷水）**

停。你现在这个状态，跟赌场里连开了十把大的赌徒没有任何区别。你觉得下一把还出大，恨不得把全部筹码推上去。

**（15-40秒，拆开真相）**

什么叫"全是好股票"？你研究过这些票吗？你知道它的股性吗？你了解它背后的主力是什么风格吗？你不知道。你只是看到大盘涨了、板块动了、朋友圈都在晒，你就觉得"我要发财了"。这叫集体亢奋，不叫判断。

战场上，所有人在狂冲的时候，死的最多的就是冲在最前面的。股市里，真正收割韭菜的人，等的就是你这一刻。你看到的遍地机会，是他故意放出来的信号。他用一根阳线让你觉得要起飞了，你冲进去，他把货全倒给你。所以记住：当你觉得"全是好股票"的时候，不是市场给你送钱了，是你主动给别人送钱。

**（40-55秒，行动指令）**

下次这种普涨行情，先做一件事：关掉朋友圈，关掉炒股群，只看盘中每一次异动。没异动的，别碰。有异动的，问自己：这是有人在抢货，还是有人在画图给我看？说不出三个风险之前，不动一分钱。

**（55-60秒，结尾引导）**

从"骂市场烂"到"觉得遍地黄金"，你的心就跟着情绪来回摆。怎么练出一颗不被洗脑的心？下期讲——操盘手的"百万军规"，从叠被子开始。

### 第七集：总想买在最低卖在最高

**E. 认知幻觉——用户把"精准预测市场走势"当成自己的能力，本质是对市场本质的根本性误判。**

| :--- | :--- |
| **标题** | 《你总想抄底逃顶？K线不是天气预报，是人画的》 |
| **封面** | 一个人伸手去抓最低点和最高点，两手空空。大字：**你在猜天意，人家在下单！** |

**逐字稿**：

**（开头0-3秒，直视镜头，语气扎心）**

你是不是总想买在最低点、卖在最高点？我告诉你，就这一个想法，把你坑惨了。

**（3-15秒，建立对比）**

你有这种想法因为你把K线当成了天气预报——觉得分析走势，就能预测明天晴雨。但K线不是刮风下雨，每一根K线的背后，是有人在按下买入、有人在按下卖出。没有人点那个按钮，价格不会动。

**（15-40秒，点破本质）**

你想想，你等着抄最低点时，谁在卖你？是人，一个真实的、活生生的人，他为什么要在那个价格卖？他傻吗？你等着逃那个最高点的时候，是谁在买你的？也是人，他为什么要在那个价格接你的货？你从来没想过这些问题。你只想着"市场应该按我画的线走"。这不是分析，这是傲慢。你把妄念当能力，把运气当本事。

**（40-55秒，行动指令）**

明天开盘，别再看你画的那些线了。盯着一只你熟悉的票，就看分时成交那一栏。每笔大单出来的时候，问自己：这个人，他为什么要在这个时候买？为什么在这个时候卖？他不是数字，他是你的对手。

**（55-60秒，结尾引导）**

你开始把每一笔成交当成人来看的时候，你才算摸到了交易的门。下期讲：为什么你买之前清醒，买了之后整个人就变了。

### 第八集：为什么一买股票就变傻

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《买之前头头是道，套住了就"价值投资"？你在自己骗自己》 |
| **封面** | 一个人对着镜子，镜子里的人嘴巴被封住了。大字：**下单那一刻，你就不再客观了！** |

**逐字稿**：

**（开头0-3秒，皱眉，语气辛辣）**

你有没有发现——买之前你分析得头头是道，买了之后整个人就变了。涨了拿不住，跌了死扛。一买进去，智商直接掉一半。

**（3-15秒，拆解真相）**

为什么？因为你下单的那一刻，你就不再是裁判了，你变成了球员。买之前，你是来分析市场的；买之后，你是来证明自己正确的。你开始疯狂搜集所有说它要涨的消息——大盘涨了你觉得你的票肯定跟，板块动了你觉得主力来了，大V随口提一句你当成实锤。利空呢？业绩下滑叫洗盘，减持叫压价吸筹，公告利空叫主力故意吓人。

**（15-40秒，直击要害）**

人最可怕的，就是自己骗自己。今天买进去，想着明天涨了就卖，这叫投机。第二天套住了，不卖了，告诉自己"我这是价值投资"。你不是价值投资，你是给自己找了一个不认错的台阶。投机的时候，你是按计划来的；变成"投资"的时候，你是被套逼的。承认自己是投机，你有一套应对方法；骗自己是投资，你就只能眼睁睁看着亏损越来越大。

**（40-55秒，行动指令）**

今天，打开你的持仓。每一个票，问自己：我当初买它，是因为分析到位了，还是因为怕踏空冲进去的？如果是后者，明天开盘第一件事——不管你赚了还是亏了——先卖掉一半。用这个动作，把自己从球员重新变回裁判。

**（55-60秒，结尾引导）**

承认自己就是个投机者，不丢人。丢人的是骗了自己三年，账户还是绿的。下期讲：为什么你总觉得别人的股票比你的好。

### 第九集：总觉得别人的股票比自己的好

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你追的不是牛股，是别人已经亮出来的底牌》 |
| **封面** | 一个人眼巴巴看着隔壁桌丰盛的菜，自己面前也有盘子却视而不见。大字：**你是来吃饭的，不是来追厨师的！** |

**逐字稿**：

**（开头0-3秒，语速快，调侃中带刺）**

你是不是经常这样：刷手机看到别人晒涨停，心里不痛快。再看看自己的票，半死不活。然后你做了个决定——割了自己的，去追别人的。

**（3-15秒，还原场景）**

结果呢？你一追进去，别人的票也不涨了。而你刚卖掉的，开始涨了。你不是倒霉，你是被自己坑了。

**（15-40秒，戳破幻觉）**

你追的到底是谁的票？是那个在朋友圈晒涨停的人。但你想想，他买的时候发了吗？他研究的时候发了吗？他低位潜伏的时候发了吗？没有。他只在涨起来了、赚到钱了、心里美了，才发出来。你看到的是人家精挑细选的战果，不是全部。你拿别人过滤了十遍的高光时刻，去比你持仓的日常波动，你不痛苦谁痛苦？

更致命的是，你追的不是票，是别人已经亮出来的底牌。他什么时候买的？你不知道。他什么成本？你不知道。他明天卖不卖？你也不知道。你什么都不研究，就因为他赚了你就冲进去。这不叫交易，这叫接盘。

**（40-55秒，行动指令）**

明天开始，立一条规矩：当你因为"别人赚了"而想买一只票的时候，别碰手机。去冲个冷水澡。洗完回来，如果还能写出三个跟"别人赚了"无关的理由，再买。

**（55-60秒，结尾引导）**

你以为"羡慕别人"是最危险的？错了。还有一种更毒的心态——"总觉得自己的股票才是最好的"。那个能让你死扛到底、把全部身家都搭进去。下期讲。

### 第十集：总觉得自己的股票才是最好的

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你把K线图画了又画，结果图是主力画的》 |
| **封面** | 一张画满各种线的K线图，被一只手撕开。大字：**你画的线，是人家的剧本！** |

**逐字稿**：

**（开头0-3秒，语气冷）**

前面讲了总觉得别人的好。但你知道更可怕的是什么吗？总觉得自己的持仓好，怎么看怎么顺眼。

**（3-15秒，还原症状）**

你买了这个票，从按下买入键那一刻，你就开始给它上光环。涨了——"你看，我选对了"。跌了——"没事，洗盘，主力在压价"。利空来了——"假的，主力吓人的"。业绩差了——"提前计提，下个季度就反转了"。你给自己编了一个完整的故事，在这个故事里你永远正确。

**（15-40秒，刀刀见血）**

你还学了各种技术分析，画线、数浪、找形态。看到红三兵，你说要涨了；看到头肩底，你说反转了。但你想过没有——那些图是主力画给你看的。他画一个红三兵，是想拉升释放信号，还是想让你觉得要拉升了、冲进来接他的货？你判断不出来，那些图就是他自己骗自己的道具。

战场上，对方摇一下小白旗，你就觉得他投降了？说不定你一冒头，一枪就过来了。K线图就是主力的白旗，他不是要投降，他是要你的命。拿着别人画的东西当自己判断的依据，你亏的每一分钱都不冤。

**（40-55秒，行动指令）**

明天开盘，把你画的所有趋势线、支撑位、压力位全都删掉。只看成交：价格在变、量在变、谁在买、谁在卖。每一次你想说"这个图形说明XXX"的时候，改问自己：刚才是谁在动？他动的目的是什么？

**（55-60秒，结尾引导）**

关了你的画图软件，把你从图里拽出来，你才看得见真实的敌人。下期讲：当你觉得整个市场烂透了的时候，真正的问题出在哪。

### 第十一集：觉得这个市场烂透了

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你骂市场的时候，机会正在被看懂的人捡走》 |
| **封面** | 一个人关掉电脑，屏幕是绿的，背景却是别人在弯腰捡金块。大字：**你在骂街，别人在捡钱！** |

**逐字稿**：

**（开头0-3秒，语气低沉，停顿片刻）**

你是不是最近——打开账户看一眼，关掉，骂一句："这个市场不行，烂透了，根本没机会。"

**（3-15秒，直接打脸）**

你这口气我太熟了。你嘴里骂的是市场，但你心里真正想的是什么？是"为什么只有我在亏"。

**（15-40秒，层层剥开）**

你不是第一天炒股。你经历过赚钱，也经历过回吐；你经历了追高被套，也经历了割肉就涨。这些事反复发生，让你产生了一个念头：这个市场，我搞不定。干脆不搞了，骂它。骂完舒服了，责任不在你了，是市场不好。

但你舒服的时候，市场不会停下来。恐慌砸出的坑、磨底之后的反转、真正的主线启动——每一次市场最难看的时刻，都有人在买入。不是你这种骂着买，是那种冷静地、有计划地、看到异动就扣扳机地买。你不买，别人买；你骂街，别人在捡便宜。你以为自己退出了，其实是你主动把机会让给了看得懂的人。

**（40-55秒，行动指令）**

明天，别管大盘是涨是跌，打开盘面找三只跟大盘走势不一样的票。大盘跌它在横，或者大盘涨它先动，放进自选，盯。机会不是没有，是你的愤怒让你看不见。

**（55-60秒，结尾引导）**

跟"全烂了"相反的，还有一个更致命的——"到处都是机会！"。那个更危险，下期讲。

### 第十二集：觉得到处都是好股票

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你觉得遍地黄金？那是主力给你下的饵》 |
| **封面** | 一片金灿灿的"机会"，其中一块写着"诱多"。大字：**你看见机会，人家看见韭菜！** |

**逐字稿**：

**（开头0-3秒，语气讽刺）**

全市场都在涨。你手上有钱，心慌了。脑子里只有一句话——"全是机会。再不买就来不及了。"

**（3-15秒，浇冷水）**

停。你现在这个状态，跟赌场里连开了十把大的赌徒没有任何区别。你觉得下一把还出大，恨不得把全部筹码推上去。

**（15-40秒，拆开真相）**

什么叫"全是好股票"？你研究过这些票吗？你知道它的股性吗？你了解它背后的主力是什么风格吗？你不知道。你只是看到大盘涨了、板块动了、朋友圈都在晒，你就觉得"我要发财了"。这叫集体亢奋，不叫判断。

战场上，所有人在狂冲的时候，死的最多的就是冲在最前面的。股市里，真正收割韭菜的人，等的就是你这一刻。你看到的遍地机会，是他故意放出来的信号。他用一根阳线让你觉得要起飞了，你冲进去，他把货全倒给你。所以记住：当你觉得"全是好股票"的时候，不是市场给你送钱了，是你主动给别人送钱。

**（40-55秒，行动指令）**

下次这种普涨行情，先做一件事：关掉朋友圈，关掉炒股群，只看盘中每一次异动。没异动的，别碰。有异动的，问自己：这是有人在抢货，还是有人在画图给我看？说不出三个风险之前，不动一分钱。

**（55-60秒，结尾引导）**

从"骂市场烂"到"觉得遍地黄金"，你的心就跟着情绪来回摆。怎么练出一颗不被洗脑的心？下期讲——操盘手的"百万军规"，从叠被子开始。
