### 第一集：每一笔成交背后都有人

**（对应核心洞察：市场是人为博弈，不是自然现象）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《K线不是刮风下雨，每一笔成交背后都有一个人在按按钮》 |
| **封面** | 一根K线被拆开，里面是一群小人。大字：**K线背后，是人！** |

**逐字稿**：

**（开头0-3秒，直视镜头，语气笃定）**

你是不是以为K线是自然现象？跟地震、台风一样，分析分析走势图就能预测？大错特错。

**（3-15秒，建立对比）**

每一笔成交，都是有人下了单。没有人按下买入键，那个价格不会动。没有人按下卖出键，那个成交量不会出来。你在看的是什么？不是图，是人的行为。是一群人在那儿，有的买，有的卖，有的排队，有的撤单，有的突然冒出来，有的突然消失。

**（15-40秒，点破本质）**

你把K线当数学题做，画各种线，数各种浪。但主力不会按你的线走，因为他画线的时候，根本不会通知你。他是有计划、有策略地在操作。他可以连拉三天，也可以突然消失三天，让你完全摸不着头脑。这叫两军相争，不是天气预报。

**（40-55秒，行动指令）**

明天开盘，别再看指标了。盯着一只你熟悉的股票，只看一个东西：每一分钟的成交，是大单还是小单？是有人在扫货，还是有人在出货？你看到的是人，不是数字。

**（55-60秒，结尾引导）**

那怎么判断这背后的人到底想干什么？下期讲。今天先把这个视角转过来了——你面对的不是市场，是活生生的人。

### 第二集：盘中异动就是敌人的动作

**（对应核心洞察：异常就是信号，盯住异动）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《突然拉涨停又撤单？那不是假的，那是有人在试盘！》 |
| **封面** | 一个人拿着望远镜趴在战壕里。大字：**异动，就是敌人的动作！** |

**逐字稿**：

**（开头0-3秒，语速略快）**

你看到盘口突然出现一个大单，堆到涨停板上，然后一秒钟又撤了。你是不是骂一句"骗炮"，就划走了？你亏钱的根源就在这儿。

**（3-15秒，建立对比）**

你不觉得奇怪吗？能封到涨停板，需要几个亿的资金。这不是一个散户或者一个小游资能干的事。这背后有一个机构，或者一个大金主。他有这么多钱，他把它堆在那儿，然后又撤了，他闲的吗？他精神病院里跑出来的？不是。他在试盘。他在测试这个地方有多少抛压，有多少跟风。

**（15-40秒，点破本质）**

战场上有句话：哪儿枪响了，哪儿炮响了，哪儿就是交战的地方。盘口也一样。哪个票突然出现异动——突然拉升、突然砸盘、突然有规律的大单进出——那地方就有人在做动作。你看到了，你要做的不是猜，是盯。盯着他接下来干嘛。他撤了，你就瞄着；他又动了，你就准备扣扳机。

**（40-55秒，行动指令）**

明天，找一个今天有异动的票，放进自选前三位。明天盯着它，看他会不会再动。动了，记录时间、量、方向。三次记录下来，你就大概知道他什么路数了。

**（55-60秒，结尾引导）**

那看到异动之后，到底什么情况下可以跟，什么情况下必须撤？下期讲。

### 第三集：主力是怎么割韭菜的

**（对应核心洞察：涨停诱多+融券砸盘的套路）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《第一天涨停你追进去，第二天低开6%——这一刀是怎么砍下来的？》 |
| **封面** | 一把刀，刀柄写着"主力"，刀刃朝下砍在一根K线上。大字：**涨停追进去，第二天闷杀！** |

**逐字稿**：

**（开头0-3秒，语气冷峻）**

第一天涨停，你冲进去了。第二天直接低开6个点，然后一路砸到跌停。你说主力太坏了。但你知道这一刀是怎么砍的吗？

**（3-15秒，拆解套路）**

第一天，主力花真金白银把股价拉上去，封涨停。你以为是拉升开始，冲进去了。但主力有自己的筹码吗？不一定。他可以融券。融券是什么？我没股票，但我能借股票来卖。涨停板上，他把借来的股票砸给你，卖出去。第一天，他已经跑了一部分。

**（15-40秒，继续拆解）**

第二天，如果开盘还在高位，他继续砸。他有的是券，你买多少他就砸多少。三分钟，盘就崩了。崩了之后呢？散户全慌了，都开始卖，根本不用他动手，股价就一路往下。跌了20%，他把上面卖掉的筹码，在下面全部买回来。上面高价卖了，下面低价买回来，20%落袋。上下一共40%。这叫什么？这叫正规打法。你以为是阴谋，其实人家是明牌。

**（40-55秒，给出策略）**

所以你怎么办？涨停不追。提前埋伏在可能发生这种事儿的票里。他拉上去，你跟着卖；他砸下来，你是现金，你怕什么？你甚至可以跟着他一起融券——你也能开融资融券，只是你没用过。

**（55-60秒，结尾引导）**

什么样的票容易被选中干这种事？下期讲。

### 第四集：承认自己是赌徒，才能开始赢

**（对应核心洞察：不认识自己的投机本质，就会陷入无限被动）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《你天天说你价值投资，你投了个什么？你连公司门朝哪开都不知道》 |
| **封面** | 一个人照镜子，镜子里是一只鸵鸟。大字：**别骗自己了，你就是来赌的！** |

**逐字稿**：

**（开头0-3秒，直视镜头，语气扎心）**

你套住了，告诉自己：我是价值投资，我长期持有。你是不是觉得自己特别高级？我今天就戳破这层纸。

**（3-15秒，火力全开）**

你买的那个公司，你去过吗？你知道他的CEO长什么样吗？你看过他的财报吗？你能像巴菲特一样直接给管理层打电话吗？你啥都没干，你只是在键盘上敲了几个字母，买了之后就开始指望它涨。那你跟去澳门有什么区别？赌场里还有百家乐、21点、老虎机，你总得挑一个吧？你挑股票的时候，花了多少时间研究规则？

**（15-40秒，点破本质）**

人最可怕的，就是自己骗自己。今天买进去，想着明天涨了就卖，这叫投机。第二天套住了，不卖了，告诉自己"我价值投资了"。你不是价值投资，你是给自己找个借口扛着。结果呢？从短套变深套，从深套变腰斩。承认自己是投机的人，他有一套应对投机的策略，胜率能支撑他不亏。你不是。你赢了是运气，亏了是必然。

**（40-55秒，行动指令）**

今天，把你账户里所有股票，重新分类：哪些是你当初想投机但被套了才改成"投资"的？列出来，写在一张纸上。对着这张纸，问自己一句话：如果今天我是空仓，我会买它吗？如果答案是"不会"，你还不卖等什么？

**（55-60秒，结尾引导）**

承认自己是赌徒不难，难的是承认之后你还知道怎么赢。下期讲。

### 第五集：纸上谈兵死路一条

**（对应核心洞察：K线形态与技术指标只是表象，所有战略战术必须根据实际战场调整）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《红三兵就涨？那是主力画给你看的！别拿K线自己骗自己了》 |
| **封面** | 一个人在纸上画了一个完美的K线图，纸被撕成两半。大字：**你的图，是主力画的！** |

**逐字稿**：

**（开头0-3秒，语气辛辣）**

你是不是背了一大堆K线形态？红三兵、启明星、头肩底，如数家珍。你觉得看到这个图，就等于看到了机会。我告诉你，那个图，是主力画给你看的。

**（3-15秒，拆解真相）**

战场上，你拿个小棍摇一摇小白旗，对方就真的投降了吗？说不定你一冒头，一枪就打过来。K线形态也是这个道理。它可以是主力的真实意图，也可以是他专门做出来引诱你接盘的工具。红三兵出现，是主力想拉升，给市场释放信号？还是他想让你觉得要拉升了，诱多进去接他的货？你判断不出来，红三兵就是陷阱。

**（15-40秒，点破本质）**

所有伟大的战役，打赢的将军，没有一个是在战前把敌人每一步怎么走都写好的。他们都有一个东西——临场应变。前面冒出一队人，情报变了，立刻调整部署。股市也一样，你是侦察兵，你要做的是观察敌人异动，实时汇报。看到大量真金白银在扫货，你跟不跟？看到大单砸盘，你跑不跑？所有判断，都必须在事实发生那一瞬间做出。

**（40-55秒，行动指令）**

明天开始，关掉所有技术指标，只看裸K和分时成交。只看三件事：价格、成交量、异动大小。每一次想操作之前，问自己：这个动作，是图上的指标告诉我的，还是盘口今天正在发生的事实告诉我的？

**（55-60秒，结尾引导）**

那怎样训练自己的战场应变能力？不是靠背口诀，是靠百万次重复。下期讲"操盘手骑士·百万军规"是怎么练成的。

### 第六集：百万军规，从叠被子开始

**（对应核心洞察：极致训练通向极致自由，100→1万→100万的颗粒度进化）**

| 维度 | 内容 |
| :--- | :--- |
| **标题** | 《一个普通士兵为什么要叠豆腐块？操盘手的"百万军规"怎么练》 |
| **封面** | 左边是一块豆腐块被子，右边是一根K线。大字：**叠被子和赚钱，是一个道理！** |

**逐字稿**：

**（开头0-3秒，语气深沉）**

为什么一个普通士兵，被子要叠成豆腐块？牙膏怎么放，鞋带怎么系，枪怎么擦——所有这些小事，跟打仗有什么关系？

**（3-15秒，揭示答案）**

因为这些标准动作，练的是你在任何情况下，都能做到你想做到的事。暴风雨来了，别人慌成一团，他面不改色。因为他已经练过无数次了，在泥里滚过，在沼泽里爬过。所以当战争真的来临，他能从容不迫，随机应变。

**（15-40秒，对标交易）**

操盘手也是一样。"操盘手骑士·百万军规"——这是一个从100条、到1万条、到100万条的训练体系。你只做到100条，入门了；做到1万条，你是高手；做到100万条，你就是顶级狙击手。你知道风速怎么影响弹道，知道光线折射的角度，知道趴在哪里最安全、什么时候扣扳机。所有的高手，一眼就能看到100万个细节。就像芒格说的，一眼看到本质的人，和一辈子都看不清的人，注定是两种人生。

**（40-55秒，行动指令）**

你的第一步，从今天开始：梳理你自己的第一条军规，写下来贴在屏幕旁边。比如："永远不在开盘第一分钟下单"。这就是你100条军规的第一条。明天你来直播间，我告诉你第二条应该写什么。

**（55-60秒，结尾引导）**

从100条到1万条再到100万条，怎么一步步升级自己的操作系统？来我直播间，我正在拆解这个训练框架。
