# 短视频创作实战Checklist V3.2  
  
> **使用说明**：本Checklist覆盖短视频创作全流程，建议打印出来，每创作一条视频就对照执行一次。  
> **使用频率**：每条视频必用  
> **预计耗时**：写稿10分钟 + 录制5分钟 + 发布3分钟  
  
---  
  
## 📋 使用指南  
  
### 如何使用这个Checklist  
  
1. **打印出来**：建议A4纸打印，放在工作台随时对照  
2. **逐项打勾**：每完成一项就打勾 ✓，确保不遗漏  
3. **定期复盘**：每周回顾哪些环节经常出错，重点改进  
4. **团队共享**：可作为团队SOP，确保出品质量统一  
  
### Checklist流程图  
```  
  
选题 → 写稿前 → 写稿中 → 录制前 → 录制中 → 录制后 → 发布前 → 发布  
↓ ↓ ↓ ↓ ↓ ↓ ↓  
[9.1] [9.2] [9.3] [9.4] [9.5] [9.6] [9.7]  
  
```

## 9.1 写稿前检查清单  
  
### 选题确认  
- [ ] 是否解决了观众的某个具体痛点？  
- [ ] 这个痛点是否足够普遍？（至少10万人会遇到）  
- [ ] 这个痛点是否足够痛？（会让观众产生"对对对，就是这样"的共鸣）  
  
### 内容类型确认  
- [ ] 确定是知识科普/情感共鸣/产品介绍/娱乐搞笑中的哪一种？  
- [ ] 根据类型调整梅拉宾三要素权重  
- [ ] 根据类型调整语速和时长  
  
### 核心信息确认  
- [ ] 这条视频最想传递的一个核心信息是什么？  
- [ ] 能否用一句话概括？（如果不能，说明内容太杂）  
  
---  
  
## 9.2 写稿中检查清单（五步结构逐项检查）  
  
### 钩子（0-3秒）  
- [ ] 是否在3秒内抛出了具体痛点/悬念/反差？  
- [ ] 是否避免了"大家好""今天讲讲"等无效开场？  
- [ ] 是否使用了钩子公式库中的模板？  
- [ ] 是否具象化、有画面感？（避免抽象概念）  
  
### 铺垫（3-30秒）  
- [ ] 是否给出了具体的人物、场景、时间？  
- [ ] 是否让观众产生了代入感？（"这就是我"）  
- [ ] 是否为后面的转折做了充分铺垫？  
- [ ] 是否控制在30秒内？（60秒视频建议15秒内）  
  
### 转折（30-60秒）  
- [ ] 是否推翻了前面的预期？  
- [ ] 是否揭示了核心洞察/真相？  
- [ ] 是否有金句？金句是否具象化、可感知？  
- [ ] 金句是否标注了重音和手势？  
  
### 互动（60-90秒）  
- [ ] 是否打破了第四面墙？（直接对观众说话）  
- [ ] 是否提出了观众此刻心里的问题？  
- [ ] 互动问题是否简单、二选一最优？  
- [ ] 是否引导了具体行动？（敲1/敲2/评论区告诉我）  
  
### 收尾（90-120秒）  
- [ ] 是否总结了核心观点？  
- [ ] 是否给出了具体行动指令？  
- [ ] 是否有下集预告/悬念钩子？  
- [ ] 是否避免了"谢谢观看"等无效结尾？  
  
---  
  
## 9.3 技法应用检查清单  
  
### 翻译器应用  
- [ ] 专业概念是否翻译成了生活画面？  
- [ ] 道理是否翻译成了具体故事？  
- [ ] 是否避免了直接扔术语？  
  
### 包袱公式应用  
- [ ] 是否至少使用了一个包袱公式？（预期违背/具象化/角色扮演/谐音双关）  
- [ ] 包袱位置是否合理？（建议在转折处）  
- [ ] 包袱是否标注了表演方式？（语调、手势、表情）  
  
### 梅拉宾三要素标注  
- [ ] 🎤 语速是否标注？（根据内容类型）  
- [ ] 🎤 重音词是否标注？（每句至少一个）  
- [ ] 🎤 情绪是否标注？（与内容一致）  
- [ ] 🎬 手势是否标注？（每30秒至少一次）  
- [ ] 🎬 身体动线是否标注？（前倾/后靠）  
- [ ] 🎬 眼神是否标注？（看镜头/压低/睁大）  
  
---  
  
## 9.4 录制前检查清单  
  
### 环境准备  
- [ ] 光线是否充足？（建议环形灯）  
- [ ] 背景是否整洁？（避免杂乱）  
- [ ] 收音设备是否正常？（无线麦/领夹麦）  
- [ ] 手机/相机是否固定？（三脚架）  
  
### 状态准备  
- [ ] 是否对着空气讲了3遍？（找感觉）  
- [ ] 是否把逐字稿改成了关键词大纲？（避免背稿感）  
- [ ] 情绪是否到位？（比正常稍夸张20%）  
  
### 设备检查  
- [ ] 分辨率是否4K？（至少1080P）  
- [ ] 帧率是否60帧？（至少30帧）  
- [ ] 提词器是否调试好？（速度、位置）  
  
---  
  
## 9.5 录制中检查清单（三遍法）  
  
### 第一遍：找状态  
- [ ] 流畅度是否达到70%？  
- [ ] 是否有明显的卡顿、忘词？  
- [ ] 整体节奏是否合适？  
  
### 第二遍：抓节奏  
- [ ] 重音是否到位？  
- [ ] 语速是否符合标准？  
- [ ] 手势是否自然？  
- [ ] 眼神是否有交流感？  
  
### 第三遍：出成品  
- [ ] 情绪是否饱满？  
- [ ] 金句是否突出？  
- [ ] 整体表现是否自然？  
- [ ] 是否有明显的失误？  
  
---  
  
## 9.6 录制后检查清单  
  
### 回看检查（关掉声音）  
- [ ] 身体语言是否在讲故事？  
- [ ] 手势是否自然、有节奏？  
- [ ] 面部表情是否丰富？  
- [ ] 是否有小动作/抖动？  
  
### 回看检查（打开声音）  
- [ ] 语调是否有起伏？  
- [ ] 重音是否砸实？  
- [ ] 语速是否合适？  
- [ ] 是否有口头禅/嗯啊等？  
  
### 整体评估  
- [ ] 能否在3秒内抓住注意力？  
- [ ] 能否在60秒内讲完一个完整故事？  
- [ ] 是否有记忆点/金句？  
- [ ] 结尾是否有钩子？  
  
---  
  
## 9.7 发布前检查清单  
  
### 标题优化  
- [ ] 是否包含数字/反差/痛点？  
- [ ] 是否在20字以内？  
- [ ] 是否有吸引力？  
  
### 封面优化  
- [ ] 是否清晰、有冲击力？  
- [ ] 是否与内容相关？  
- [ ] 是否有文字提示？  
  
### 标签优化  
- [ ] 是否添加了3-5个相关标签？  
- [ ] 是否包含热门话题？  
- [ ] 是否包含精准关键词？  
  
### 发布时间  
- [ ] 是否选择了目标受众活跃时段？  
- [ ] 是否避开了平台流量低谷？  
  
---  
  
## 速查表：常见问题快速定位  
  
### 如果3秒留存<50%  
- [ ] 检查钩子是否够痛/够反差  
- [ ] 检查前3秒是否有无效开场  
- [ ] 检查语速是否够快  
  
### 如果完播率<30%  
- [ ] 检查是否讲了多个问题  
- [ ] 检查转折是否在30-60秒  
- [ ] 检查金句是否突出  
  
### 如果互动率<5%  
- [ ] 检查互动问题是否太难  
- [ ] 检查是否引导了具体行动  
- [ ] 检查结尾是否有钩子  
  
### 如果观众觉得"怪怪的"  
- [ ] 检查梅拉宾三要素是否一致  
- [ ] 检查台词、手势、表情是否统一  
- [ ] 检查情绪是否自然

## 快速参考：核心标准速查  
  
### 语速标准（字/分钟）  
- 知识科普：150-180  
- 情感共鸣：180-220  
- 剧情演绎：120-160  
- 产品介绍：200-240  
  
### 手势频率  
- 每30秒至少1次具象化手势  
  
### 钩子类型  
- 痛点型：你有没有遇到过______？  
- 反差型：别人都说______，其实______。  
- 悬念型：我发现了______的秘密。  
- 数字型：3天/5个方法/1个技巧，______。  
  
### 互动问题  
- 二选一最优：你觉得A和B，谁更______？敲1或2
