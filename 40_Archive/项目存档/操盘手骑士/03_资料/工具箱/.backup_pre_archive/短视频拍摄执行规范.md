# 短视频拍摄执行规范

> **定位**：操盘手骑士短视频的通用拍摄执行规范，适用于所有系列。
> **用途**：创作者拍摄时的执行 Checklist。
> **来源**：提取自已归档的 [[【已废弃】创世纪系列修订版_对外脚本_2026-06-30]]，并整合后续版本中的通用规范。


## 一、时长控制

- 严格 60 秒以内
- 追求信息密度，不注水
- 核心观点在前 15 秒说完


## 二、BGM 选择

- 选用带"史诗感/神圣感"的纯音乐
- 整体音量压低，不盖人声
- 金句处做情绪强化（音量微升或加音效）


## 三、剪辑节奏

- 快切为主
- 每个重音、每个金句配放大字幕
- 关键转折处加轻微音效（如"咚"一声）


## 四、肢体语言

- 保留指屏幕、皱眉、摊手、前倾等自然动作
- 不要刻意表演，保持真实感
- 直视镜头建立信任感（开头 0-3 秒）


## 五、字幕风格

- 黑底白字或透明底描边
- 字体方正有力（推荐：思源黑体 Heavy）
- 关键词用黄色/金色高亮
- 金句放大 + 描边强调


## 六、封面设计

- 大字标题，信息清晰
- 视觉冲击力优于美观度
- 标题不超过 15 字


## 七、发布检验

- 核心指标：3 秒完播率
- 评论观测：寻找"说得太对了""这就是我"等共鸣型评论
- 数据偏冷时调整开头更口语化，核心观点保持不变

## 八、表演指导细则

> **来源**：提取自 [[蓝色日·打开视野_脚本原型]]

### 语速控制

| 效果 | 技法 |
|:---|:---|
| 建立信任 | 语速平稳，重音拖长 |
| 制造冲击 | 短促有力（如"啪"） |
| 制造悬念 | 压低声音，放慢语速 |
| 表达讽刺 | 语调转辛辣，层层递进 |
| 扎心一击 | 陡然沉降，一字一顿 |
| 互动收尾 | 上扬收住，等观众反应 |

### 动作设计

| 效果 | 技法 |
|:---|:---|
| 强调重点 | 目视镜头，右手食指竖起 |
| 展开概念 | 双手缓缓打开，或从一侧划过 |
| 制造转折 | 右手拍桌面，身体前倾 |
| 表达无奈 | 摊手耸肩 |
| 视觉化比喻 | 做对应手势（如握电筒） |
| 收尾定格 | 身体坐正，双手收回，定格 |

### 情绪标注格式

写稿时使用以下标注，拍摄时对照执行：

- 🎤 标注语调、语速、重音、情绪转折
- 🎬 标注手势、身体姿态、眼神方向、道具使用
- 📝 逐字稿正文

### 使用原则

- 表演指导服务于内容，不喧宾夺主
- 保持真实感——动作是思考的副产品，不是设计的结果
- 录制后回看：关掉声音看是否自然，打开声音听是否像聊天
