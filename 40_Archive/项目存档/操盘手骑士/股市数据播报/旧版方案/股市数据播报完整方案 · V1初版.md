## 一、项目定位

### 1.1 为什么做

操盘手每天开盘前最需要的不是分析，是**看清楚市场正在发生什么**。数据播报是所有交易决策的起点——先知道，再判断，后行动。

### 1.2 做什么

每天早上，用3-5分钟口播，告诉股民和交易员：
- 大盘现在什么位置
- 涨跌情况如何（多少人赚钱、多少人亏钱）
- 钱在往哪里流（哪些板块热、哪些板块冷）
- 跟昨天比有什么变化

### 1.3 用户是谁

- 每天开盘前需要快速了解市场全貌的散户
- 需要固定信息来源而不是刷几十个网页的交易员
- 想养成操盘手骑士/直播稿习惯但不知道从哪开始的操盘手

### 1.4 最终产出

- 一份固定格式的每日数据播报表（口播脚本）
- 一套从数据获取到发布的完整工作流
- 一个可以交给任何员工直接执行的SOP


## 二、播报核心数据清单

### 2.1 市场全景

| 数据 | 说明 | 为什么重要 |
| :--- | :--- | :--- |
| 上证指数 | 收盘点位、涨跌幅、成交量 | A股最核心的风向标 |
| 深证成指 | 收盘点位、涨跌幅、成交量 | 代表深市整体表现 |
| 创业板指 | 收盘点位、涨跌幅、成交量 | 代表成长股、小盘股情绪 |

### 2.2 涨跌结构

| 数据           | 说明           | 为什么重要         |
| :----------- | :----------- | :------------ |
| 上涨家数 vs 下跌家数 | 全市场多少只涨、多少只跌 | 真实赚钱效应，比指数更诚实 |
| 涨停家数         | 不含ST的涨停数量    | 市场情绪热度指标      |
| 跌停家数         | 不含ST的跌停数量    | 市场恐慌程度指标      |
| 涨幅>5%家数      | 强势股数量        | 赚钱效应的宽度       |
| 跌幅>5%家数      | 弱势股数量        | 亏钱效应的宽度       |

### 2.3 资金流向

| 数据 | 说明 | 为什么重要 |
| :--- | :--- | :--- |
| 两市成交额 | 沪深合计成交金额 | 市场参与度，万亿以上才算活水 |
| 北向资金 | 沪股通+深股通净流入/流出 | 外资动向，聪明的钱 |
| 主力资金净流入 | 大单净流入金额 | 机构和游资的方向 |
| 行业板块资金流入TOP3 | 当日资金最热的三个板块 | 热点在哪 |
| 行业板块资金流出TOP3 | 当日资金最冷的三个板块 | 钱从哪撤 |

### 2.4 简单情绪指标

| 数据 | 说明 | 为什么重要 |
| :--- | :--- | :--- |
| 昨日成交量与今日对比 | 环比变化 | 热了还是冷了 |
| 连板高度 | 市场最高连板数 | 游资活跃度的温度计 |
| 炸板率 | 涨停后打开的比例 | 追涨风险有多大 |


## 三、数据源方案

### 3.1 免费数据源（推荐优先使用）

| 数据源 | 覆盖数据 | 获取方式 | 难度 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **AkShare** | 全部核心数据 | Python API | ⭐⭐ 中等 | 主力数据源，覆盖面最广 |
| **东方财富网页** | 涨幅榜、资金流向 | 网页抓取/手动 | ⭐ 简单 | 备选方案，数据验证 |
| **同花顺 iFinD** | 全部核心数据 | 网页/客户端 | ⭐ 简单 | 手动备选，数据准确 |
| **新浪财经** | 大盘指数、涨跌家数 | 网页 | ⭐ 简单 | 快速核对 |

### 3.2 付费数据源（长期运营后升级）

| 数据源             | 覆盖数据      | 费用             | 优势          |
| :-------------- | :-------- | :------------- | :---------- |
| **Tushare Pro** | 全部数据 + 历史 | 积分制（可免费获取基础积分） | 稳定性好，文档完善   |
| **Wind终端**      | 全部数据 + 研报 | 数万元/年          | 机构级，但成本太高   |
| **Choice数据**    | 全部数据 + 研报 | 数千元/年          | Wind平替，性价比高 |

### 3.3 推荐技术方案

**第一阶段（低成本启动）**：AkShare + 东方财富网页验证
- 用Python写一个脚本，每天早上运行，自动拉取数据，输出到固定格式的Excel或Markdown表格
- 人工核对关键数据（涨跌幅、成交额）与东方财富网页是否一致

**第二阶段（稳定后升级）**：Tushare Pro
- 数据稳定性和准确性更好
- 支持历史数据回溯，可以做“跟昨天比”的环比


## 四、播报脚本结构

### 4.1 固定口播模板

```
各位早上好，今天是X月X日星期X。先看昨天收盘数据。

【大盘位置】
上证指数报收XXXX点，涨/跌XX%，成交XXXX亿。
深证成指报收XXXX点，涨/跌XX%，成交XXXX亿。
创业板指报收XXXX点，涨/跌XX%，成交XXXX亿。

【赚钱效应】
全市场上涨XXXX家，下跌XXXX家。
涨停XX家（不含ST），跌停XX家。
涨幅超过5%的XX家，跌幅超过5%的XX家。
——简单说，昨天赚到钱的人多还是亏钱的人多。

【资金去哪了】
两市合计成交XXXX亿（跟昨天比增加/减少了XX亿）。
北向资金净流入/流出XX亿（连续X天流入/流出）。
板块方面，资金流入前三：XX、XX、XX。
资金流出前三：XX、XX、XX。

【简单一句总结】
（根据数据给出一个方向性判断，例如：市场偏暖，但资金集中在少数板块 / 赚钱效应差，观望为主）

以上是今天盘前数据，具体操作我们盘中直播见。
```

### 4.2 播报时长
- 完整版：3-5分钟（直播/视频用）
- 精简版：1-2分钟（短视频/图文用，只保留大盘+涨跌比+成交额+北向）

### 4.3 播报风格

| 维度 | 要求 |
| :--- | :--- |
| 语速 | 中速偏快，保持节奏感 |
| 语调 | 客观陈述为主，情绪化判断放在最后的“一句话总结” |
| 时长 | 控制在5分钟以内 |
| 禁忌 | 不说“我觉得会涨/会跌”；不给具体买卖建议 |


## 五、数据获取技术方案

### 5.1 AkShare 核心接口

```python
# 大盘指数
import akshare as ak
df = ak.stock_zh_index_日志(symbol="sh000001")  # 上证指数

# 涨跌家数
df = ak.stock_zh_index_日志_tx()  # 包含上涨、下跌、平盘家数

# 北向资金
df = ak.stock_hsgt_north_net_flow_in_em()  # 北向净流入

# 行业资金流向
df = ak.stock_sector_fund_flow_summary()  # 行业板块资金

# 涨停板
df = ak.stock_zt_pool_em(date="20260101")  # 涨停池
```

### 5.2 自动化工作流
1. 每天早上8:00，Python脚本自动运行
2. 调用AkShare接口拉取所有数据
3. 计算环比（与前一天对比）
4. 填充到固定格式的口播模板中
5. 输出为Markdown文件，存入 `10_Projects/每日播报/` 文件夹
6. 丁萌（或值班员工）核对关键数据后发布

### 5.3 备用方案（API故障时）
- 打开东方财富首页，手动获取大盘指数
- 打开同花顺，查看涨跌家数、成交额、北向资金
- 手动填写模板，10分钟内可完成


## 六、与工具箱的联动

| 播报数据 | 对应工具箱 | 触发提醒 |
| :--- | :--- | :--- |
| 涨停家数激增 | 遍地黄金（第6集） | 注意“全都是机会”的幻觉 |
| 跌停家数激增 | 全烂透了（第5集） | 恐慌时别关掉眼睛 |
| 北向资金连续流出 | 设立时令（创世纪第4天） | 冬天来了，该冬眠存子弹 |
| 成交额持续萎缩 | 安息圣日（创世纪第7天） | 空仓是顶级利润 |
| 板块轮动加速 | 纸上谈兵（第9集） | 不是形态不对，是战场变了 |
| 炸板率飙升 | 涨停接盘侠（第7集） | 涨停板是给你卖的 |
