## 一、项目定位

### 1.1 为什么做

操盘手每天最需要的不是分析，是看清楚市场正在发生什么。数据播报是所有交易决策的起点——先知道，再判断，后行动。

### 1.2 做什么

每天早晚各一次，用3-5分钟口播，告诉股民和交易员：
- 大盘现在什么位置
- 涨跌情况如何（多少人赚钱、多少人亏钱）
- 钱在往哪里流（哪些板块热、哪些板块冷）

- **早盘**：回顾昨天收盘数据，为今天开盘做准备
- **晚盘**：总结今天盘中数据，为明天提供参考

### 1.3 用户是谁

- 每天开盘前需要快速了解市场全貌的散户
- 需要固定信息来源而不是刷几十个网页的交易员
- 想养成操盘手骑士/直播稿习惯但不知道从哪开始的操盘手

### 1.4 最终产出

- 早晚各一份固定格式的数据播报表（口播脚本）
- 一套从数据获取到发布的完整工作流
- 一个可以交给任何员工直接执行的SOP


## 二、早盘播报

**播报时间**：每天早上开盘前（8:30-8:45采集数据，9:00前完成录制）
**数据依据**：昨日收盘数据
**核心功能**：回顾昨天，为今天开盘做准备

### 2.1 早盘数据清单

| 数据 | 说明 | 为什么重要 |
| :--- | :--- | :--- |
| 上证指数 | 收盘点位、涨跌幅、成交额 | A股风向标 |
| 深证成指 | 收盘点位、涨跌幅、成交额 | 深市整体表现 |
| 创业板指 | 收盘点位、涨跌幅、成交额 | 成长股情绪 |
| 上涨家数 vs 下跌家数 | 全市场涨跌比 | 真实赚钱效应 |
| 涨停家数 / 跌停家数 | 不含ST | 情绪热度 / 恐慌程度 |
| 两市成交额 | 沪深合计 | 市场参与度 |
| 北向资金 | 沪股通+深股通净流入/流出 | 外资动向 |
| 行业资金流入TOP3 | 昨天钱去哪了 | 热点板块 |
| 行业资金流出TOP3 | 昨天钱从哪撤 | 冷门板块 |

### 2.2 早盘数据获取

| 序号 | 数据项 | 数据源 | 操作 |
| :--- | :--- | :--- | :--- |
| 1 | 上证/深证/创业板 | 新浪财经 finance.sina.com.cn | 首页抄收盘点位、涨跌幅、成交额 |
| 2 | 涨跌家数 | 东方财富 quote.eastmoney.com | 首页“市场概况”栏 |
| 3 | 涨停/跌停家数 | 同花顺 10jqka.com.cn | 行情中心→涨跌榜，选“不含ST” |
| 4 | 两市成交额 | 东方财富 | 市场概况栏沪深合计 |
| 5 | 北向资金 | 东方财富 data.eastmoney.com/hsgt | 沪股通+深股通净流入合计 |
| 6 | 行业资金TOP3 | 同花顺 | 行情中心→板块资金，看行业板块 |

### 2.3 早盘口播模板

```
各位早上好，今天是__月__日星期__。先看昨天收盘数据。

大盘位置
上证__点，涨/跌__%，成交__亿。
深证__点，涨/跌__%，成交__亿。
创业板__点，涨/跌__%，成交__亿。

赚钱效应
昨天上涨__家，下跌__家。
涨停__家，跌停__家。
——赚到钱的人比亏钱的人__。

资金去哪了
两市成交__亿，比前天__了__亿。
北向资金净__出__亿。
钱流入前三：__、__、__。
钱流出前三：__、__、__。

一句话
__。

今天开盘见。
```

### 2.4 早盘一句话判断规则

| 数据特征         | 判断方向                |
| :----------- | :------------------ |
| 涨>跌 且 涨停>50  | “昨天赚钱效应不错，今天关注能否持续” |
| 涨>跌 但 涨停<30  | “指数好看但赚钱的人不多，资金集中”  |
| 跌>涨          | “昨天亏钱的人多，今天先看半小时”   |
| 成交额比前天少20%以上 | “缩量明显，资金在等”         |
| 北向连续3天流出     | “外资在撤，注意风险”         |
| 北向连续3天流入     | “外资持续买，情绪偏暖”        |


## 三、晚盘播报

**播报时间**：每天收盘后（15:00-15:30采集数据，16:00前完成录制）
**数据依据**：今日盘中数据
**核心功能**：总结今天，为明天提供参考

### 3.1 晚盘数据清单

| 数据 | 说明 | 为什么重要 |
| :--- | :--- | :--- |
| 上证指数 | 收盘点位、涨跌幅、成交额 | 今日最终结果 |
| 深证成指 | 收盘点位、涨跌幅、成交额 | 深市今日表现 |
| 创业板指 | 收盘点位、涨跌幅、成交额 | 成长股今日情绪 |
| 上涨家数 vs 下跌家数 | 今日涨跌比 | 今天真实赚钱效应 |
| 涨停家数 / 跌停家数 | 不含ST | 今日情绪高点/冰点 |
| 炸板家数 | 涨停后被打开的 | 追涨风险有多高 |
| 两市成交额 | 沪深合计 | 今天资金参与度 |
| 成交额与昨日对比 | 环比变化 | 市场在变热还是变冷 |
| 北向资金 | 今日净流入/流出 | 外资今天动了多少 |
| 行业板块涨幅TOP3 | 今日涨最好的板块 | 哪些在领涨 |
| 行业板块跌幅TOP3 | 今日跌最多的板块 | 哪些在领跌 |
| 行业资金流入TOP3 | 今日资金去哪了 | 今日热点 |
| 行业资金流出TOP3 | 今日资金从哪撤 | 今日冷门 |

### 3.2 晚盘数据获取

| 序号 | 数据项 | 数据源 | 操作 |
| :--- | :--- | :--- | :--- |
| 1 | 上证/深证/创业板 | 新浪财经 | 收盘后刷新，抄收盘点位、涨跌幅、成交额 |
| 2 | 涨跌家数 | 东方财富 | 收盘后刷新，抄上涨/下跌家数 |
| 3 | 涨停/跌停/炸板 | 同花顺 | 行情中心→涨跌榜，选“不含ST” |
| 4 | 两市成交额 | 东方财富 | 沪深合计 |
| 5 | 成交额环比 | 手动计算 | 今日成交额 vs 昨日成交额 |
| 6 | 北向资金 | 东方财富 | 收盘后抄沪股通+深股通合计 |
| 7 | 板块涨幅/跌幅TOP3 | 同花顺 | 行情中心→板块排行 |
| 8 | 行业资金TOP3 | 同花顺 | 行情中心→板块资金 |

### 3.3 晚盘口播模板

```
各位下午好，今天是__月__日星期__。刚收盘，看今天数据。

大盘结果
上证收__点，涨/跌__%，成交__亿。
深证收__点，涨/跌__%，成交__亿。
创业板收__点，涨/跌__%，成交__亿。

赚钱效应
今天上涨__家，下跌__家。
涨停__家，跌停__家，炸板__家。
——赚到钱的人比亏钱的人__。
——追涨停的人，有__家被炸开了。

钱去哪了
两市成交__亿，比昨天__了__亿。
北向资金今天净__出__亿。
板块涨幅前三：__、__、__。
板块跌幅前三：__、__、__。
资金流入前三：__、__、__。
资金流出前三：__、__、__。

一句话
__。

明天见。
```

### 3.4 晚盘一句话判断规则

| 数据特征 | 判断方向 |
| :--- | :--- |
| 涨停>50 且 炸板率<20% | “今天情绪好，明天可延续” |
| 涨停>50 但 炸板率>30% | “情绪看着好但追高风险大” |
| 跌>涨 且 涨停<20 | “今天偏冷，明天谨慎” |
| 成交额比昨天放大30%以上 | “资金进来了，是好事还是出逃要看方向” |
| 成交额比昨天缩小30%以上 | “资金在撤，量没了” |
| 北向尾盘大幅流入 | “外资尾盘抄了，关注明天早盘” |
| 北向全天持续流出 | “外资一整天都在卖，注意” |
| 板块一天换一批 | “没有持续性，追涨容易接盘” |

## 五、操作SOP

### 5.1 早盘操作流程

| 步骤 | 时间 | 动作 |
| :--- | :--- | :--- |
| 1 | 8:30 | 打开新浪财经、东方财富、同花顺三个网页 |
| 2 | 8:30-8:40 | 按早盘数据获取表逐项抄录 |
| 3 | 8:40-8:45 | 填入早盘口播模板，写一句话总结 |
| 4 | 8:45 | 文件命名为 `2026-05-XX-早盘.md`，存入 `每日播报/` |
| 5 | 9:00前 | 录制/直播口播 |

### 5.2 晚盘操作流程

| 步骤 | 时间 | 动作 |
| :--- | :--- | :--- |
| 1 | 15:00 | 收盘后刷新三个网页 |
| 2 | 15:00-15:15 | 按晚盘数据获取表逐项抄录 |
| 3 | 15:15-15:20 | 计算成交额环比（今日÷昨日-1） |
| 4 | 15:20-15:25 | 填入晚盘口播模板，写一句话总结 |
| 5 | 15:25 | 文件命名为 `2026-05-XX-晚盘.md`，存入 `每日播报/` |
| 6 | 16:00前 | 录制/直播口播 |
