> **适用环境**：Windows 10
> **预计耗时**：15 分钟
> **你的腾讯云账号**：APPID = 1309120115

## 第一步：创建图床专用存储桶

1. 打开 https://console.cloud.tencent.com/cos
2. 点击「创建存储桶」
3. 填写配置：

| 配置项 | 填写内容 |
|:---|:---|
| **名称** | `obsidian-image-bed-1309120115`（全局唯一，不会冲突） |
| **所属地域** | 选择离你最近的地域，比如「广州」（ap-guangzhou） |
| **访问权限** | **选「公有读私有写」**（这是最关键的一步） |
| **其他选项** | 全部保持默认，**取消所有已勾选的额外付费服务** |

4. 点击「确定」创建
5. 创建成功后，在存储桶列表中找到这个桶，记下右上角的**「存储桶名称」**（`obsidian-image-bed-1309120115`）和**「所属地域」**（如 `ap-guangzhou`）

## 第二步：创建子账号并授权（仅限这个桶）

### 2.1 创建自定义策略

1. 打开 https://console.cloud.tencent.com/cam/policy
2. 点击「新建自定义策略」→「按策略语法创建」
3. 选择「空白模板」
4. 粘贴以下内容（**注意替换桶名**obsidian-image-bed-1309120115）：

```json
{
  "version": "2.0",
  "statement": [
    {
      "effect": "allow",
      "action": [
        "cos:PutObject",
        "cos:GetObject"
      ],
      "resource": [
        "qcs::cos:ap-guangzhou:uid/1309120115:obsidian-image-bed-1309120115/*"
      ]
    }
  ]
}
```

5. 策略名称填：`PicGo-ImageBed-Policy`
6. 点击「完成」

### 2.2 创建子账号

1. 打开 https://console.cloud.tencent.com/cam/user
2. 点击「新建用户」→「自定义创建」
3. **选择用户类型**：选「可访问资源并接收消息」，下一步
4. **填写用户信息**：
   - 用户名：`picgo-uploader`
   - **勾选「编程访问」**，**取消勾选「控制台访问」**
5. **设置权限**：搜索刚才创建的 `PicGo-ImageBed-Policy`，勾选上
6. 点击「完成」
7. **创建成功后，会弹出一个窗口显示 SecretID 和 SecretKey，复制保存好**（关闭后就看不到了）
8. 主账号 ID 1309120115 用户名 picgo-uploader 登录密码 - SecretId `<REDACTED>` SecretKey `<REDACTED>` 快捷登录 https://cloud.tencent.com/login/subAccount/100023203758?type=subAccount&username=picgo-uploader

## 第三步：安装 PicGo

1. 打开 https://github.com/Molunerfinn/PicGo/releases
2. 找到最新版本（v2.5.3），下载 `PicGo-Setup-2.5.3-x64.exe`
3. 安装，一路「下一步」即可
4. 安装完成后打开 PicGo

---

## 第四步：配置 PicGo 连接腾讯云 COS

1. 打开 PicGo，点击左侧「图床设置」
2. 找到「腾讯云 COS」，点击

3. 填写以下配置（**注意不要多填不要少填**）：

| 配置项 | 填写内容 |
|:---|:---|
| **COS 版本** | 选 `V5` |
| **SecretID** | 粘贴刚才子账号的 SecretID |
| **SecretKey** | 粘贴刚才子账号的 SecretKey |
| **存储桶名** | `obsidian-image-bed-1309120115`（**纯桶名**，不要带 `.cos.` 后缀） |
| **存储区域** | `ap-guangzhou`（**纯地域简写**，不要写完整域名） |
| **存储路径** | 留空（不填） |

4. 点击「确定」保存

---

## 第五步：验证图床

1. 在 PicGo 左侧切换到「上传区」
2. 确认顶部图床切换为「腾讯云 COS」
3. 随便拖一张图片进去
4. 如果上传成功，会显示绿色勾，并生成一个 URL

**检查 URL 格式**：
- ✅ 正确格式：`https://obsidian-image-bed-1309120115.cos.ap-guangzhou.myqcloud.com/xxx.png`
- ❌ 错误格式：如果 URL 后面带了 `?Expires=`、`?Signature=` 等参数，说明配置有误

**如果 URL 带签名参数**：
- 检查存储桶权限是否设为「公有读私有写」
- 如果还是不行，把 PicGo 的腾讯云 COS 配置删掉重新填一遍

## 第六步：安装 Obsidian 插件

### 先装 Paste Image Rename

1. 在 Obsidian 中按 `Ctrl+P`，搜索「社区插件」
2. 搜索 `Paste Image Rename`
3. 安装并启用
4. **进入插件设置，配置默认命名模板**：`{{date:YYYYMMDD-HHmmss}}`

### 再装 Image Auto Upload

1. 搜索 `Image Auto Upload Plugin`
2. 安装并启用
3. 进入插件设置，找到「上传失败时的行为」→ 设为 **「保留本地附件」**

## 第七步：验证整条链路

1. 打开或新建一篇笔记
2. 按 `Ctrl+V` 粘贴一张截图
3. 观察是否弹出 Paste Image Rename 的命名窗口（如果你配置了才会弹）
4. 片刻后，笔记中会自动插入一个以 `https://obsidian-image-bed-...` 开头的图片链接
5. 点击这个链接，图片能在浏览器中打开，说明图床搭建成功

## 可选：安装完毕后关闭 PicGo 开机自启

1. 在 PicGo 右下角托盘图标右键
2. 选「设置」
3. 关闭「开机自启」

PicGo 关掉后，只要你 Obsidian 开着，粘贴图片依然会自动调用 PicGo 上传。不需要它常驻后台。

## 常见问题

**Q：粘贴后没反应，没上传**
A：检查 PicGo 是否打开，图床是否切换为「腾讯云 COS」

**Q：上传成功但图片显示不出来**
A：检查存储桶权限是否为「公有读私有写」

**Q：想上传到子目录**
A：在 PicGo 的「存储路径」填 `blog/` 或 `notes/`（末尾要加斜杠）

**Q：以后换电脑怎么办**
A：用 PicGo Cloud 功能，登录账号同步配置

## 故障排查指引

| 现象 | 原因 | 解决 |
|:---|:---|:---|
| 存储桶创建失败，提示名称已存在 | 桶名全局唯一，有人用了 | 名称后面加随机数字，如 `obsidian-image-bed-1309120115-v2` |
| 上传失败，提示 403 | 密钥权限不对 | 检查子账号是否关联了策略，策略 JSON 中的桶名和地域是否正确 |
| 上传失败，提示 Bucket 不存在 | 桶名或区域填错了 | 检查 PicGo 配置中的桶名和区域（纯地域简写，不要完整域名） |
| 上传成功，URL 带签名参数 | 存储桶权限不是「公有读私有写」 | 去 COS 控制台修改桶权限 |
| 命名窗口不弹出 | Paste Image Rename 没装或没启用 | 检查插件列表，确认插件已启用 |
