# 行为追踪系统说明书

> **系统类型**：Bullet Journal + Atomic Habits 融合系统
> **数据源**：日记文件中的习惯打卡行
> **自动化程度**：95%（日记生成 + 数据聚合 + Insight 分析）

---

## 一、系统架构概览

### 核心理念

这是一个**单一数据源**的习惯追踪系统：
- ✅ 所有习惯数据都记录在每日日记中
- ✅ Habit Tracker 展示 Dataview 聚合看板
- ✅ Collector 分流自动处理 [H][T] 标记
- ✅ Insight 自动分析周/月习惯趋势

### 关键组件

| 组件 | 路径 | 作用 |
|:---|:---|:---|
| Daily Log 模板 | `90_System/91_Templates/Bullet Journal/Bullet Journal · Daily Log · Template.md` | 日记模板（含习惯打卡区） |
| 日记文件 | `20_Areas/A2_能力接口/Bullet Journal/Daily/YYYY-MM/YYYY-MM-DD-Daily-Log.md` | 每日日记（数据源） |
| Habit Tracker | `20_Areas/A2_能力接口/Atomic Habits/Habit Tracker/Monthly/` | 月度习惯记分卡 |
| Daily Insight | `20_Areas/A2_能力接口/Insight/Daily/Insight · Daily — 今日.md` | 每日习惯分析 |
| Weekly Insight | `20_Areas/A2_能力接口/Insight/Weekly/` | 每周习惯趋势 |
| Collector | `00_Inbox/Collector.md` | [H] 习惯扫描入口 |

- 习惯打卡
- 睡前三口气

## 四、习惯打卡区

### 三习惯标签（固定，永久不变）

```markdown
- [ ] [habit:: 曦·启明·以守筑基] — 膈肌呼吸 2min + 收下巴自检 ×5
- [ ] [habit:: 午·承势·以执笃行] — 完成最重要那件事（先投一票）
- [ ] [habit:: 夕·观成·以校归正] — 复盘 + 丢弃烦恼
```

**标签含义**：

| 标签 | 时段 | 核心动作 |
|:---|:---|:---|
| 曦·启明·以守筑基 | 晨间 | 呼吸 + 收下巴自检 |
| 午·承势·以执笃行 | 上午 | 先投一票（完成最重要的事） |
| 夕·观成·以校归正 | 睡前 | 复盘 + 丢弃烦恼 |

### 训练折叠块

日记模板底部包含 `🏋️ 上交叉矫正训练` 的 `<details>` 折叠块，记录每日训练数据（晨间/正式训练/工位重置/晚间复盘）。非训练日可跳过。

## 六、Habit Tracker 看板

**位置**：`20_Areas/A2_能力接口/Atomic Habits/Habit Tracker/Monthly/YYYY-MM Habit Tracker.md`

**数据源**：每日日记中的 `[habit::]` 完成情况。看板为月度汇总。

### 工作原理

1. Agent 每月 1 日从模板 `Habit Tracker · Template.md` 复制生成当月看板
2. 习惯完成状态在 BuJo 日记中勾选
3. Insight cron 自动分析习惯投票率

## 七、符号系统

| 符号 | Markdown 写法 | 含义 |
|:---|:---|:---|
| • | `- [ ]` | 任务（未完成） |
| ✔ | `- [x]` | 任务完成 |
| > | `>` 或 `- [ ] >` | 迁移到未来/其他日期 |
| < | `- [ ] <` | 计划中（日程待定） |
| 👁 | `- !` | 事件 |
| 📝 | `- Note` | 普通笔记 |
| * | `*` 重点 / C 检查 | 优先标记或检查确认项 |

## 八、常见问题

### Q1：日记文件存在哪里？

`20_Areas/A2_能力接口/Bullet Journal/Daily/YYYY-MM/YYYY-MM-DD-Daily-Log.md`

### Q2：习惯怎么打？

在日记的习惯打卡区勾选：
```markdown
- [x] [habit:: 曦·启明·以守筑基]
- [x] [habit:: 午·承势·以执笃行]
- [x] [habit:: 夕·观成·以校归正]
```

### Q3：Collector [H] 是什么？

`Collector.md` 中用 `[H]` 标记的习惯条目，Agent 每日 8/12/18 点自动扫描并分流到 Habit Tracker。

### Q4：训练折叠块在哪里？

在日记底部的 `<details><summary>🏋️ 上交叉矫正训练 · 今日记录</summary>` 区块，填入当天的训练数据。
