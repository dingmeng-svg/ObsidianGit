## 一、这是什么知识库？

这是一个 **PARA × Zettelkasten × Bullet Journal × Atomic Habits** 四体系融合的个人知识管理系统。

**核心理念**：
- 知识库不是仓库，而是**思想接口**
- 每一条笔记都是**与自己未来的一次对话邀请**
- 书写即思考，AI 辅助但不替代

## 三、日常使用流程

### 每天早上

1. **打开今日日记**：`20_Areas/A2_能力接口/Bullet Journal/Daily/2026-07/2026-07-28-Daily-Log.md`
2. **习惯打卡**：勾选晨间习惯 `[habit:: 曦·启明·以守筑基]`
3. **填写今日优先任务**（最多 3 件）
4. **睡前三口气**：完成晚间反思和习惯打卡

### 工作过程中

1. **闪念捕获**：随时在 `Collector.md` 用 `[N]` 记录，或在日记闪念区记录
2. **项目工作**：在 `10_Projects/` 下记录进展
3. **知识提炼**：发现可复用的概念时，提炼为原子笔记存入 `31_Atomic_Notes/`

### 定期复盘

| 周期 | 内容 | 文件 |
|:---|:---|:---|
| 每日 22:00 | Daily Insight（自动） | `A2_能力接口/Insight/Daily/` |
| 周日 21:00 | Weekly Insight（自动） | `A2_能力接口/Insight/Weekly/` |
| 月末 21:00 | Monthly Insight（自动） | `A2_能力接口/Insight/Monthly/` |
| 手动 | BuJo 周/月/季复盘 | `Bullet Journal/Weekly/` |

### Collector 分流

- `[T] 任务` → 每日 8/12/18 点自动分流到今日日记
- `[T] 任务 @项目` → 分流到项目文档 + 今日日记
- `[T] 任务 #习惯` → 分流到 Habit Tracker

## 四、笔记规范（核心铁律）

### YAML 头部（必填字段）

```yaml
---
title: 笔记标题
date: 2026-07-28
status: active          # active / draft / archived
tags:
  - 标签名              # 从 20 种标签中选择
related:
  - "[[相关笔记]]"
---
```

### 命名规范

- **文件名**：最简 + 一眼看懂 + 永不再改
- **日记**：`YYYY-MM-DD-Daily-Log.md`
- **Worklog**：`YYYY-MM-DD-Worklog.md`
- **原子笔记**：纯概念名（如 `认知负荷理论.md`）
- **语言组块**：`01. name.md`（带序号）
- **模板**：`名称 · Template.md`
- **Insight**：`Insight · Daily — 今日.md`（入口）/ `YYYY-MM-DD-Insight.md`（归档）

### 标签系统（20 种）

**10 核心标签**：`MOC` `project` `area` `resource` `note` `concept` `model` `practice` `critique` `refrence`
**10 功能性标签**：`想法` `待办` `复盘` `洞察` `习惯` `健身` `饮食` `学习` `系统文档` `语言`

## 五、特殊笔记类型

### 原子笔记（Atomic Notes）

**位置**：`30_Resources/31_Atomic_Notes/{领域}/{类型}/`

**特点**：
- 一条笔记只讲一个概念
- 通过 `related` 字段连接其他笔记
- 类型分：concept / model / practice / critique / reference

### 语言组块（Language Chunk）

**位置**：`30_Resources/31_Atomic_Notes/语言/concept/`（公共层）
也可放在项目产出目录（如 `操盘手骑士/05_产出/金融英语/Language Chunks/`）

**特点**：
- 包含词源故事、核心边界、隐喻锚点、间隔重复卡片

**七维框架**：观全局 → 察潜流 → 拂遗珠 → 照暗面 → 辨风势 → 测热力 → 践一诺

## 六、AI 协作机制

### Agent 能做什么

- ✅ 创建笔记、维护标签、修复断链
- ✅ 批量处理文件、更新 YAML 元数据
- ✅ 执行 Lint 检查、生成审计报告
- ✅ 生成 Insight、整理 Inbox、分流 Collector
- ✅ 提取原子笔记

### Agent 不能做什么

- ❌ 删除文件（必须请示）
- ❌ 覆盖 `human_edited: true` 的笔记正文
- ❌ 修改系统文档（需先备份）
- ❌ 删除 `_raw/` 中的源文件

### 习惯三标签（固定）

三条习惯标签永久固定，对应三个时段身份：

```
[habit:: 曦·启明·以守筑基]  — 晨间（收下巴自检 + 膈肌呼吸）
[habit:: 午·承势·以执笃行]  — 上午（先投一票）
[habit:: 夕·观成·以校归正]  — 睡前（复盘 + 丢弃烦恼）
```
