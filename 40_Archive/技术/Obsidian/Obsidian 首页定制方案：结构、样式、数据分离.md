# Obsidian 首页定制方案：结构、样式、数据分离

> 外部教程摘要。核心思路：用 `首页.md` 搭结构、CSS 片段做美化、Dataview 插件让数据动态化、AI（Cursor）辅助写代码。归档备查。

---

## 核心思路

**结构、样式、数据三者分离**——页面骨架用 Markdown，颜值用 CSS，动态数据用 Dataview，AI 辅助生成代码和内容。

## 所需插件

| 插件 | 用途 |
|:---|:---|
| **Homepage** | 设置 Obsidian 启动时自动打开指定首页 |
| **Dataview** | 从笔记库中动态查询和抓取数据（最新文章、待办任务等） |
| **Heatmap Calendar** | 生成笔记活跃度的“注意力热力图” |

## 首页结构

首页分两大块：

- **操作台**：包含“今日行动”（待办）、“今日输入”和“今日输出”三个卡片
- **洞察镜**：展示 AI 生成的“七维分析”报告

基础框架示例：

```markdown
# 我的知识工作台

## 操作台
### ✅ 今日待办
- [ ] 任务1

### 📥 今日输入
![[最近创建的笔记]]

### 📤 今日输出
![[最近修改的笔记]]

## 洞察镜
!当日
```

## 实现步骤

1. **安装插件**：Homepage、Dataview、Heatmap Calendar
2. **创建 `首页.md`**：在库根目录下创建，搭好 Markdown 骨架
3. **创建 CSS 片段**：在 `.obsidian/snippets/` 下新建 CSS 文件，写入样式代码，在设置中启用。可直接让 AI 根据描述生成 CSS
4. **配置 Dataview 查询**：在 `首页.md` 中用 Dataview 代码块实现动态数据
5. **配置 AI 洞察**：创建 `AI洞察/当日.md`，通过自动化流程让 AI 扫描库并生成分析文本写入该文件，首页用 `!当日` 嵌入
6. **设置启动页**：在 Homepage 插件中将 `首页.md` 设为默认页面
7. **微调迭代**：反复截图标记不满意的细节，让 AI 修改代码，耐心打磨
