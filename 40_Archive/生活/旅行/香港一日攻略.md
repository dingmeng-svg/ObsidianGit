# 香港一日攻略

> 深圳出发的香港一日高效暴走路线。尖沙咀→中环→油麻地旺角，含打卡点位、美食清单和精确交通费用。全程人均约 ¥393.75。归档备查。

---

## 路线总览

```
深圳湾 → 天水围 → 尖沙咀 → (天星小轮) → 中环 → (巴士) → 太平山顶 → (观光巴士) → 旺角 → 天水围 → 深圳湾
```
