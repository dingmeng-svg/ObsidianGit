# 🏊‍♂️ 体态纠正 + 自由泳专项每日计划（约25-30分钟）

## 📋 总览表

| 时间段 | 动作/项目 | 细节与次数 | 备注（目标） |
|--------|----------|------------|--------------|
| **🌅 早晨唤醒（3分钟）** | 1. 下巴后缩 | 平躺，后脑勺贴床，下巴水平后移，保持5秒 → 10次 | 改善颈前伸，训练头部稳定 |
| | 2. 跪坐压脚背 | 跪姿，脚背贴地，臀部坐向脚跟 → 保持1分钟 | 提高自由泳脚背灵活性（鞭状打水） |
| **🕒 白天微习惯（每小时1分钟）** | 1. 耸肩-向后-下沉 | 站立或坐着，肩膀画大圆，最后停在下沉后收位 | 复位日常姿势，对抗驼背 |
| | 2. 门框胸肌拉伸 | 双手扶门框成“门”形，身体前倾 → 每侧20秒 | 放松紧张胸肌，打开肩膀 |
| | 3. 俯卧椅子转头 | 俯身胸口贴大腿，头水平转向一侧（不抬头）→ 每侧5次 | 模拟自由泳换气，稳定颈部 |
| **🏋️ 核心训练单元（15分钟）** | **A. 体态纠正组** | | |
| | - 靠墙天使 | 靠墙站立，手臂贴墙上下滑动 → 10次 × 2组 | 改善圆肩，恢复肩胛活动度 |
| | - 弹力带面拉 | 向面部拉弹力带，呈W形 → 15次 × 2组 | 强化上背部，防止自由泳拖肘 |
| | **B. 自由泳专项组** | | |
| | - 俯卧Y-T-W-L | 俯卧，依次做Y/T/W/L字母，每个字母保持2秒 → 各5次，2轮 | 稳定肩胛，优化划水支撑 |
| | - 俯卧“转头不转头” | 俯卧，额头轻贴地，只转头找肩 → 每侧10次（慢速） | 换气时头部稳定，不抬头 |
| | - 脚背灵活性 | ① 脚背下压踩地 → 每侧30次；② 跪坐压脚背1分钟；③ 坐姿模拟打水（脚踝放松）→ 30秒×2组 | 提升打水鞭状感 |
| | **C. 核心与流线型** | | |
| | - 平板支撑 | 肩胛推离地面 → 20-40秒 × 2组 | 激活前锯肌，防肋骨外翻 |
| | - 陆上流线型 | 靠墙双臂上举夹耳，肩胛上回旋 → 保持30秒 | 自由泳出发/转身姿势 |
| **🌙 睡前放松（2分钟）** | 1. 泡沫轴放松胸椎 | 仰卧，泡沫轴垫在肩胛中间，缓慢上下滚动 | 改善胸椎僵硬，利于转体 |
| | 2. 婴儿式 | 跪姿额头贴地，手臂前伸 → 30秒 | 伸展背部，放松全身 |
| | 3. 脚踝前侧拉伸 | 跪坐后用手拉脚趾向后 → 每侧30秒 | 进一步打开脚背 |

## 📅 每周节奏建议

| 星期 | 执行内容 |
|------|----------|
| 周一、三、五 | 完整执行上述全部计划（25-30分钟） |
| 周二、四 | 只做“早晨唤醒”+“白天微习惯”+ 自由泳专项组中任意2个动作（共约10分钟） |
| 周末 | 下水实践时，重点关注：打水脚踝放松、换气不抬头、移臂不耸肩 |

---

## 🧠 关键要点提醒

- **不要用力夹死肩胛骨**：日常站姿应是“腋下夹纸”般的轻微后收+下沉。
- **自由泳核心口诀**：头顶顶水（下巴后缩）、肩胛稳定（不耸）、脚背鞭水（放松踝）。
- **疼痛警示**：如出现肩峰撞击痛或颈部刺痛，请减小幅度或咨询康复师。

## ✅ 效果预期

- **第1周**：靠墙天使+下巴后缩熟练，打水时脚踝感觉变软。
- **第4周**：站立时自然挺拔，自由泳换气更流畅，打水推进力明显提升。
