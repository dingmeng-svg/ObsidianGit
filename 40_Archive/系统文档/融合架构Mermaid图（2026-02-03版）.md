## 🆕 七、PARA 与 ZK 并行判断模型

> 同一条外部信息可能同时触发行动需求（"我该怎么做"）和理解需求（"我该怎么理解"）。以下流程图帮助判断信息应该进入 PARA 行动层、ZK 知识层，还是同时进入两者。

```mermaid
flowchart TD
    INFO["📥 一条信息进入系统"]

    Q0{"这触发的是<br/>行动需求还是<br/>理解需求？"}

    Q0 -->|"我该怎么做这件事？"| PARA["🚀 进入 PARA 行动层"]
    Q0 -->|"我该怎么理解这件事？"| ZK["🧠 进入 ZK 知识层"]
    Q0 -->|"两者都有"| BOTH["🔀 同时进入两条路径"]

    PARA --> PQ{"有明确截止日？"}
    PQ -->|"是"| PROJ["10_Projects<br/>执行文件中记录<br/>具体的行动步骤"]
    PQ -->|"否"| AREA["20_Areas<br/>维护相关领域的<br/>待办或参考"]

    ZK --> ZQ{"是原始资料<br/>还是自己的理解？"}
    ZQ -->|"原始资料"| RES["30_Resources<br/>文献笔记<br/>标注来源"]
    ZQ -->|"自己的理解"| ATOMIC["31_Atomic_Notes<br/>永久笔记<br/>完全用自己的话"]

    BOTH --> BQ1["行动部分→PARA<br/>按截止日分流"]
    BOTH --> BQ2["理解部分→ZK<br/>按原始/提炼分流"]

    PROJ --> OUTPUT["产出行动或交付物"]
    AREA --> MAINTAIN["持续维护参考"]
    RES --> REFINE["每周提炼"]
    ATOMIC --> LINK["与其他永久笔记<br/>建立双向链接"]

    style INFO fill:#e8eaf6,stroke:#283593
    style PARA fill:#e8f5e9,stroke:#388e3c
    style ZK fill:#f3e5f5,stroke:#7b1fa2
    style BOTH fill:#fff3e0,stroke:#f57c00
    style PROJ fill:#a5d6a7,stroke:#2e7d32
    style AREA fill:#a5d6a7,stroke:#2e7d32
    style RES fill:#ce93d8,stroke:#6a1b9a
    style ATOMIC fill:#ef9a9a,stroke:#c62828
```

> **使用示例**：
> 
> 你在读一篇关于叙事结构的文章，同时有两个反应——"这个方法可以用在下节课台本里"（行动需求）和"叙事结构这个概念的底层逻辑是什么"（理解需求）。
> 
> - **行动部分** → 进 `10_Projects/操盘手骑士/02_执行/`，在台本大纲里加一条具体可执行的叙事结构优化动作
>     
> - **理解部分** → 进 `30_Resources/` 创建文献笔记，后续提炼为永久笔记 `[[叙事结构与信息密度的关系（操盘手骑士）]]`，链接到 `[[台本写作原则]]`、`[[认知负荷理论]]` 等已有笔记
>     
> 
> 两条路径不互斥，只是回答不同的问题。
