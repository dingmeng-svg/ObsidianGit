## 一、标签分类系统

21 种单域标签，YAML 格式统一使用数组语法（`tags: [领域]` 或换行列表示）。

| 标签   | 适用范围                  | 说明               |
| :--- | :-------------------- | :--------------- |
| 工作   | 21_工作 下所有文件           | 领域标签             |
| 个人成长 | 22_个人成长 下所有文件         | 领域标签             |
| 生活   | 23_生活与健康 下所有文件        | 领域标签             |
| 关系   | 24_关系 下所有文件           | 领域标签             |
| 财务   | 25_财务与资产 下所有文件        | 领域标签             |
| 技术   | 26_技术 下所有文件           | 领域标签             |
| 心理学  | 31_Atomic_Notes/心理学/  | 知识域标签            |
| 知识管理 | 31_Atomic_Notes/知识管理/ | 知识域标签            |
| 国际政治 | 31_Atomic_Notes/国际政治/ | 知识域标签            |
| 科学   | 31_Atomic_Notes/科学/   | 知识域标签            |
| 系统文档 | 90_System/ 下所有文件      | 系统标签             |
| 归档   | 40_Archive/ 下所有文件     | 状态标签             |
| 素材   | 外部摘抄类文件               | 类型标签             |
| 日记   | 每日日记                  | 类型标签             |
| 习惯   | 习惯方法论概念（与 个人成长 联用）    | 子领域标签，仅与 个人成长 联用 |

**规则：**

- **操盘手骑士不是标签。** 项目名写在 `project:` YAML 字段中，标签使用 `[工作]`。
- 复盘稿等操盘手骑士输出文件：`project: "操盘手骑士"`，tags 用 `[工作]` 或省略。
- 原子笔记使用**一个**领域标签（如 `[个人成长]`、`[心理学]`），习惯相关概念可用 `[个人成长, 习惯]`。
- Archive 文件使用 `[归档]` + 来源标签。
- 禁用旧版 `#领域/子类` 格式（如 `#知识管理/Bujo`），全部改为扁平标签。

## 三、标签演变日志

> 当前 15 种扁平标签是从原始 21 种系统逐步精简而来。以下记录每次变更的动因。

### 原始 21 种（2026-06-25）

| 层级 | 标签 |
|:-----|:------|
| 项目层 | `操盘手骑士` `知→行→进化` `知→行→进化/习惯` |
| 知识层 | `心理学` `概念` `模型` `知识管理` `素材` |
| 领域层 | `工作` `个人成长` `生活` `关系` `财务` `法律` `技术` |
| 类型层 | `SOP` `模板` `系统文档` `日志` `归档` `项目模板/说明` |

### 精简过程

| 操作 | 数量 | 说明 |
|:-----|:----:|:------|
| 项目标签 → `project:` 字段 | -3 | `操盘手骑士`、`知→行→进化` 等不再是标签，写在 YAML `project:` 中 |
| 类型标签 → `type:` 字段 | -2 | `概念`、`模型` 改为 `type: concept/model`，标签只保留领域 |
| 废弃未使用 | -1 | `法律` 全库无文件使用 |
| 合并冗余 → `系统文档` | -4 | `SOP` `模板` `日志` `项目模板/说明` 统一归入 `系统文档` |
| 新增领域标签 | +4 | `国际政治` `科学`（补齐 8 领域）、`日记`（每日日记独立标签）、`习惯`（与`个人成长`联用） |
| **最终 15 种** | | 11 留存 + 4 新增 = 15 |

### 关键原则

- **操盘手骑士不是标签**：项目归属在 `project:` 字段，文件标签用 `[工作]`
- **无子类格式**：禁用旧版 `#父/子`（如 `知→行→进化/习惯`），全部扁平
- **类型不在标签中**：概念/模型/实践/批判 → `type:` 字段，标签只放领域
