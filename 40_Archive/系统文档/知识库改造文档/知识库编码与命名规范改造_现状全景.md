## 五、原子笔记命名规范与问题分析

### 5.1 当前命名规则

格式：`概念名（出处）.md`

出处后缀使用约定：
- 标准学术模型 → `（AuthorName）`，如 `梅拉宾法则（Mehrabian）.md`
- 原创框架 → `（原创）`
- 书名/文章来源 → `（书名）`，如 `CODE（打造第二大脑）.md`
- 信条/人生哲学 → `（信条）`

### 5.2 文件名长度问题

通过梳理，原子笔记文件名主要有以下几种情况：

**情况 A：名字本身就长**
```
复杂系统：从思维框架到卡片笔记的非线性知识管理（卡片笔记写作法）.md
                                                ↑ 出处就占15个字符
```
这条文件名全长 **46 个中文字符**（含出处）。

**情况 B：出处后缀太长**
```
工具 ≠ 思维改变（卡片笔记写作法）.md          ← 出处11字符
行为改变四法则：让它显而易见…（原子习惯）.md     ← 出处8字符
```
很多出处后缀如 `（打造第二大脑）`、`（卡片笔记写作法）`、`（拆解一切问题）` 本身就占 10-15 个字符。

**情况 C：概念名本身带副标题**
```
箭垛效应：创新是站在巨人的肩膀上还是一窝蜂地撞墙（卡片笔记写作法）.md
                                            ← 27字概念 + 11字出处 = 38字
```

### 5.3 当前文件名长度分布（估算）

| 长度范围 | 占比 | 示例 |
|:--------|:----:|:-----|
| ≤20字符（短） | ~30% | `习惯堆叠.md`、`执行意图.md`、`环境设计.md` |
| 21-35字符（中） | ~40% | `互惠原则（影响力）.md`、`幸存者偏差（卡片笔记写作法）.md` |
| 36-50字符（长） | ~25% | `你以为的人脉不是你的人脉（认知升级）.md` |
| >50字符（超长） | ~5% | `行为改变四法则：让它显而易见、有吸引力、简单易行、令人满意（原子习惯）.md`（65字符） |

### 5.4 出处后缀使用问题

| 问题 | 表现 | 例子 |
|:----|:-----|:-----|
| 出处即领域名 | `（心理学）` 和标签重复 | `先分别，后无分别（心理学）.md`，已有 `tags: [心理学]` |
| 出处太长 | 占文件名 30%+ | `（卡片笔记写作法）` 11字，`（打造第二大脑）` 9字 |
| 出处不一致 | 同本书不同后缀 | `（拆解一切问题）` vs `（卡片笔记写作法）` 格式不统一 |
| 无出处 | 少量笔记纯概念名 | `身份认同.md`、`习惯堆叠.md` |

## 七、关键待决事项

### A. 编码方案

当前顶层是 `NN_英文描述`，如果改成 `NN_编码-中文名`（如 `10_项目`、`20_领域`），涉及：

1. **所有 wikilink 全库更新** — 只要有路径引用（如 `[[10_Projects_.../XX]]`）的都需要改
2. **Obsidian 短名 wikilink 不受影响** — 如果之前都用短名 `[[XX]]` 而非全路径 `[[10_Projects_.../XX]]`，则不需要改
3. **与 Syncthing / 本地路径无关** — Obsidian 内部路径不影响文件系统
4. **子目录要不要也带编码** — 如 `20_Areas/21_工作/` 还是 `20_Areas/工作/`？

### B. 原子笔记命名简化

**方案选择空间：**

| 方案 | 文件名格式 | 优点 | 缺点 |
|:----|:----------|:-----|:-----|
| **1. 纯概念名** | `概念名.md` | 最短，最整洁 | 同名冲突无法区分 |
| **2. 短出处（缩写）** | `概念名（来源缩写）.md` | 保留来源信息 | 需要定义缩写映射表 |
| **3. 无出处，YAML 承担** | `概念名.md`，出处只在 YAML 的 `source` 和 `author` | 最短，YAML 承担检索 | 文件名同名冲突时无法区分 |
| **4. 保留但简化** | `概念名（简写）.md` | 平衡 | 需要迁移一次 |

### C. 出处后缀的实际使用频率

全库约 **280 篇**原子笔记中，出处后缀使用分布（估算）：
- `（卡片笔记写作法）` ~40篇
- `（打造第二大脑）` ~20篇
- `（穷查理宝典）` ~15篇
- `（金惟纯）` ~10篇
- `（影响力）` ~6篇
- `（原子习惯）` ~5篇
- `（马斯克）` ~5篇
- 其余各种出处：~80篇
- 无出处：~10篇
- 其他各种：~90篇

### D. 全库所有文件是否需要以编码开头

当前原子笔记无编码、MOC 无编码、Areas 下子目录无编码。如果对所有文件和文件夹统一编码，需要决定：

1. **编码粒度**：到目录层面，还是到每个文件？
2. **编码格式**：`NN_`（两位数字）还是 `N.N.`（层级码）
3. **编码映射**：当前 15 种标签 → 领域编码对照表
