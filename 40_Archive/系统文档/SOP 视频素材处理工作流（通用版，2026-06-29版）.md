## 通用知识转化工作流（The 5C Flow）

核心理念：**从“收藏即遗忘”到“捕获即转化”**。

```text
Capture（捕获） → Clarify（澄清） → Condense（压缩） → Connect（连接） → Create（创造）
```

### 工作流全景图

| 阶段                 | 核心问题     | 输入物   | 输出物      | 时间成本       |
| :----------------- | :------- | :---- | :------- | :--------- |
| **1. Capture 捕获**  | 我看到了什么？  | 碎片信息  | 临时锚点     | < 2 分钟     |
| **2. Clarify 澄清**  | 它到底在说什么？ | 临时锚点  | 结构化素材    | 10-15 分钟/日 |
| **3. Condense 压缩** | 它的本质是什么？ | 结构化素材 | 原子化概念/模型 | 30 分钟/周    |
| **4. Connect 连接**  | 它和什么有关？  | 原子化概念 | 知识网络     | 持续进行       |
| **5. Create 创造**   | 我因此能做什么？ | 知识网络  | 行动/表达/决策 | 自然涌现       |

---

### 阶段一：Capture —— 建立临时锚点

**目的**：在遗忘曲线生效前，用最低成本把信息“钉”住。

| 原则 | 具体做法 | 反例 |
| :--- | :--- | :--- |
| **零摩擦** | 只记一个关键词 + 一句话触动你的理由 | 试图当场复述完整内容 |
| **单入口** | 所有碎片扔进同一个“篮子”（一个文件夹、一本便签、一个聊天窗口） | 根据内容类型分散到不同 App |
| **留钩子** | 必须包含一个“日后能回忆起”的线索（截图、时间、场景） | 只写“好有道理”四个字 |

**工具无关示例**：
- 微信“文件传输助手”：发一条 `视频 女性不主动心理 感觉观点太博弈论 待反驳`
- 实体便签：写 `2026.4.17 看了XX视频，核心是“情感泰勒主义”`，贴在桌面待办区
- 备忘录语音：对着手机说 10 秒语音备忘

---

### 阶段二：Clarify —— 从碎片到素材

**目的**：每天/每两天清空一次“篮子”，决定信息的生死去留。

| 原则 | 具体做法 |
| :--- | :--- |
| **定时清空** | 设定一个固定时间（如睡前 15 分钟），强制处理捕获池中的所有条目 |
| **残忍筛选** | 问自己：*“一个月后，我还会关心这条信息吗？”* 如果答案是否，**立即删除** |
| **标准化记录** | 为素材建立统一字段：**来源 / 核心观点 / 我的第一反应 / 待办动作** |

**通用素材卡片模板（纯文本思维）**：

```text
---
类型：素材
来源：[平台/作者/日期]
链接/位置：[如有则记]
---

# 标题

## 核心内容摘要
- 要点1
- 要点2

## 触动我的点（最重要）
（写一句个人反应，这是后续提炼的火种）

## 待处理标记
[ ] 反驳 / [ ] 提炼概念 / [ ] 行动实验
```

---

### 阶段三：Condense —— 提取原子单位

**目的**：把别人讲的内容，变成你自己的一句话概念。

| 原则 | 具体做法 |
| :--- | :--- |
| **一张卡片只讲一件事** | 如果素材讲了 3 个观点，拆成 3 张独立的原子卡片 |
| **用自己的话重述** | 禁止复制粘贴。强制自己完成一次神经回路的“翻译” |
| **标注类型** | 每张卡片标记属性：**概念 / 模型 / 批判 / 洞察 / 实践** |

**原子卡片模板（通用）**：

```text
# [概念名称]

## 一句话定义

## 详细说明

## 与我已有的哪些想法有关？

## 可能的行动提示
```

---

### 阶段四：Connect —— 让想法碰撞

**目的**：单个原子没有力量，链接产生洞见。

| 原则 | 具体做法 |
| :--- | :--- |
| **主动寻找冲突** | 新卡片和旧卡片观点矛盾吗？把它们放在一起比较，写下“为什么不同” |
| **建立索引页** | 当你对某个主题有 5 张以上卡片时，手动建一个目录页，罗列所有相关卡片标题 |
| **用问题牵引链接** | 不要只按主题分类。试试按问题链接：“这张卡片回答了什么问题？又提出了什么问题？” |

**工具无关的链接方式**：
- 纸质卡片盒：在卡片底部写“参见：[卡片编号]”
- 备忘录：用 `` 或 `→` 符号标记关联笔记标题
- Notion：使用 `@` 或 Relation 字段

### 阶段五：Create —— 自然涌现产出

**目的**：卡片不是终点，行动和表达才是。

| 产出层级 | 触发信号 | 具体产出形式 |
| :--- | :--- | :--- |
| **微表达** | 3 张相关卡片就位 | 一条朋友圈、一段微博、一次有准备的聊天 |
| **小行动** | 某张实践卡有明确指令 | 进行为期 3 天的行为实验，记录结果 |
| **中思考** | 某主题的 MOC 有 10+ 卡片 | 写一篇 1000 字梳理文章（给自己看） |
| **大决策** | 多个领域的卡片指向同一模式 | 用于职业选择、关系调整的判断依据 |

---

### 防囤积三大铁律（任何工具都适用）

| 铁律 | 具体规则 |
| :--- | :--- |
| **1. 池子水位线** | 捕获池内的待处理条目 **永远不超过 7 条**。超过即触发强制清空。 |
| **2. 两周死刑** | 任何在捕获池停留超过 14 天未处理的条目，**直接删除**。它不重要，留下只是心理负担。 |
| **3. 原子必链** | 每新建一个原子概念，**必须至少建立一条双向链接**（连向旧卡片或索引页）。无链接的卡片是知识孤岛，会沉没。 |

### 知识转化 5C 工作流

| 阶段 | 动作口诀 | 产出物 |
| :--- | :--- | :--- |
| **Capture** | 一句话 + 一个触动点 | 捕获池中的临时条目 |
| **Clarify** | 补全 + 写反应 + 打标签 | 标准化素材记录 |
| **Condense** | 拆开 + 用自己的话说 | 原子卡片（一张一事） |
| **Connect** | 问“和什么有关/矛盾” | 索引页 + 双向链接 |
| **Create** | 看卡片数量自然说话 | 表达 / 行动 / 决策 |
### ⚠️ 铁律

| 序号 | 规则 |
| :--- | :--- |
| 1 | 待处理池 ≤ 7 条 |
| 2 | 超过 14 天未动 → 删 |
| 3 | 每张原子卡至少一条链接 |


这套工作流不绑定任何软件。您可以用 软件 实现，也可以用一叠 A6 卡片、一个备忘录 App来执行。**核心永远是人如何处理信息，而不是工具如何存储信息。**
