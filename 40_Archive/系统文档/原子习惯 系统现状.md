### 原子笔记（30_Resources/31_Atomic_Notes/）

| 笔记 | 类型 | 路径 | 在习惯系统中的具体用途 |
|:---|:---:|:---|:---|
| 身份认同驱动习惯：成为谁，而不是达到什么 | concept | 个人成长/概念/ | **身份锚定板的理论底座** — 三习惯的身份标签（曦·启明/午·承势/夕·观成）直接源自此概念：每一个习惯不是"做一件事"，而是"为一种身份投票" |
| 身份认同（原子习惯） | concept | 个人成长/概念/ | 身份认同的更底层解释——改变习惯的本质是改变自我认知 |
| 画X的即时满足感（原子习惯） | concept | 个人成长/概念/ | **Tracker 奖励设计的理论解释** — 为什么 Tracker 上打勾本身就能提供正向反馈。每个习惯的"奖励"维度中标注"Tracker 上的一勾 ✅"即源于此 |
| 环境设计（原子习惯） | concept | 个人成长/概念/ | **坏习惯阻断器的理论底座** — Design Reference 中的阻断策略（手机放客厅、卧室无充电器等）直接应用了"让它不可见、让它难以执行"原则 |
| 习惯堆叠（原子习惯） | concept | 个人成长/概念/ | **习惯叠加公式的理论底座** — Design Reference 中的"做完 [当前习惯] 后在 [地点] 立即做 [新习惯]"即源于此，三个核心习惯都用习惯堆叠绑定到已有行为锚点 |
| 习惯记分卡（原子习惯） | concept | 个人成长/概念/ | **Scorecard 的理论底座** — 解释了"不评判不修改，只是看见"的觉察逻辑 |
| 执行意图（原子习惯） | concept | 个人成长/概念/ | **午·承势的底层机制** — "当 X 时，我会做 Y"的格式直接嵌入 Design Reference 的习惯叠加公式中 |
| 永不连续错过两次（原子习惯） | concept | 个人成长/概念/ | **Tracker 中断处理规则的理论底座** — Tracker 中的三级中断响应（漏1天/连漏2天/连漏3天+）直接应用此原则 |
| Don't Break the Chain：视觉化连续打卡法（原子习惯） | concept | 个人成长/概念/ | **连续投票计算的视觉动力** — Tracker 中的"当前连续/最长连续"统计即由此概念驱动 |
| 追踪应毫不费力（原子习惯） | concept | 个人成长/概念/ | **追踪降级的理论依据** — 追踪强度分级（每日→每周→月度巡检）的设计逻辑："追踪本身不该成为负担，当习惯融入身份后，追踪强度可以降级" |

**关键差异**：原子笔记是"理论"，执行文件是"应用"。同一个概念（如"环境设计"）在原子笔记中是通用原理，在 Design Reference 中落成了具体的阻断策略（手机放客厅、卧室无充电器）。原子笔记不依赖系统变化而变化，执行文件随习惯迭代更新。
