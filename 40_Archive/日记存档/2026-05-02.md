## 📌 从昨天迁移的闪念
> 昨日未处理的闪念会自动出现在下方
```dataviewjs
let yesterday = dv.date("today").minus({days: 1});
let folder = '"Bullet Journal/Daily Logs"';
let yesterdayPage = dv.pages(folder)
    .where(p => p.file.day && p.file.day.ts === yesterday.ts)
    .first();
if (yesterdayPage) {
    let tasks = yesterdayPage.file.tasks
        .where(t => !t.completed && t.header.subpath.includes("今日闪念捕获"));  // 改用 includes
    if (tasks.length) {
        dv.taskList(tasks);
    } else {
        dv.paragraph("✅ 昨天没有遗留的闪念。");
    }
} else {
    dv.paragraph("📭 未找到昨天的日记文件。");
}
```



## 🔁 从昨天迁移的任务

> 昨日未完成自动查询

```dataview

TASK
FROM "Bullet Journal/Daily Logs"
WHERE !completed 
  AND file.day = date(today) - dur(1 day)
  AND !contains(header.subpath, "今日闪念捕获")  

```
