# 多巴胺：欲望分子，而非快乐分子

## 核心概念

**多巴胺是欲望分子，而非快乐分子。**

它不直接带来快乐，而是**驱使人类追求更多、更好的事物**。了解多巴胺可以帮助我们更好地理解自己的感觉和行为，认清欲望和动力的来源，以及如何处理当下与未来的关系。

## 常见误解

| 误解 | 真相 |
|------|------|
| 多巴胺 = 快乐分子 | 多巴胺 ≠ 快乐，它产生的是“想要”而非“喜欢” |
| 多巴胺带来满足感 | 满足感来自“当下分子”（血清素、催产素等） |
| 多巴胺越多越好 | 多巴胺过多会导致永不满足、焦虑、成瘾 |

## 核心理念

> 多巴胺是关于“更多”的分子——更多的食物、更多的金钱、更多的可能性。它不关心你拥有什么，只关心你还缺什么。

## 关键功能

- **驱动追求**：让你有动力去获取尚未拥有的东西
- **影响感知**：影响你如何感受、如何行动、如何想象
- **创造欲望**：让你对未来的可能性感到兴奋

## 在“知→行→进化”中的位置

| 维度 | 贡献 |
|------|------|
| **知** | 理解人类行为背后的神经化学驱动力 |
| **行** | 识别多巴胺驱动的行为模式，避免被欲望绑架 |
| **进化** | 学会驾驭多巴胺，而非被它奴役 |
