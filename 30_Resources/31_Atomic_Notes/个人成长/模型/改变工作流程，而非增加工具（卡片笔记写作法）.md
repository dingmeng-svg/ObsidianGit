# 改变工作流程，而非增加工具

## 核心概念
**把卡片盒当作一个简单的档案库来存取资料，肯定会失望。卡片盒不是“多加一个工具”，而是需要改变原有的工作流程——理解它如何发挥作用、为什么能发挥作用，以及写作各步骤之间的配合机制。**

## 核心理念

### 一个常见的误解

很多人以为卡片盒法是“在已有的学习和写作流程中，再加一个记笔记的步骤”。结果就是：

- 把卡片盒当作资料存档库：读过的东西摘录进去，然后忘记
- 笔记写了但从不建立联系
- 需要写作时还是回到原来的方式（临时搜集资料、拼凑成文）

这不是卡片盒法——这只是一个数字化了的抽屉。

### 改变流程意味着什么

卡片盒法要求你重新定义“写作”的起点和过程：

| 传统流程 | 卡片盒流程 |
|---------|-----------|
| 写作 = 坐下来，打开空白文档 | 写作 = 持续的日常笔记积累 |
| 阅读是独立活动 | 阅读时手中就有笔，是笔记的前端 |
| 笔记是辅助记忆的工具 | 笔记是思考的媒介 |
| 输出是最后一步 | 输出是日常笔记的自然延伸 |

### 为什么必须理解原理

这也是作者写一本书而非仅出一本实用手册的原因。如果只给操作步骤，人们会用旧思维去执行新步骤，结果还是旧的：

- 知道“要记永久笔记”，但记的仍然是摘要和摘录
- 知道“要建立链接”，但只是为了链接而链接

**只有理解了“为什么这样做”，才能真正执行“这样做”。**

### 判断自己是否改变了流程

- 写作时是在空白页前冥思苦想，还是在浏览已有笔记群？
- 阅读时是在划线，还是已经在想“这能和我已有的什么笔记产生联系”？
- 新学到的知识是孤立的，还是自动嵌入到笔记网络中？

## 在“知行进化”中的位置

| 维度 | 贡献 |
|------|------|
| 知 | 理解工具与系统的区别——工具不会自动改变结果，流程才是系统 |
| 行 | 不只是在已有流程中“多加一步”，而是重新定义阅读、笔记、写作的关系 |
| 进化 | 从“我有一个卡片盒”进化为“卡片盒改变了我的思考方式” |
