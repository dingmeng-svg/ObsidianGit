# 系统思考双维度模型：回路与层级

## 核心概念

**系统思考有两个核心维度：看得远（找到"回路"）和看得透（看到"层级"）。看得远是看到事物发展的脉络，找到过去和现在的关系；看得透是理解事情背后的真正规律，看到表面之下的层级结构。**

## 核心理念

### 维度一：回路（时间维度）

回路是以时间为关系的系统，最显著特征是**自我强化的正循环和负循环**。回路一旦形成，就会自我强化，一直到系统的上限受不了为止。

**增长引擎（正循环）**：
- 学习 → 成长 → 增值 → 学习
- 锻炼 → 精力充沛 → 锻炼
- 善意 → 回报 → 善意

**死亡螺旋（负循环）**：
- 忙 → 乱 → 忙
- 穷 → 稀缺心态 → 短视决策 → 穷
- 巴尔扎克困境：需要休息 → 需要旅行 → 需要钱 → 必须工作 → 更需要休息

**破解方法**：用一条"想未来→高收益"的小循环抵消负循环。先停下来，控制混乱，引入资源思考、学习和规划，建立起另一个正循环。

回路有一个玩死人不偿命的特点：**短期感受和长期收益总是相悖。** 正循环的学习、健康、投入刚开始都感觉很累，而负循环的忙带来的充实感、不投入的安全感，短期感受都很好。所以人们往往为了不改变而改变。

### 维度二：层级（空间维度）

看问题不能只盯在"点"的层面，更要看到点背后的**线、面、体**。悲惨的人生，就是在一个常态的面上做一个勤奋的点。更悲惨的人生，是这个面本身正在下沉。最悲惨的人生，是这个面依附的经济体也正在下沉。

勤奋有三重境界：

| 层级 | 特征 | 核心操作 | 局限 |
|:---|:---|:---|:---|
| **第一层：努力勤奋** | 肯花时间、精力学习 | 空出时间、精力、财力来学习 | 有天花板，越忙越没竞争力 |
| **第二层：方法论勤奋** | 用更好的方法做事 | 学习前人已验证的方法，应用到实践中 | 需上层方向指引，否则如王语嫣——识得各大门派武功，永远成不了高手 |
| **第三层：战略勤奋** | 选择正确的目标和赛场 | 问自己：核心竞争力是什么？在什么赛场和谁竞争？ | 决定前两层的价值 |

**低水平勤奋靠努力，中等水平勤奋靠方法论，高水平勤奋靠选择目标。** 不要用战术上的勤奋，来掩盖战略的懒惰。

### 新手、老手与高手

- **新手学习系统**：识别自己所在的系统，看到回路和层级
- **老手利用系统**：在现有系统中找到增长引擎，避开死亡螺旋
- **高手破局**：当现有系统无法解决问题时，跳出系统，进入更大的系统

一个人的力量取决于他能看到多大的系统——你想象的系统有多大，就能调用多少力量。

## 在"知→行→进化"中的位置

| 维度 | 贡献 |
|------|------|
| 知 | 掌握系统思考的两个核心维度——回路（看得远）和层级（看得透） |
| 行 | 诊断自己的困境属于哪个维度的问题：是陷入了负循环回路，还是站在了错误的层级？前者需要接入正循环，后者需要战略升级 |
| 进化 | 从"在点上努力"进化为"看到回路和层级，在更高维度上破局" |
