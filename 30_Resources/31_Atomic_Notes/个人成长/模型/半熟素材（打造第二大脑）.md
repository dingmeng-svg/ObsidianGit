# 半熟素材：可复用的知识组件

## 核心概念

**半熟素材（Intermediate Packets）** 是知识创作过程中产生的“半成品”组件——尚未成为最终成品，但在后续项目中可被复用和组合。

## 五类半熟素材

| 类型 | 说明 | 示例 |
|------|------|------|
| **干货笔记** | 浓缩的核心内容 | 读书笔记摘要、金句集 |
| **落选素材** | 项目中没有用上的内容 | 报告中删掉的段落、提案中舍弃的方案 |
| **过程文件** | 创作过程的中间产物 | 头脑风暴记录、草稿、大纲 |
| **最终成果** | 已完成项目的产出 | 发布的文章、完成的报告 |
| **他山之石** | 来自外部的有用材料 | 他人的模板、案例、参考资源 |

## 核心价值

- **降低启动成本**：每次新项目不用从零开始
- **提高产出质量**：素材经过一次打磨，品质已有保证
- **加速创作速度**：拼搭半熟素材比重新创作快得多

## 与 CODE 的关系

| CODE 步骤 | 半熟素材的作用 |
|-----------|---------------|
| 抓取 | 积累原始素材 |
| 组织 | 将素材归类到 PARA 框架 |
| 提炼 | 将原始素材加工为半熟素材 |
| 表达 | 将半熟素材组合成最终成果 |

## 在“知→行→进化”中的位置

| 维度 | 贡献 |
|------|------|
| **知** | 半熟素材是“知”被加工后的形态 |
| **行** | 用半熟素材快速产出成果，降低行动门槛 |
| **进化** | 每次复用都是对知识的重新审视和精炼 |

## 一句话总结

> 半熟素材 = 知识的预制件，让创作从“砌砖”变为“搭积木”。
