# 认知偏见：人类误判心理学

## 核心概念

**人类误判心理学（Psychology of Human Misjudgment）** 是芒格对认知偏见的系统化整理——他识别出约25种导致人类判断错误的心理倾向，并认为理解这些倾向是做出更好决策的前提。

## 核心观点

> 认识到自己容易受到偏见的影响，是克服偏见的第一步。

- 每个人，包括自己，都容易受到偏见的影响
- 认知偏见往往在潜意识层面运作
- 意识到偏见的存在，本身就能削弱其影响

## 重要心理倾向（部分）

| 偏见 | 表现 |
|------|------|
| **奖励/惩罚倾向** | 人会被激励机制驱动，甚至扭曲事实 |
| **喜爱/厌恶倾向** | 我们倾向高估所爱、低估所恨 |
| **避免怀疑倾向** | 急于得出结论以消除不确定性 |
| **避免不一致倾向** | 固守已有观点，抗拒改变 |
| **从众倾向** | 随大流，即使知道是错误的 |
| **对比错误倾向** | 被相对比较误导，忽视绝对价值 |

## 如何应对

1. **觉察**：承认自己容易受偏见影响
2. **检查清单**：做重大决策前逐项检查常见偏见
3. **寻求对立观点**：主动找反方证据
4. **延迟决策**：避免在情绪中做决定
5. **学习他人错误**：从别人的失败中学习
