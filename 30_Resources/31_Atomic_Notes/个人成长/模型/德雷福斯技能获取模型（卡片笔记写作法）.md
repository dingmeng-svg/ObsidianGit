# 德雷福斯技能获取模型

## 核心概念
**技能的获取遵循从“依赖外部规则”到“内化为直觉”的五阶段进阶路径：新手 → 高级新手 → 胜任者 → 精通者 → 专家。**

## 核心理念

### 五个阶段

| 阶段 | 特征 | 决策方式 |
|------|------|---------|
| **新手** | 需要明确的规则和步骤来指导行动 | “按手册操作” |
| **高级新手** | 能识别情境模式，但仍需指导 | “我见过这种情况” |
| **胜任者** | 能独立制定计划，处理复杂任务 | “我先分析再行动” |
| **精通者** | 依靠经验而非规则，能从全局看待问题 | “直觉告诉我应该…” |
| **专家** | 知识完全内化，凭直觉做出判断，难以解释“为什么” | 直接行动，不依赖分析 |

### 核心洞察

1. **新手和专家的根本区别不是知识量，而是决策方式**：新手需要规则告诉他怎么做，专家看到情境就知道怎么做——甚至说不清楚自己为什么这样判断

2. **从“胜任者”到“精通者”需要的不再是更多规则，而是大量实践和即时反馈**：这就是为什么学术写作不能靠“学习写作方法论”来掌握，必须在真实的写作循环中积累经验

3. **规则能帮你达到“胜任”，但无法帮你达到“精通”**：过分依赖计划和方法论指南，反而会限制向更高阶段的发展

### 与卡片盒法的关系

传统学术写作教学往往给新手一堆规则（如何选题、如何列提纲、如何引用）。但卡片盒法提供了另一种路径：

- **清晰的任务结构**（区分闪念笔记、文献笔记、永久笔记）→ 新手有规则可循
- **即时的反馈循环**（每次写永久笔记都是对自己理解的检验）→ 积累真实经验
- **允许灵活调整**（不必遵循僵化计划）→ 从“遵循规则”过渡到“依赖直觉”

这正是德雷福斯模型的实践对应：**用结构支撑新手阶段，用反馈推动向精通进化。**

### 实践启示

- 如果你是新手，不要排斥规则和流程——你需要它们
- 但不要永远停留在依赖规则——要通过大量实践让规则内化
- 当你能“不按手册也能做好”时，你才真正成为了自己领域的主人

## 在“知行进化”中的位置

| 维度 | 贡献 |
|------|------|
| 知 | 理解技能成长的非线性路径：规则→经验→直觉 |
| 行 | 新手阶段拥抱规则（卡片盒流程），在重复实践中积累内化 |
| 进化 | 从“依赖方法论”进化为“方法论成为本能” |
