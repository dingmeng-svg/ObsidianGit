# 惭愧心——认错的高阶形式

## 核心概念
**真正的认错不是内疚——内疚让人自我价值感低落，没有力量。真正的认错是生惭愧心：我原来可以这样，我居然容许自己变成这样——迫不及待想要改变，而且过程是欢喜的。**

## 核心理念

### 两种认错的本质区别

| | 内疚式认错 | 惭愧心式认错 |
|------|---------|------------|
| **内心感受** | 我很糟糕、我不行 | 我本该更好、我必须改变 |
| **身体反应** | 沉重、卡住、动不了 | 发热、兴奋、有力量 |
| **对自我的影响** | 价值感低落 | 给自己一个更高的标准 |
| **行动方向** | 逃避、不敢再面对 | 迫不及待想要拉近距离 |
| **结果** | 越认越没力量 | 越认越有力量 |

### 为什么内疚式认错无效

金惟纯的洞察：如果你认错以后觉得自己被卡住了，哪里也动不了，那个认错叫做内疚——那个没有力量，自我价值感变得更低落，变得觉得自己不行，什么都做不了。这样认错是没有用的。

很多人一辈子都在做内疚式认错：被逼着认、为了息事宁人认、趋吉避凶认——和小时候被屈打成招没有本质区别。这不是真的认错，只是在管理他人情绪。

### 惭愧心的运作机制

惭愧心的意思是：**我原来可以这样，我居然容许自己变成这样。** 我怎么搞的？不行，我必须从现在开始就要改变。

这个认错是有力量的——不是价值感低落，而是给自己一个更高的标准。扫除了所有的障碍，如实地看待自己，回到过去对自己应有的标准，然后看到自己跟那个标准差那么远，迫不及待地想要把那个距离拉近。

所以真正认错是热情的、有力量的，是欢喜的，是迫不及待想要去改变、想要有所不同的。这才是真的。

### 认错的层次

金惟纯指出认错有一个过程：刚开始认那些你可以认的、不会触及核心自我的小错。越认越认，认到最后，就变成你最不肯认的那个东西——自己完全不能接受自己的那个部分——也要去面对。

所以认错不是对外的事情，是对内的一个修炼。认到极致的以后，最后就完全接受自己。完全如实接受自己以后，那个时候你生命的能量才会完全的展现。
