# 念头觉察：改命从转念开始

> 提炼自：金惟纯《凉子访谈录》专访下集

---

## 核心命题

**命运藏在"看不见的念头"里。** 人一生的起心动念超过百亿次。这些瞬间的念头固化为思维模式 → 情绪模式 → 行为习惯 → 个性 → 命运。

改命的关键不是改外境，而是**转内在的起心动念**。

---

## 三层递进模型

```
念头（瞬间） → 模式（固化） → 个性（外显） → 命运（结果）
   ↑                                                    
   └── 唯一的干预点就在这里 ← 觉察 + 转念
```

---

## 金惟纯的核心解法

| 困境 | 解法 |
|------|------|
| 想改变命运 | 从"管好念头"开始，而非盲目换环境 |
| 人际关系紧张 | 停止指责对方 → 问自己："刚才我在想什么？" |
| 焦虑迷茫 | 区分「自己的事 / 别人的事 / 老天的事」，只认真对待自己的事 |
| 想要成功 | 先修"愿力"——很多人不成功是因为内心根本不愿相信 |

---

## 可立即上手的两个练习

1. **每日念头觉察**：生气/焦虑时暂停 3 秒，问"我刚刚在想什么？"
2. **关系反求诸己**：分歧时不争对错 → 反思"我的哪个执念让我这么难受？"
