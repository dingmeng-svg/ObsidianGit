# 立德立功立言：三不朽

## 核心概念

**中国古代格言有立德、立功、立言称为三不朽之说。不朽即如西方宗教中之永生与复活。然立功有际遇，立言有条件，只有立德，不为际遇条件之所限。因此中国人最看重立德。**

## 核心理念

### 三不朽的区别

| | 立德 | 立功 | 立言 |
|:---|:---|:---|:---|
| **依赖条件** | 不依赖任何外在条件 | 依赖际遇——有没有机会做大事 | 依赖条件——有没有才华和资源著书立说 |
| **人人可及** | 是 | 否 | 否 |
| **钱穆的论断** | 运水搬柴，亦见德 | 治国平天下是大功，但非人人有这个机会 | 著书立说是大言，但非人人有这个才华 |
| **历史地位** | 中国人最看重 | 次之 | 次之 |

### 为什么立德最可贵

立功需要际遇——不是每个人都有机会治国平天下。立言需要条件——不是每个人都有资源和才华著书立说。只有立德，不为际遇条件之所限。

我若在运水搬柴的位分上，一心一意运水搬柴，水也运了，柴也搬了，心广体胖，仰不愧俯不怍，职也尽了，心也安了，此也是一种德。**大小之分，分在位上，分在力上，不分在德上。位与力人人所异，德人人可同。**

中国的圣人，着重在德性上，不着重在地位力量上。不必舜与周公始得称纯孝，十室之邑，三家村里，同样可以有孝子——即同样可以有大舜与周公。地位不同，力量不同，德性则一。

### 与"尽其在我"的关联

立德是[[尽其在我（人生十论）]]的延伸。尽其在我讲的是在关系中先做好自己的本分，立德讲的是在任何位分上都可以完成德性。两者合在一起回答了同一个问题：**当外在条件不受我控制时，我还能做什么？**——做好那个不受条件限制的、人人都能做到的、却最被看重的"德"。

## 在"知→行→进化"中的位置

| 维度 | 贡献 |
|------|------|
| 知 | 理解"三不朽"中立德最可贵的逻辑——因为它不依赖任何外在条件，人人可及 |
| 行 | 在自己的位分上（无论大小）完成自己的德性——运水搬柴亦可成德 |
| 进化 | 从"追求不可控的立功立言→焦虑挫败"进化为"先完成人人可及的立德→在条件具备时再立功立言" |
