# 人力资源：知识与技能的总和

## 核心概念

**人力资源**是人类自身展现出来的一系列知识与技能的总和。它是第二大脑要服务和放大的对象。

## 构成要素

- 教育
- 经验
- 智慧
- 技术
- 人际关系
- 常识判断
- 直觉思维

## 数据背景

> 全美有形资产价值约为 10 万亿美元，不及人力资本价值总量的五分之一甚至十分之一。

人力资本的价值**远超**有形资产——这意味着“人”本身是最宝贵的资源。

## 与第二大脑的关系

第二大脑的任务：**放大和扩展这个“人力资源”**

| 人力资源的要素 | 第二大脑如何扩展 |
|---------------|----------------|
| 教育 | 存储学习内容，随时调取 |
| 经验 | 记录项目过程，方便复盘 |
| 智慧 | 提炼模式，形成框架 |
| 技术 | 工具系统化，降低认知负荷 |
| 人际关系 | 记录和追踪沟通 |
| 常识判断 | 积累决策依据 |
| 直觉思维 | 通过记录和反思，训练和校准直觉 |

## 一句话总结

> 你本身就有巨大的资源——第二大脑只是帮你更好地运用它。
