# CODE：第二大脑的信管法则

## 核心概念

**CODE** 是打造第二大脑的四步核心流程，由 Tiago Forte 在 *Building a Second Brain* 中提出。四个字母分别代表：

| 步骤 | 英文 | 中文 | 核心动作 |
|------|------|------|---------|
| **C** | Capture | 抓取 | 有意识地筛选和保存最有价值的信息 |
| **O** | Organize | 组织 | 以行动为导向，为信息赋予结构 |
| **D** | Distill | 提炼 | 分层萃取出笔记的精华 |
| **E** | Express | 表达 | 将知识转化为成果输出 |

## 流程逻辑

CODE 是一条从**输入到输出**的完整链路：

> 抓取（选材）→ 组织（存放）→ 提炼（加工）→ 表达（产出）

每一步都为下一步做准备，最终目的是**让知识产生价值**，而非仅仅囤积。

## 核心原则

- **抓取**：只保留直击内心的重磅信息，其他能省则省
- **组织**：以行动为导向，问“这条信息对我手头的项目有何助益”
- **提炼**：为未来的自己做笔记——“如何记录才能更好地帮到今后的我”
- **表达**：所有的光说不练都是假把式

## 在“知→行→进化”中的位置

| 维度 | 贡献 |
|------|------|
| **知** | 提供从信息输入到输出的全流程框架 |
| **行** | 强调“行动导向”和“产出成果”，避免纸上谈兵 |
| **进化** | 提炼与表达环节本身就是对知识的深度加工和内化 |

## 一句话总结

> CODE 是把信息从“囤积”变为“资产”的完整工作流。
