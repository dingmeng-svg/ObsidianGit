# 三层过滤机制

## 核心概念
**阅读时遇到与当前问题无关的内容，不是全部都要记，也不是全部略过——而是通过三层逐级筛选：当前燃料→未来种子→图书馆编目，让卡片盒只收录值得长期思考的想法。**

## 为什么需要过滤

阅读一本书时，与当前研究问题直接相关的内容通常只占 20%。剩下的 80% 如果全部做成笔记，卡片盒会迅速膨胀，充满大量低质量的"死"卡片，淹没真正有价值的想法。

但完全忽略这 80% 也不行——其中可能藏着你未来思考其他问题时的关键素材。

三层过滤的目的：**在不占有每一个字的前提下，确保有价值的想法不被遗漏。**

## 三层详解

| 层级 | 判断标准 | 产出 | 心态 |
|------|---------|------|------|
| **第一层：当前燃料** | 直接与当前研究问题相关 | 立即做永久笔记，链接到项目 | 这是"燃料"，不是"库存" |
| **第二层：未来种子** | 与当前问题无关，但让你眼前一亮、感到兴奋 | 独立永久笔记，尝试建立 1-2 个链接 | 为未来思考网络"播种" |
| **第三层：图书馆编目** | 兴趣不大，但可能是基础概念或未来参考资料 | 在文献列表记简要摘要和页码，不放入卡片盒 | "图书馆编目"，不是"思考创造" |

## 两层关键判断

### 第一关：我有兴趣吗？

- **有兴趣甚至兴奋** → 立刻做永久笔记。兴趣是最好的筛选器，兴奋感意味着与潜意识中的某个知识模块产生共鸣
- **兴趣一般** → 略过或在文献列表留标记

### 第二关：是不是绕不开的基础概念？

- **是**（如康德的"物自体"）→ 制作一张概念笔记，为未来知识大厦打地基
- **不是** → 略过

## 决策树

```
读到时
  └→ 与当前研究问题直接相关？
      ├─ 是 → 【第一层】立即做永久笔记
      └─ 否 → 我有兴趣吗？
                ├─ 有 → 【第二层】做独立永久笔记，建立链接
                └─ 没有 → 是不是绕不开的基础概念？
                          ├─ 是 → 做概念笔记
                          └─ 不是 → 【第三层】文献留记号，或略过
```

## 关键心态：不要有占有欲

> 卡片盒法的核心是**思考**，而不是**复制**。只有那些能激发你思考、能与现有知识产生连接的内容，才值得进入卡片盒。其他内容，就让它留在书里——**书是你的外部存储器。**

你不必占有书里的每一个字。不要有占有欲。

## 与 GTD 的共通

这个方法与 GTD（Getting Things Done）的核心理念高度一致：
- **GTD**：2分钟法则——如果一件事 2 分钟能完成，立刻做，不堆积
- **三层过滤**：兴趣法则——如果一段内容让你兴奋，立刻写卡片，不犹豫

两者都依赖**快速决策 → 即时行动 → 不堆积**的机制。不同在于：GTD 处理的是任务，三层过滤处理的是想法。但底层逻辑相同——**用即时的小行动替代延后的分类负担。**

## 第二层为什么重要

兴趣是最好的筛选器。卢曼自己只做他认为有长久价值的内容。当你读到某条内容时产生的"眼前一亮"，意味着这条信息很可能与你潜意识里某个已有知识模块产生了共鸣——即使你当下说不清楚是什么。

给它做成一张独立笔记，放入卡片盒并建立链接，相当于为你未来的思考网络埋下一个种子。未来当你的思考触碰到相关领域时，这张笔记会自动浮现。
