# 接受平庸不是妥协

## 核心概念
**接受平庸不是妥协，不是放弃——接受是你可以去优化改善的起点。因为接受才是一个好状态，有这个好状态的时候，做什么事情才会做得比较到位。**

## 核心理念

### "接受"的三个层次

| 常见误解 | 实际含义 |
|:--------|:--------|
| 接受 = 认命、放弃努力 | 接受 = 如实看到现状，不逃避、不否认 |
| 接受 = 对自己降低标准 | 接受 = 不再把能量浪费在自我对抗上 |
| 接受 = 妥协、不再追求更好 | 接受 = 给自己一个真实的起点，从这儿开始优化 |

### 为什么接受才能优化

人没有高峰体验和低谷体验的对照，很难有平常心。金惟纯认为，人必须要有体验——糊底的体验也有，巅峰的体验也有——慢慢就可以用平常心去面对。

如果你一辈子就是很平庸、很普通，没有高峰体验怎么办？答案是：**你可以在接受自己平庸的状态之下，去发挥你的生命潜力。**

接受是让自己生命内在处于好的状态，可以去面对外面的挑战和风风雨雨。一个不接受自己的人，内在处于对抗状态——对抗自己的平庸、对抗自己的缺陷、对抗现实的不如意。这种对抗本身消耗了大部分能量，哪还有力气去优化改善？

### 与"认错"的关联

接受自己与认错是一体两面：不肯认错的部分背后，往往是有所不受——不承认自己是这样的人。当一个人如实地、完整地接受自己的时候，认错就变成自然而然的功课，而不是被迫的屈辱。
