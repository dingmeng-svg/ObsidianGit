# 规划谬误与任务分解

## 核心概念
**人们系统地低估任务所需时间，即使有过去的经验，没有即时反馈也不会改善——解决方案不是“更好地做计划”，而是分解任务并建立即时反馈循环。**

## 核心理念

### 规划谬误的实验证据

心理学家 Buehler 等人进行了一项经典实验：

- 要求学生预估完成论文所需的时间
- 学生给出的“50%把握”的预估、甚至“99%把握”的预估，都远低于实际用时
- **即使学生知道过去自己总是低估，他们在下一次预估时依然低估**

这说明：规划谬误不是“不够谨慎”的问题，而是人类认知的系统性偏差——**经验本身不会自动改善计划能力，除非有即时反馈将预估与实际进行对比。**

### 为什么做大计划是无效的

| 典型做法 | 问题 |
|---------|------|
| “先选题 → 读文献 → 列提纲 → 写作” | 研究过程中会不断出现新问题、新想法，打乱线性计划 |
| 为整篇论文设定一个截止日期 | 帕金森定律：任务会膨胀以填满分配时间；蔡格尼克效应：大任务悬而未决，持续占用大脑资源 |
| 告诉自己“接下来三个月写完” | 缺乏中间反馈节点，无法校准对自身效率的认知 |

### 解决方案：任务分解 + 即时反馈

将“写一篇论文”拆解为可一次性完成的微小任务：

```
❌ “今天写论文”
✅ “今天记3条永久笔记”
✅ “阅读某章节并做文献笔记”
✅ “整理一条笔记与已有笔记的链接”
```

**为什么小任务有效：**

1. **可完成**：一条笔记几分钟到几十分钟即可完成，完成后获得“完成感”
2. **即时反馈**：每天有多次“完成—检查—调整”的循环，逐步校准对自己效率的认知
3. **释放大脑**：蔡格尼克效应——小任务完成后大脑可以“放下”，不再持续占用注意力
4. **积累复利**：每天3条笔记，一年约1000条；复利效应在连接中显现

### 卢曼的做法

卢曼从不为“下一本书”做计划。他只是持续记笔记，当某个主题的笔记集群足够丰富时，自然就“长”出了一本书的素材。他同时进行多个处于不同阶段的项目，从不强迫自己去做困难的事——因为分解后的小任务本身就不困难。
