# 楷模与英雄

## 核心概念
**人生有两种榜样：楷模和英雄。楷模是人人像他这样，世界会变得更好的人——可复制、可普及；英雄是你很崇拜他、很佩服他，但人人都像他这样，世界搞不好大乱——不可复制、不可普及。**

## 核心理念

### 两者的本质区别

| | 楷模 | 英雄 |
|------|------|------|
| **定义** | 人人都可以效仿，效仿后世界更好 | 令人敬佩，但不可普及 |
| **可复制性** | 普世价值，可复制 | 特殊天赋+特殊机缘，不可复制 |
| **社会效果** | 人人效仿→社会优化 | 人人效仿→可能混乱 |
| **例证** | "修身为本"——放在哪里都对 | 马斯克——令人佩服，但不是人生方向 |
| **风险** | 无——学不会也不会走偏 | 高——学不像可能走火入魔 |

### 为什么需要这个区分

金惟纯用马斯克举例：把人类送上火星，很令人佩服。但他的方向是大家都要模仿的吗？未必。他不是楷模，他是个英雄。人人都像他这样，世界搞不好大乱。

这个区分的现实意义在于：当下的社会叙事总是推崇"英雄"——极少数人的极端成功故事被广泛传播，让人觉得"像他那样才算成功"。但英雄的成功条件不可复制，普通人硬学只会挫败和走偏。

楷模则不同。像中国人讲的"以修身为本"——这是普世价值，放在哪里都是对的，用在什么地方都有效果。这才是每个人都值得走的路。

### 与跨学科思维的关联

这个区分与芒格的"铁锤人倾向"有异曲同工之处：单一学科的训练让人只看到一个维度的成功模板——比如商业英雄、技术英雄——而忽略了更广阔的人生可能性。楷模思维本质上是"多模型思维"在人生观上的应用。
