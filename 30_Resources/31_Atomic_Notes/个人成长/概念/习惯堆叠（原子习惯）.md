# 习惯堆叠 (Habit Stacking)

> "One of the best ways to build a new habit is to identify a current habit you already do each day and then stack your new behavior on top."
> — James Clear

## 公式

**做完 [当前习惯] 后，我会立即做 [新习惯]。**

> After [CURRENT HABIT], I will [NEW HABIT].

## 我的习惯堆叠链

```
☀️ 早晨链条：
起床 → 喝水 → 称体重 → 写下MIT → 阅读30分钟

🕐 工作链条：
打开电脑 → 处理Inbox → Pomodoro (25+5) → 

🌙 晚间链条：
晚饭后 → 散步 → 复盘 → 规划明天 → 阅读 → 睡觉
```

## 堆叠设计原则

1. **锚点要具体**：不是"饭后"而是"把碗放进洗碗机后"
2. **频率要匹配**：每日习惯配每日锚点，每周习惯配每周锚点
3. **新习惯要小**：从2分钟版本开始
