# 识别宣传与假新闻的判断框架

在判断新闻报道的真实性及宣传成分时，可以重点关注以下三个维度：

## 一、议题选择

> 关注媒体是否只报道对“本阵营”有利的选题。

| 类型 | 表现 |
|------|------|
| 右翼媒体 | 只关注抗议者暴力 |
| 左翼媒体 | 只强调镇压和人权 |
| 中立/专业媒体 | 同时报道多方视角，哪怕对“自己人”不利 |

**核心问题**：如果一篇报道让你觉得“事情很简单，好坏分明”，很可能是议题选择已经过滤掉了复杂性。

## 二、信息密度

> 真正掌握内幕的报道会给出具体细节，而宣传性内容多用抽象口号。

**高信息密度报道的特征**：

- 具体时间线（如“1月13日五角大楼向总统呈报多套打击选项”）
- 参与官员的名字或职务
- 会议层级与政策流程
- 可交叉验证的细节

**宣传性内容的特征**：

- 抽象口号
- 无名的“知情人士”
- 缺少可验证的细节
- 情绪驱动而非事实驱动

## 三、交叉印证

> 若多家专业机构在关键事实层面高度一致，而分歧集中在解读，则事实本身可信度更高。

**验证策略**：

1. 找到路透、AP、WSJ、FT 等专业机构的报道
2. 比较它们之间的事实陈述部分（非评论部分）
3. 如果事实层面一致，分歧在解读层面 → 事实可信
4. 如果事实层面本身矛盾 → 继续寻找更多来源

## 快速判断清单

| 检查项 | 是/否 |
|--------|-------|
| 报道是否只呈现了单一立场？ | |
| 是否有具体的时间、地点、人物、流程细节？ | |
| 是否有多家独立来源交叉印证了核心事实？ | |
| 报道的情绪色彩是否过强（愤怒、恐惧、兴奋）？ | |

## 一句话总结

> 宣传让你“感觉”什么是对的；好报道给你足够的信息让你“判断”什么是对的。
