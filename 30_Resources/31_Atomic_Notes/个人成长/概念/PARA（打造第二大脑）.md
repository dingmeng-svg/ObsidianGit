# PARA：以行动为导向的分类框架

## 核心概念

**PARA** 是 Tiago Forte 提出的信息组织框架，是“行动导向”原则的具体落地。四个字母分别代表：

| 类别     | 英文        | 说明              | 时间维度 |
| ------ | --------- | --------------- | ---- |
| **项目** | Projects  | 正在进行、有截止日期的短期任务 | 现在   |
| **领域** | Areas     | 长期承担的责任范围       | 持续   |
| **资源** | Resources | 未来可能用到的素材       | 将来   |
| **存档** | Archives  | 已完成或不活跃的内容      | 过去   |

## 核心逻辑

PARA 将信息组织从“主题分类”转变为**“行动分类”**：

- 传统分类：按“这是什么”（如心理学、历史、科技）
- PARA 分类：按“这能帮我做什么”（如我正在写的报告、我需要维护的健康）

> 这是一种从“知识视角”到“用户视角”的转变。

## 与子弹笔记集子的对接

| BuJo 集子 | PARA 对应 | 功能 |
|-----------|-----------|------|
| 项目集子 | Projects | 有截止日期的短期任务 |
| 月度/每日记录 | Areas | 持续维护的责任范围 |
| 未来记录 | Resources | 可能用到的素材 |
| 归档集子 | Archives | 已完成的内容 |

## 操作建议

- 从四个文件夹开始，为每个活动项目创建一个专用文件夹
- 将相关笔记放入对应项目文件夹
- 项目完成后移至存档
- 领域和资源按需维护

## 在“知→行→进化”中的位置

| 维度 | 贡献 |
|------|------|
| **知** | 提供清晰的信息分类框架，让“知”可落地 |
| **行** | 直接以“项目”为中心驱动行动 |
| **进化** | 项目→存档的流转和领域的定期检视本身就是进化节奏 |

## 一句话总结

> PARA 不是按“信息是什么”来分类，而是按“信息能做什么”来分类。
