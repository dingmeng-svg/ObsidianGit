# 环境设计

> "Environment is the invisible hand that shapes human behavior."
> — James Clear

## 四大法则

### 第一法则：让好习惯显而易见 (Make it Obvious)

| 想建立的习惯 | 如何让它显而易见 |
|-------------|-----------------|
| 多喝水 | 桌上放装满水的水瓶 |
| 多读书 | 床头放书，手机放远处 |
| | |

### 第二法则：让好习惯有吸引力 (Make it Attractive)

| 想建立的习惯 | 如何让它有吸引力 |
|-------------|-----------------|
| 运动 | 边运动边听最喜欢的播客 |
| | |

### 第三法则：让好习惯简单易行 (Make it Easy)

| 想建立的习惯 | 如何让它简单 |
|-------------|-------------|
| 早起跑步 | 前一晚把运动服放在床边 |
| | |

### 第四法则：让好习惯令人满足 (Make it Satisfying)

| 想建立的习惯 | 如何让它满足 |
|-------------|-------------|
| 完成MIT | 在日历上打一个大大的✓ |
| | |

---

## 反过来：戒除坏习惯

| 法则 | 策略 | 应用 |
|------|------|------|
| 让它不显眼 | 把手机放在另一个房间 | |
| 让它没吸引力 | 重新编程你的大脑 | |
| 让它困难 | 删除APP | |
| 让它不满足 | 设置惩罚机制 | |
