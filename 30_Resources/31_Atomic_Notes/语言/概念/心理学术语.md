## 正文

心理学、哲学领域的专业术语构成了一个多维语义场：

**维度一：对象层次（个人/社会/世界）**
- psyche → 个人层面的心智、心灵
- ambivalent → 个人层面的矛盾情感
- nihilism → 世界层面的虚无主义
- relativism → 认知层面的相对主义

**维度二：情感基调（中性/负面/矛盾）**
- psyche → 中性学术术语
- nihilism → 负面世界观
- ambivalent → 矛盾情感状态
- selfdeception → 负面认知模式

**维度三：理论层次（描述/理论/批判）**
- psyche → 描述性概念
- manic → 临床诊断术语
- relativism → 哲学理论概念
- nihilism → 批判性概念

**维度四：认知方向（接受/否定/怀疑）**
- selfdeception → 否定现实
- nihilism → 否定意义
- ambivalent → 矛盾态度
- relativism → 怀疑绝对
