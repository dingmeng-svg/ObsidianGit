# 冲突即韧性建设（亲密关系）

> 来源：曹雪敏《我们为什么不爱了》

## 核心命题

更好的爱与被爱，需要通过**建设性的冲突**才能实现。冲突不是关系破裂的信号，而是关系韧性的**建设契机**。

## 三大价值

1. **深化理解**：打破「分类-等级」的社会规训带来的关系割裂
2. **保留自我 + 增进联结**：让双方既能在关系中保留独立自我，又能构建更紧密的情感联结
3. **韧性加固**：每一次成功的冲突处理，都在加固关系的韧性

## 安全的爱的反馈循环

```
确信彼此相爱 
  → 敢于直面冲突（而非压抑或攻击）
    → 成功处理冲突
      → 关系韧性增强
        → 更确信彼此相爱（回到起点）
```

## 与纸片人恋爱的关系

「纸片人恋爱」（虚拟情感 / 乙游）本质是对完美伴侣的想象投射，完全回避了真实亲密关系中必然存在的摩擦与冲突。但正是在**差异与冲突中反复磨合**的过程，才构建了真实关系的韧性。回避冲突，等于放弃加固关系的机会。
