# 情绪表达的习得性无助 → 结构化表达框架

> 来源：曹雪敏《我们为什么不爱了》冲突管理章节，案例「你看不到我的情绪」

## 问题机制

童年时期父母只关注衣食起居与学业，忽略情绪回应 → 形成「情绪表达是无效的」的**习得性无助** → 压抑情绪，转而期待伴侣主动「猜中」自己的感受 → 对方猜不中时爆发指责。

## 结构化表达练习

核心公式（三要素）：

```
我现在很__（情绪/感受）
+ 我经历了__（触发事件）
+ 我想要__（对对方的明确期待）
```

### 示例

- ❌ 「你看不到我的情绪！你不爱我！」
- ✅ 「我现在很难过 + 今天加班回来看到你在打游戏没注意到我进门 + 我想要你抱抱我」

## 效果

练习后，伴侣间的冲突大幅减少——不是因为不再有分歧，而是因为对方不再需要「猜」，关系中的误解空间被压缩了。
