# 标题：用意图驱动行动

## 核心概念

在子弹笔记中，**标题（Title）** 不仅仅是页眉——它是一个“暂停”的动作，帮助你澄清意图并设定内容方向。

## 三个目的

| 目的 | 动作 | 效果 |
|------|------|------|
| **确定并描述内容** | 给页面起名 | 明确“这是什么” |
| **阐明意图** | 问“为什么做这个” | 连接行动与意义 |
| **设定内容安排** | 规划页面结构 | 让内容有序 |

## 为什么有效？

> 起标题的过程打磨“专注于要事”的能力。

- 它迫使你在行动前**停下来思考**
- 它让意图**显性化**，而非模糊的念头
- 它是“意向性”的最小实践单元

> 带着意向去生活——行动前停下来认真规划。

## 与第二大脑的关联

| 子弹笔记标题 | 第二大脑 |
|------------|---------|
| 确定页面内容 | 确定笔记标题和内容范围 |
| 阐明意图 | 问“这条笔记将如何被使用？” |
| 设定内容安排 | 用 CODE 框架引导笔记结构 |

## 一句话总结

> 每写一个标题，都是在问自己一次：“我为什么在做这件事？”
