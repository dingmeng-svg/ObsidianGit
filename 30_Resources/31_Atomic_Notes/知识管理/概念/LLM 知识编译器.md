# LLM 知识编译器

## 核心概念

**LLM 知识编译器是指让大语言模型充当"知识编译器"，将你丢进文件夹的零散原始资料（论文、文章、代码等）自动分析、提取、撰写成相互链接的 Markdown 维基百科页面。它将人类从繁琐的笔记整理中解放出来，变为监督者，AI 承担主要的"写作"和"维护"工作。**

## 核心理念

### 为什么需要知识编译器

传统知识管理面临信息过载与维护惰性：收藏越来越多，检索越来越难，手动整理成本过高。LLM 知识编译器将这个过程反转——人类只负责投喂原始资料，AI 自动完成摘要、提取概念、撰写主题文章、建立双向链接，并支持增量更新。

### 编译过程四步

1. **撰写摘要**：为每份资料生成核心要点。
2. **提取概念与实体**：识别出文章中值得独立成页的关键词。
3. **撰写主题文章**：综合多份资料，为每个概念写出完整、独立的说明。
4. **建立双向链接**：在相关页面之间自动织成知识网络。

整个过程是**增量式**的：新增资料只更新受影响的页面，不重建整个库。

### 从"搜索"到"编译"的范式转移

传统搜索是每次从零开始查找资料；知识编译器则是持续将碎片信息编译成可继承的结构化网络。知识不是被找到的，而是被"编译"出来的。最终的产物是一个不断生长的、互联互通的第二大脑——甚至是一个可继承的数字分身。
