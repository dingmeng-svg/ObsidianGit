# Markdown 语法速查

> Obsidian 常用 Markdown 语法速查表。日常写作参考。

---

## 基础语法

| 语法       | 效果                    |
| :------- | :-------------------- |
| `# 标题`   | 一级标题（## 二级，### 三级，类推） |
| `**文字**` | **加粗**                |
| `*文字*`   | *斜体*                  |
| `~~文字~~` | ~~删除线~~               |
| ==文字==   | 高亮（Obsidian 扩展）       |
| `> 文字`   | 引用块                   |
| `---`    | 分隔线                   |

## 列表

```md
- 无序列表
1. 有序列表
- [ ] 待办事项
- [x] 已完成
```

## 链接与嵌入

| 语法 | 效果 |
|:---|:---|
| `[[笔记名]]` | 内部链接 |
| `|别名` | 带别名的链接 |
| `[[笔记名#标题]]` | 链接到标题 |
| `[文字](URL)` | 外部链接 |
| `![[文件名]]` | 嵌入文件/图片 |

## 代码

```md
`行内代码`
```

````md
```语言名
代码块
```
````

## Obsidian 扩展

| 语法 | 效果 |
|:---|:---|
| `%%文字%%` | 注释（渲染时隐藏） |

## 常用快捷键

| 快捷键 | 功能 |
|:---|:---|
| `Ctrl+E` | 切换编辑/阅读模式 |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+P` | 命令面板 |
| `Ctrl+O` | 快速打开 |
| `Ctrl+K` | 插入链接 |
| `Ctrl+,` | 打开设置 |
