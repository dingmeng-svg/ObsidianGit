# 集子：主题模块的容器

## 核心概念

**集子（Collection）** 是以主题聚合的页面组合——它是子弹笔记中用于承载长期追踪、项目规划和兴趣收集的模块。

## 常见类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 目标列表 | 记录长期目标 | 年度目标、季度目标 |
| 项目规划 | 管理具体项目 | 写作计划、装修项目 |
| 习惯追踪 | 追踪日常习惯 | 锻炼、阅读、冥想 |
| 阅读/观影清单 | 记录想看的书或电影 | 书单、影单 |
| 购物清单 | 管理采购需求 | 需购买的物品 |
| 财务记录 | 追踪收支 | 月度预算、支出追踪 |
| 心情追踪 | 记录情绪变化 | 每日心情 |

## 集子套组（Collection Stack）

多个关联集子组合使用，形成更完整的系统：

> 例如：一个“写作项目”可能包含 → 大纲集子 + 素材集子 + 进度追踪集子 + 反馈集子

## 与 PARA 的关联

| 集子类型 | PARA 对应 |
|---------|----------|
| 项目规划 | Projects |
| 习惯追踪/财务记录 | Areas |
| 阅读清单/购物清单 | Resources |
| 已完成项目 | Archives |

> 集子 = PARA 在纸质笔记本上的物理实现

## 一句话总结

> 集子是子弹笔记的“文件夹”——一个主题，一个页面组。
