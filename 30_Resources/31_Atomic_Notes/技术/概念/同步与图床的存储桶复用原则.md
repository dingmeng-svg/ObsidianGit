## 原子笔记

**触点判定**：潜在启发
**提纯**：同一个 COS 存储桶可同时承载图床托管和笔记多端同步两项功能，前提是它们各自使用不同的访问权限策略（图床公读私写、同步私有读写）。

---

**类型**：概念

**正文**：
一个 COS 存储桶同时干两件事之所以可行，是因为图床和同步对存储桶的访问权限可以独立控制：

- **图床场景**：需要「公有读私有写」。图片链接被嵌入笔记后，需要在任意网络环境下被加载展示，因此必须允许公开读取；只有本人可以上传和删除。
- **同步场景**：需要「私有读写」。笔记文件是个人隐私数据，不应被公开访问，只允许通过 Remotely Save 插件的密钥认证进行读写。

这两套权限在 COS 层面并不冲突——存储桶的访问策略是全局设定，但图床通过 CDN 分发实现公开访问（COS 上实际仍是私有链接，CDN 承担公开分发），而同步插件通过 API 密钥直连 COS 的私有 API 接口。两者在数据层共存，在访问层隔离。

**关键限定**：这种复用只适用于同一个云服务商的同一个账号下的同一个存储桶。跨云或跨账号时，需要分别配置。
