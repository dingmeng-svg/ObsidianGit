# 交易中的情绪循环

> 普通股民在交易中反复陷入的"冲动→亏损→懊悔→再冲动"死循环。识别这个循环是打破它的第一步。

## 循环的四个阶段

```
冲动交易 ──→ 亏损/踏空
   ↑              ↓
 懊悔         情绪反弹
   ←──────────
```

### 阶段一：冲动交易
- 驱动因素：FOMO（害怕错过）、消息刺激、他人赚钱
- 表现：不分析就买入、追涨、在情绪高点加仓

### 阶段二：亏损/踏空
- 亏损：买入即跌，账户缩水
- 踏空：卖出就涨，错失行情
- 两者的共同点：引发强烈的后悔情绪

### 阶段三：情绪反弹
- 试图"扳回来"的冲动
- 改变策略（追热点、换风格）
- 寻找外部原因（怪市场、怪消息、怪庄家）

### 阶段四：懊悔
- 自我怀疑："我是不是不适合炒股？"
- 暂时退缩，但下次冲动时又重复

## 打破循环的关键

1. **在阶段一设卡** — 交易前强制问自己三个问题
2. **在阶段二接受** — 亏损是交易的一部分，不是判断失误的证明
3. **在阶段三暂停** — 亏损后强制空仓24小时
4. **在阶段四复盘** — 写交易日志，找模式而非自责
